## 1. 改动目标

在侧栏「课表查询」下新增两个二级菜单页面：

1. **学生课表密度**
2. **教师课表密度**

页面主体展示效果对齐调课申请中的「学生课表密度」抽屉：筛选区 + 提示语 + 星期×节次密度矩阵表（支持「比率 / 人数」维度切换）。

相对调课抽屉的差异：

| 项 | 调课抽屉（现状保留） | 课表查询新页面（本期） |
| --- | --- | --- |
| 入口 | 调课申请目标节次下拉底部按钮 | 课表查询侧栏二级菜单 |
| 形态 | 嵌套抽屉 `#modal-adjustment-density` | 独立整页 `section.page` |
| 查询条件 | 无日期范围 | **增加日期范围（起止）**；其余学生侧对齐抽屉 |
| 单元格点击 | 可选中并回填目标节次 | **不回填调课**；单元格仅展示密度（可保留 hover/title） |
| 底部「确定」 | 有（回填 + 忽略学生冲突） | **无** |
| 提示语 | 查询优先级 + 选中节次忽略冲突说明 | 查询优先级 + **查询条件范围内人数与比率之比**（见 §4） |
| 单元格展示 | 维度切换 | 维度切换（已确认，同左） |

非目标（本期不做）：

- 不改调课申请密度抽屉的交互与回填逻辑（除非抽公共渲染时做无行为变更的复用）；**调课抽屉本期不强制加日期范围**。
- 不改排课表时间 / 排课表教室两侧菜单与交互。
- 不做导出、不做与调课申请的双向联动。
- 单元格不做「人数 + 比率」同时显示。

## 3. 页面结构

### 3.1 学生课表密度页

结构对齐调课抽屉主体，改为课表查询页常见布局（`page-header` + `card` 查询区 + 结果区）：

```html
<section class="page schedule-page" id="page-schedule-student-density" hidden>
  <div class="page-header">
    <div>
      <h1>学生课表密度</h1>
      <p class="subtitle">按筛选范围查看学生在星期×节次上的占用密度</p>
    </div>
  </div>
  <!-- 查询条件：调课密度字段 + 日期范围 -->
  <!-- 提示语：见 §4 -->
  <!-- 密度矩阵表 -->
</section>
```

#### 3.1.1 查询条件

| 字段 | DOM 建议 id | 说明 |
| --- | --- | --- |
| 学期 | `sdf-term` | 默认当前开课/排课学期 |
| 学生学号 | `sdf-student-id` | 文本 |
| 学生姓名 | `sdf-student-name` | 文本；查询优先级最高 |
| 专业 | `sdf-programme` | 全部 + 专业列表 |
| 批次 | `sdf-batch` | 全部 + 专业·批次 |
| 性别 | `sdf-gender` | 全部 / Male / Female |
| 周数 | `sdf-week` | 全部 + 第1–18周；默认当前教学周 |
| **日期范围（起）** | `sdf-date-from` | `type="date"`；可空 |
| **日期范围（止）** | `sdf-date-to` | `type="date"`；可空 |
| 教师工号 | `sdf-teacher-id` | 文本 |
| 教师姓名 | `sdf-teacher-name` | 文本；次优先级 |
| 密度维度 | `sdf-dimension` | `ratio`（比率）/ `count`（人数），默认比率 |

操作：查询、重置。

布局建议：日期起、日期止并排两个筛选项，标签可用「开始日期」「结束日期」，或同一 `srf-item` 内「日期范围」+ 两个 date 输入（与场地冲突查询单日 `type="date"` 控件风格一致）。

查询优先级规则（与现逻辑一致，须在提示语中保留）：

1. 有学生姓名 → 仅按学生姓名过滤  
2. 否则有教师姓名 → 仅按教师姓名关联学生过滤  
3. 否则叠加学号 / 专业 / 批次 / 性别 / 教师工号等其他条件  

**周数与日期范围**：均作用于矩阵「占用是否计入」，与人员池过滤独立；二者同时有值时取 **交集**（节次落在指定周 **且** 落在日期范围内才计入该格）。任一为空表示该维不约束。

#### 3.1.2 表格展示（维度切换已确认）

- 表头：首列「时间节次」，其后周一…周日（与 `SCHEDULE_WEEKDAYS`、调课密度一致）。
- 行：节次目录（`getAdjustmentPeriodCatalog` / 同等节次源），展示「第 N 节 HH:mm-HH:mm」。
- 单元格（由 `sdf-dimension` 切换，**不同时显示双值**）：
  - 维度 = 比率：`Math.round(count/total*100)%`
  - 维度 = 人数：`count`
  - `title`：`学生占用 {count}/{total} 人`（与调课侧一致）
- **不实现**单元格选中 / 回填；不展示「请点击表格单元格选择目标星期与节次」。

### 3.2 教师课表密度页（筛选已确认）

视觉与布局同学生页；数据口径改为「教师占用」。

```html
<section class="page schedule-page" id="page-schedule-teacher-density" hidden>
  ...
  <h1>教师课表密度</h1>
  <p class="subtitle">按筛选范围查看教师在星期×节次上的占用密度</p>
</section>
```

#### 3.2.1 查询条件（已确认，含日期范围）

| 字段 | DOM 建议 id | 说明 |
| --- | --- | --- |
| 学期 | `tdf-term` | 同学生页 |
| 教师工号 | `tdf-teacher-id` | 文本 |
| 教师姓名 | `tdf-teacher-name` | 文本；查询优先级最高 |
| 周数 | `tdf-week` | 全部 + 第1–18周；默认当前教学周 |
| **日期范围（起）** | `tdf-date-from` | `type="date"`；可空 |
| **日期范围（止）** | `tdf-date-to` | `type="date"`；可空 |
| 密度维度 | `tdf-dimension` | 比率 / 人数，默认比率 |

本期不做：学院/系、教师类型等扩展字段。

查询优先级：

1. 有教师姓名 → 仅按姓名过滤  
2. 否则叠加工号等其他条件  

周数与日期范围的交集规则同 §3.1.1。

#### 3.2.2 矩阵计算口径

- 总体 `total` = 当前筛选命中的教师人数。  
- 某格 `count` = 该星期+节次上「有已排课节次占用」的教师数（一人多课同一格只计 1）；计入时须满足周数 / 日期范围约束。  
- 比率 = `count / total`。  
- 单元格按 `tdf-dimension` 切换显示比率或人数。  
- `title`：`教师占用 {count}/{total} 人`。

演示数据源：`getScheduleTeacherGroupRows()` + 各教师任务节次（`getAdjustmentTeacherTasks` / `taskHasScheduleTeacher` 同类路径）。

### 3.3 日期范围校验与默认值

| 规则 | 行为 |
| --- | --- |
| 起、止均可空 | 空 = 不按日期约束 |
| 只填起或只填止 | 按单边约束（≥ 起 或 ≤ 止） |
| 起 > 止 | 查询时 `alert` 提示「开始日期不能晚于结束日期」，不刷新矩阵 |
| 重置 | 起、止清空；周数恢复当前教学周；维度恢复「比率」 |
| 默认进入 | 日期范围为空；与调课抽屉首次打开「按周默认、不按自然日」一致 |

占用是否落入日期范围（演示实现建议）：

1. 由学期开始日 + 节次周次 + 星期，换算该节次对应自然日（可复用 `getAdjustmentDateByWeekAndWeekday` / `getScheduleSlotDateLabel` 一类逻辑）。  
2. 若节次周次为区间（如第1-16周），则判断该区间内是否存在至少一个自然日落在 `[dateFrom, dateTo]` 且星期匹配；有则该人格计入占用。  
3. 与「周数」筛选同时开启时：先限定周，再套日期交集。

矩阵计算函数签名建议扩展为：

```text
computeAdjustmentDensityMatrix(students, weekFilter, termCode, dateFrom, dateTo)
computeTeacherDensityMatrix(teachers, weekFilter, termCode, dateFrom, dateTo)
```

页面调用传入日期；**调课抽屉**继续传空日期，行为与改前一致。

## 4. 页面提示语（文案已确认）

### 4.1 需求表述

在页面提示语中**额外**展示：当前查询条件范围内的 **人数** 与 **比率** 的对应关系（人数和比率之比）。

### 4.2 展示位置

使用独立提示块（样式可复用 `.adj-density-hint`，页面上可用 `.schedule-density-hint`）：

- 放在查询条件区下方、密度表格上方。  
- 查询成功后随结果刷新；重置后按默认条件重算。

### 4.3 文案规则（已确认）

#### 学生页

```text
查询优先级：学生姓名条件、教师姓名条件、其他条件。
当前查询范围：共 {total} 人。单元格「人数」为该节次占用人数；「比率」= 占用人数 ÷ 范围人数（人数/比率之比，如 12/80 → 15%）。
```

#### 教师页

```text
查询优先级：教师姓名条件、其他条件。
当前查询范围：共 {total} 人。单元格「人数」为该节次占用教师数；「比率」= 占用人数 ÷ 范围人数（人数/比率之比，如 3/20 → 15%）。
```

说明：

- `{total}` 取本次 `compute*DensityMatrix` 返回的 `total`（筛选后的学生/教师池大小）。  
- 「人数/比率之比」在提示语中用固定说明 + 举例；**不要求**在提示语里罗列全部单元格。  
- 若 `total === 0`：提示「当前查询范围：共 0 人，无密度数据」，表格空态「暂无数据」。  
- **删除/不展示**调课专用句：「选中节次确定调课则默认为忽略冲突调课。」

### 4.4 与「密度维度」的关系（已确认）

- 维度下拉控制单元格显示「比率」**或**「人数」（切换，非双显）。  
- 提示语始终同时解释两种口径及换算关系，避免用户只看到一种维度时误解分母。

## 5. 代码改动清单

### 5.1 `index.html`

4. **不改动** `#modal-adjustment-density` 的 DOM（调课入口继续用原抽屉）。

### 5.2 `app.js`

#### 5.2.1 推荐复用策略

将调课密度中的「纯计算 / 纯渲染」抽一层可复用函数（行为不变地供抽屉继续调用），页面侧只换 DOM id 与交互壳：

| 能力 | 现函数（调课） | 建议抽公共 / 页面封装 |
| --- | --- | --- |
| 学生池 | `getAdjustmentDensityStudentUniverse` | 可直接复用 |
| 学生过滤 | `filterAdjustmentDensityStudents` | 入参为 filters 对象，页面传入 `sdf-*` 读值结果 |
| 矩阵计算 | `computeAdjustmentDensityMatrix` | 增加可选 `dateFrom/dateTo`；抽屉传空 |
| 表渲染 | `renderAdjustmentDensityTable` | 抽 `renderDensityMatrixTable({ thead, tbody, data, dimension, selectable })`；调课 `selectable=true`，查询页 `false` |
| 教师矩阵 | （无） | 新增 `computeTeacherDensityMatrix(teachers, weekFilter, termCode, dateFrom, dateTo)` |
| 日期落入判断 | （无） | 新增 `densitySlotInDateRange(slot, task, dateFrom, dateTo, termCode)` 一类辅助 |

原则：抽公共时 **调课抽屉对外 API 名与行为保持不变**（`openAdjustmentDensityDrawer` / `queryAdjustmentDensity` 等仍可用）。

#### 5.2.2 页面级函数（建议命名）

```text
renderScheduleStudentDensityPage()
buildScheduleStudentDensityFilterOptions()
getScheduleStudentDensityFilters()   // 含 dateFrom / dateTo
queryScheduleStudentDensity()
resetScheduleStudentDensityQuery()
updateScheduleStudentDensityHint()
renderScheduleStudentDensityTable()

renderScheduleTeacherDensityPage()
buildScheduleTeacherDensityFilterOptions()
getScheduleTeacherDensityFilters()   // 含 dateFrom / dateTo
queryScheduleTeacherDensity()
resetScheduleTeacherDensityQuery()
updateScheduleTeacherDensityHint()
renderScheduleTeacherDensityTable()
computeTeacherDensityMatrix(...)
filterTeacherDensityTeachers(...)
```

状态变量与调课侧隔离：

```text
scheduleStudentDensityData
scheduleTeacherDensityData
```

（查询页不需要 `*Selected` / contextVal。）

#### 5.2.3 路由钩子

见 §2.2。
