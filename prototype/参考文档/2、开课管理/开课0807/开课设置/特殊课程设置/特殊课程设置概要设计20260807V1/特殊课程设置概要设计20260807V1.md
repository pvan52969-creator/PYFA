## 2. 建设目标与范围

### 2.1 目标

在开课设置侧提供课号级默认配置（教室属性/偏好、默认 Support 学院、Support 历史），供专业开课安排新建或仍为系统默认的教学班自动带出，减少每学期重复录入。

### 2.2 范围内

- 从教务课程库手动将课程纳入维护清单
- 四类学时各自的教室属性与参考教室偏好
- 默认 Support 学院（多选，不可含本开课单位）
- Support 历史（Y / N）
- 查询、添加、编辑、删除清单项

### 2.3 非目标（不在本菜单）

- 不强制全库课程必须先配置才能开课
- 不替换校选课程管理
- 不改排课冲突算法
- 不在本页做合班 / 名单 / 任务安排
- 班级覆盖不回写课号配置

## 3. 用户角色与使用场景

| 角色 | 场景 | 目标 |
|------|------|------|
| 教务管理员 | 某课每学期重复录入教室/Support | 一次性维护课号级默认 |
| 教务管理员 | 新开课安排新建教学班 | 自动带出教室与 Support 默认值 |
| 教务管理员 | 查看 Support 历史 | 计划/安排抽屉只读展示 Y/N |

## 4. 在整体业务链路中的位置

```text
教务课程库 → 【特殊课程设置】→ 开课计划（Support历史只读展示）
                              → 开课安排（新建/空字段时带出教室与 Support 默认）
                              → 通识等（预留复用同一读取接口）
```

与开课时间设置、校选课程管理并列，属开课设置前置配置；非专业开课必经，未纳入清单的课号按系统默认（Support 历史视为 N）正常流转。

## 5. 主业务流程

1. 管理员按开课单位、课号筛选已纳入清单。
2. 通过「添加课程」从教务课程库多选纳入（课号去重；新纳入默认教室全普通、Support 空、Support历史 = N）。
3. 行操作「编辑」打开抽屉，维护四学时教室属性/偏好、Support 学院与 Support 历史。
4. 下游新建教学班或打开编辑且字段仍为空时，按 `onlyIfEmpty` 规则补全；班上已手工改过的值不被覆盖。
5. Support 历史始终按课号同步展示，不受班级覆盖影响。

## 6. 职责边界

| 职责 | 说明 |
|------|------|
| 负责 | 课号级教室默认、Support 学院默认、Support 历史 |
| 不负责 | 教学班级最终教室/Support 维护（在开课安排）、计划生成、授课确认 |
| 与他模块交接点 | 默认值读取 → 开课计划/安排；Support 历史 → 各层只读展示 |
