## 2. 建设目标与范围

### 2.1 目标

维护校选课程（GE 通识选修 + ME 专业选修类校选）主数据池，规范修读范围与开课默认教学设置，作为通识选修开课计划的候选课库与默认值来源。

### 2.2 范围内

- 校选课程清单查询、分页、排序
- ME 类型从教务课程库纳入；GE 由 Restrictions List 种子同步（本页不可新增 GE）
- 修读范围维护：可选/不可选专业、学生类型、不可选年级学期、冲突/先修课程
- 开课默认信息：Support 历史、状态、是否排课/排场地/考勤/录入成绩/排考、备注
- 批量改状态、删除校选池记录

### 2.3 非目标（不在本菜单）

- 不含计划人数、预留名额、起止周、分组与教师（在通识选修开课侧维护）
- 不含专业开课计划生成、合班、授课确认
- 不含入学批次级修读范围细化
- 不含导出 Excel（原型占位已隐藏）

## 3. 用户角色与使用场景

| 角色 | 场景 | 目标 |
|------|------|------|
| 教务 | 通识开课前 | 确认 GE 课库完整、ME 课纳入校选池 |
| 教务 | 调整某门校选课修读范围 | 限制/开放专业与学生类型 |
| 教务 | 维护开课默认开关 | 下游通识计划自动带出默认值 |
| 教务 | 停课某门校选课 | 使其不可再被选入通识开课计划 |

## 4. 在整体业务链路中的位置

```text
教务课程库 / GE Restrictions List → 【校选课程管理】→ 通识选修开课计划
                                              ↘（与专业开课链路并行，无直接依赖）
```

操作流程图将本菜单与开课时间设置、特殊课程设置并列置于「开课设置」泳道；通识选修计划 → 安排 → 名单依赖本模块课库，专业开课主链路不经过本页。

## 5. 主业务流程

1. 管理员按单位、类型（GE/ME）、类别、状态、课号筛选列表。
2. GE 课由外部 Restrictions List 同步进入池；ME 课通过「新增」从课库 `Major Elective` 纳入。
3. 对单课设置修读范围（专业互斥规则、学生类型、年级学期、冲突/先修）。
4. 通过「课程信息 · 修改」维护开课默认教学设置与状态。
5. 通识开课计划选课时仅消费 GE + 正常状态课程，并带入修读范围与教学默认值。

## 6. 职责边界

| 职责 | 说明 |
|------|------|
| 负责 | 校选池主数据、修读范围、开课默认、课程状态（正常/停课） |
| 不负责 | 通识计划行维护、任务安排、名单、选课应用联调本体 |
| 与他模块交接点 | 候选课库与默认值 → 通识选修计划；Support 历史语义与特殊课程设置可对齐但各自维护 |
