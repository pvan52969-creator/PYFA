## Why

开课管理各列表的查询栏与表头不对齐：常见列无法检索，人数不能按区间筛，导出按钮被拿掉或只在个别页存在。学院/教务需要按表头条件查出结果并导出当前筛选全集，否则只能靠肉眼扫表。

## What Changes

- 开课管理侧栏所有**页级主表**统一：查询区提供「查询 / 重置 / 导出」。
- 导出当前筛选后的全部行（不分页），CSV UTF-8 BOM；无数据时提示，不下载空文件。
- 筛选尽量对应可见数据列；字段过多时默认只展示高频项，其余进「展开筛选」。
- 文本框模糊匹配（contains）；枚举下拉精确匹配；人数类字段用「从 x — 到 x」区间（空端不限）。
- 开课计划查询区「专业」改为「上课专业」（仍筛上课专业，不是所属专业）。
- 开课计划人数筛预置人数；开课名单人数筛实际导入名单人数。

## Capabilities

### New Capabilities

- `offering-list-export-filters`: 开课管理主列表的查询展开、列对齐筛选、文本模糊、人数区间、CSV 导出约定

### Modified Capabilities

- （无）`openspec/specs/` 下暂无已归档主规格

## Impact

- `index.html`：各开课管理页查询栅格（primary / more）、导出按钮、开课计划「上课专业」标签
- `app.js`：通用 CSV 下载、人数区间匹配、各页 filter / export；Teaching Load 现有导出走同一下载函数
- `styles.css`：查询展开收起、人数区间字段
- 非目标：流程图、抽屉/弹窗/分组工作台内部表、培养方案与排课模块、批量升版 PRD
