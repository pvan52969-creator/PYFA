## 1. 原则

| 原则 | 说明 |
|------|------|
| 母文件夹 = 一级菜单 | 二级菜单文档放在对应一级菜单目录下 |
| **序号前缀** | 一级 `NN_菜单名`；二级 `NN_菜单名`（与侧栏顺序一致，见下表） |
| **每版本一文件夹** | `<二级>/<菜单><日期><Vn>/` 内放该版 md/docx；变更说明放在**新版**文件夹 |
| 禁止覆盖 | 不得用新内容覆盖已有版本文件夹内的 md/docx |
| 升版递增 | 同菜单下次产出为新版本文件夹；允许跳号 |
| 变更必随 | 凡升版须同时产出「变更说明」，对照**上一有效版本** |
| 模板对齐 | 正文用 PRD V3.1（或 V3）→ 变更说明必须用简版 V3；正文仍为旧 V2 结构 → 可用简版 V2 |

## 3. 变更说明模板选用（过渡策略）

| 本版 PRD 正文结构 | 变更说明 | 规则 |
|------------------|----------|------|
| 《厦大马来分校本科教务系统PRD模板_V3》 | **简版 V3（强制）** | 总览须含对象类型、对象ID |
| 仍为旧 PRD V2 章节结构 | 简版 V2（允许） | `--template-version v2` |
| 历史已产出的变更说明 | — | **不批量回改**；不删除 V2 模板文件 |

自首份按 PRD 模板 V3 写正文的升版起，强制使用变更说明 V3。

## 4. 变更说明必填项（简版 V3）

1. **版本信息**：文档名、菜单路径、V_ → V_、上一版/本版文件、本版 PRD 模板、原型地址（可选）、变更日期（**不含**签核栏）  
2. **本次改了什么**：类型 ∈ {新增, 修改, 删除, 澄清}；列含对象类型、对象ID、可读名、调整内容、状态；一行一事  
3. **前后对照**（复杂时）：须落到对象ID；字段状态写明 Add/Edit/View  
4. **连带影响**（影响原型/开发/测试时）：鼓励写下游菜单路径或界面 ID  

对象类型：界面 / 字段 / 功能 / 规则 / 数据流 / 其他。有 PRD ID 必填对象ID；纯文案澄清可 `—`；未确认可标 `UC00x`。

## 5. 操作提示

```bash
# 重新生成变更说明简版 V3 模板（不覆盖已有同名文件）
python3 scripts/generate-change-note-template-v3.py

# 生成变更说明（默认 V3，对齐 PRD 模板 V3）
python3 scripts/generate-submenu-prd-change-note.py --menu 开课计划 --from V6 --to V7

# 正文仍为旧 PRD V2 结构时
python3 scripts/generate-submenu-prd-change-note.py --menu 开课计划 --from V6 --to V7 --template-version v2

# 历史批次：V2 结构 PRD（仅作参考，新开 V3 正文勿用）
python3 scripts/generate-prd-20260825-batch.py
```

无需求差异时不要空升版。
