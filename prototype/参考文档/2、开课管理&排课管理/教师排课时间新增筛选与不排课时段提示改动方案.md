# 教师排课时间新增筛选 · 排课界面「不排课时段」提示改动方案

> 文档性质：代码改动方案（需求文档，供实现前对齐）  
> 适用范围：  
> 1. 排课基础设置 → 排课时间设置 → **教师排课时间**（新增/修改弹窗）  
> 2. 排课表时间详情页冲突图例 / 软冲突提示色  
> 关联代码：`prototype/index.html`、`prototype/app.js`、`prototype/styles.css`  
> 状态：**已按默认口径实现**（批量多选保存；图例+格子+弹窗 soft 行改灰；列表页不加性别/职称；修改不可换人）

---

## 1. 改动目标

### 1.1 教师排课时间「新增」

在 `#modal-schedule-teacher-slot`（新增/修改教师排课时段）中，教师选择能力升级为：

- 支持按范围筛选教师后再设置时段；
- 筛选维度：**所属学院、性别、教职工类型、职称**；
- 筛选结果用于圈定要维护时段的教师集合（见 §3.3 保存口径）。

### 1.2 排课界面提示

排课表时间详情页冲突图例中：

| 项 | 现状 | 目标 |
| --- | --- | --- |
| 名称 | 「占位/时段提示」 | **「不排课时段」** |
| 提示色 | 琥珀色（`is-soft`：背景 `#fef3c7` / 色点 `#f59e0b`） | **灰色** |

非目标（本期不做，除非确认）：

- 不改「课表不排课时间」「选修课排课时间」两个 Tab 的列表与弹窗。
- 不改教师排课时间**列表页**既有查询字段（工号/姓名/学院/教职工类型/周次/星期/节次）；若产品希望列表也加性别/职称，见 §8。
- 不改排教室侧图例集合与交互（本图例项 `data-sch-leg="time"`，仅排时间侧显示）。
- 不改调课申请、自动排课中的冲突文案体系（除非与图例共用函数，仅做文案常量替换时顺带对齐）。

## 3. 教师排课时间新增：按范围筛选

### 3.1 交互结构（建议）

在弹窗「教师」区域上方或左侧增加**范围筛选条**，再展示可选教师：

```text
[所属学院 ▼] [性别 ▼] [教职工类型 ▼] [职称 ▼]  [筛选] [重置]
教师选择区：多选列表 / 勾选表格（展示工号、姓名、学院、性别、类型、职称）
全选当前筛选结果 | 已选 N 人
（下方时段区不变：只排课 / 不排课互斥）
```

布局建议：

1. 筛选项使用与设置页一致的 `schedule-query-field` / `form-grid` 风格。  
2. 教师选择由「单选 `<select>`」改为「可勾选列表」（推荐高度约 200–280px，可滚动）。  
3. **修改**已有单条记录时：保持单教师编辑（筛选区可隐藏或禁用多选），避免误批量覆盖。  
4. **新增**时：支持勾选多名教师，一套时段配置批量写入。

### 3.2 筛选项定义

| 字段 | DOM 建议 id | 选项来源 | 说明 |
| --- | --- | --- | --- |
| 所属学院 | `schedule-modal-ts-filter-school` | `OFFERING_UNIT_CODES` / `SCHOOL_CODES`（与列表页 `schedule-time-setting-teacher-school` 一致） | 全部 + 学院代码 |
| 性别 | `schedule-modal-ts-filter-gender` | `Male` / `Female` | 全部 + 两项 |
| 教职工类型 | `schedule-modal-ts-filter-staff-type` | `TEACHER_TYPE_CODES` 或花名册去重 | 全部 + 类型 |
| 职称 | `schedule-modal-ts-filter-title` | 花名册职称去重（见 §3.4） | 全部 + 职称 |

筛选逻辑：各条件 AND；空值表示不约束。点击「筛选」刷新可选列表；「重置」清空四条件并恢复全量可选教师。

> 也可做成改条件即刷新（`onchange`），与「筛选」按钮二选一；建议保留按钮以降低误触刷新。

### 3.3 保存口径（新增批量）

新增且勾选多名教师时：

1. 校验时段规则与现单教师保存相同（星期/节次成对、周次起≤止、只排课与不排课互斥等）。  
2. 对每名已选教师：  
   - 若该学期已存在档案 → **跳过并汇总提示**（与现状「已存在请修改」一致，不静默覆盖）；  
   - 否则新增一条 `teacherSlotProfiles` 记录（时段/备注相同，教师信息各异）。  
3. 保存结束提示示例：`成功新增 5 人；跳过已存在 2 人（工号…）`。  
4. 变更日志：按教师逐条 `appendEntityChangeLog`（`create`）。

修改模式：仍只更新当前 `scheduleModalCtx.id` 对应的一名教师；教师下拉/列表不可改人或仅只读展示。

### 3.4 花名册字段扩展

扩展 `toScheduleTeacherRosterEntry`：

```text
id, name, schoolCode, staffType, gender, title
```

数据回填优先级建议：

| 字段 | 来源 |
| --- | --- |
| schoolCode | 任务/开课单位 → pool.departmentCode |
| staffType | 入参 → meta.staffType → pool.teacherType |
| gender | pool.gender → meta.gender → 演示缺省（按工号哈希 Male/Female） |
| title | pool.title → meta.title → 演示枚举补齐 |

演示职称枚举建议（原型即可）：

```text
Professor / Associate Professor / Assistant Professor / Lecturer / Senior Lecturer
```

在 `buildMockTeacherPickerPool` 为每位教师补 `title`（按 index 轮询上表）。  
列表页「所属学院 / 教职工类型」下拉填充逻辑可复用扩展后的花名册去重结果。

### 3.5 函数改动清单（建议）

```text
// 花名册
toScheduleTeacherRosterEntry(...)          // 增加 gender/title
collectScheduleTeachersForTimeSetting()    // 透传字段
getScheduleTeacherRosterList()             // 不变接口，字段变富

// 弹窗筛选与多选
buildScheduleTeacherSlotModalFilterOptions()
getScheduleTeacherSlotModalFilters()
filterScheduleTeacherRosterByModalFilters(list, filters)
renderScheduleTeacherSlotModalTeacherPicker()
toggleScheduleTeacherSlotModalTeacher(id, checked)
toggleScheduleTeacherSlotModalTeachersAll(checked)
resetScheduleTeacherSlotModalFilters()

// 打开/保存
openScheduleTeacherSlotModal()             // 新增：渲染筛选+多选；修改：单教师
saveScheduleTeacherSlotModal()             // 新增：批量写入
```

DOM 建议：

| 用途 | id |
| --- | --- |
| 筛选条容器 | `#schedule-modal-ts-filter-bar` |
| 教师多选列表 | `#schedule-modal-ts-teacher-list` |
| 已选计数 | `#schedule-modal-ts-selected-count` |
| 原单选下拉 | 新增模式隐藏；修改模式保留或改为只读展示 |

## 4. 排课界面：名称与颜色

### 4.1 文案

| 位置 | 现状 | 目标 |
| --- | --- | --- |
| 图例 `#schedule-conflict-legend` 中 `is-soft` 项 | 占位/时段提示 | **不排课时段** |
| `getScheduleConflictSoftDetailLabel` 多类/空回退 | 占位/时段提示 | **不排课时段** |
| 注释中提及该图例名的说明 | 同步改 | 同步改 |

单类软冲突仍可显示细类（「不排课时间」「选修课占位」「教师排课时间」「排课规则」）；仅图例总称与多类回退名改为「不排课时段」。

> 说明：图例「不排课时段」是排课界面软冲突总称，与设置页「课表不排课时间 / 教师不排课时段」细类并存；弹窗明细行标题可继续用细类，避免信息损失。

### 4.2 颜色（灰色）

建议统一软冲突视觉为灰色系（图例 + 课表格着色 + 角标，保持一致）：

| 选择器 | 建议值 |
| --- | --- |
| `.sch-leg-item.is-soft` | 背景 `#f3f4f6`，文字 `#374151` |
| `.sch-leg-item.is-soft::before` | `#9ca3af` |
| `.schedule-grid-cell.is-conflict-soft` | 背景 `#e5e7eb`，描边 `#6b7280` |
| `.sch-conflict-cell-label.is-soft` | `#374151` |
| `.sch-conflict-summary.is-soft`（若弹窗摘要仍用） | 背景 `#f3f4f6`，文字 `#374151`，左边线 `#9ca3af` |

可选：冲突弹窗中 `is-blackout / is-elective / is-teacher-slot` 行背景是否一并改灰——**建议本期一并改为灰色**，与图例「不排课时段」语义一致；若只改图例不改弹窗行，需在 §8 确认。

### 4.3 范围与独立性

- 图例项带 `data-sch-leg="time"`，排教室侧不展示该文案，满足时间/教室独立性。  
- `.is-conflict-soft` 为共享 class：若教室侧未使用 soft 着色，改色无教室侧可见影响；若后续教室侧复用，需再评估。  
- **禁止**为满足本需求去改教室侧右键菜单、锁定/待定等交互。
