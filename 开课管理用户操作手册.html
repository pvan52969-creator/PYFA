开课管理 · 用户操作手册

厦门大学马来西亚分校（XMUM）本科教务系统 ｜ 版本 V4 · 2026年8月

适用角色

教务管理员、学院教务、授课教师。不同角色在系统中的操作权限有所区别，详见各模块说明。

系统概述

开课管理是XMUM本科教务系统的核心模块，负责从培养方案执行计划生成学期开课任务，完成教学任务维护、合班、师资安排与学生名单管理，最终产生可交付排课、选课、考勤等下游系统使用的正式开课数据。

操作建议

推荐按从左到右、从上到下的顺序完成开课工作流：先做开课设置 → 再生成开课计划 → 完成开课安排 → 最后维护开课名单。

图：系统主界面 — 开课管理模块

快速入门

以下是一个完整学期的开课操作主流程：

1. 开课时间设置→ 2. 校选课程管理
(维护GE/ME主数据)→ 3. 特殊课程设置
(课号级默认)→ 4. 开课计划
(生成→合班→生效)→ 5. 开课安排
(三步→生效)→ 6. 开课名单
(分配→保存)

关键依赖：第4步"生成开课任务"必须在第1步设置「默认展示学期=是」之后操作。第5步"开课安排"只有在第4步"开课计划"生效后才能看到对应教学班。第6步"开课名单"只有在第5步"开课安排"生效后才能维护。

1. 开课时间设置

菜单位置：开课管理 → 开课设置 → 开课时间设置

适用角色：教务管理员

目的：按学年学期配置开课操作时间窗口，作为专业开课等下游模块的前置条件。

1.1 主要功能

功能说明
查询 / 重置按学年学期、默认展示学期过滤列表
新增为尚未配置的学期新增开课时间（选择学年学期 → 设置开始/截止时间）
修改修改全校开课窗口、授课确认截止日期、备注信息
删除批量删除学期配置（确认后不可撤销）
默认展示学期开关在列表中切换"是/否"，全局仅允许一个"是"（排他），下游模块依赖此项
单位开课时间设置展开行内区域，为各学院配置独立的开课时间（有配置时覆盖全校时间，否则继承）

1.2 字段说明（修改弹窗）

字段类型必填说明
学年学期只读—附教学周提示
开课开始日期时间是须早于截止，格式 dd/mm/yyyy HH:mm
开课截止日期时间是须晚于开始；超出校历结束日可确认后保存
授课确认截止日期日期否仅日期；可设已过期日期；供教师确认函引用
备注文本否最长200字

1.3 业务规则

  • 教学周数由学期类型固定推导：2月短学期=5周，4/9月长学期=14周（不在本页手工维护）
  • 状态由截止时间相对当前时刻判定：开放中 / 已截止
  • 单位覆盖：单位有独立起止时间时，该单位开课操作窗口以单位配置为准；未配置则继承全校时间
  • 默认展示学期下游"开课计划"生成开课任务前须存在至少一个"是"

4. 开课计划

菜单位置：开课管理 → 专业开课 → 开课计划

适用角色：教务管理员、学院教务

目的：从已锁定的培养方案执行计划生成学期开课任务，维护教学任务基础信息与合班，批量生效后进入开课安排。

粒度：1门课 × 1个专业 × 1个入学批次 = 1条计划行（默认各自生成独立教学班）

4.1 主要功能

功能说明操作入口
生成开课任务弹窗从已锁定执行计划选未开课专业课生成计划工具栏 → 生成开课任务
修改教学任务抽屉维护选课类型、周次、开关、教室等列表 → 课程信息
合班合并同课多专业批次（仅未生效草稿可用）操作列 → 合班
一键合班工具栏按规则合并未生效草稿（不与已生效班合并）工具栏
生效批量将计划生效，进入开课安排工具栏 → 生效
删除删除计划行及关联班/名单（仅非已生效可删）工具栏 → 删除
预置人数查看学生预置人数（只读）列点击
操作记录查看字段变更历史列点击

4.2 状态流转

草稿→生效→ 已生效→退回→ 回退→再生效→ 已生效
  • 草稿：不可进入开课安排列表
  • 已生效：出现在开课安排，可进入下游
  • 回退：可修改后再生效；合班保留（需手动拆班）
  • 删除仅限草稿或回退状态

4.3 合班前提（须同时满足）

  1. 同开课学期、同课程号
  2. 学分、总学时、起止周、教学周数一致
  3. 教学任务开关一致（选课类型、是否排课/排场地/考勤/录入成绩/排考）
  4. 计划页仅未生效可合
合班副作用

人数/预留累加；清空分组、教师安排、场地类型与教室安排偏好；关联的任务安排重置为草稿。

4.4 修改教学任务 关键字段

字段编辑性说明
起止周可编辑打开"设置起止周"弹窗（支持全部/单周/双周/全不选模式）；保存后不被学期默认覆盖
计划总人数条件可编开放选课时手动填写；不开放选课+老生=预置人数（只读）；不开放选课+新生=招生计划（只读）
预留名额可编辑默认5，可改，计入名额上限
选课类型可编辑默认"不开放选课"
是否排课/排场地/考勤/录入成绩/排考可编辑排场地/考勤默认随学时（全为0→否，否则→是）；排课/录入成绩/排考默认"是"
教室属性 / 参考教室可编辑四学时各行独立设置（普通/计算机/专业教室）
Support历史只读始终取自特殊课程设置

5. 开课安排

菜单位置：开课管理 → 专业开课 → 开课安排

适用角色：教务管理员、学院教务、教师

目的：对计划已生效的教学班，分三步完成开课前期设置、课程班（合班/Support）、师资安排（教师/授课确认/共同授课），再批量生效进入开课名单。

1

开课前期设置

课程基础信息（含教室等）

行操作："设置"

2

课程班

合班 · Support管理

行操作："合班" / "Support管理"

3

师资安排

安排教师 · 授课确认 · 共同授课

行操作："安排教师" / "共同授课" / "授课确认"

生效门槛（须同时满足）
  • 分组结构与学时投递无致命错误
  • 分组人数上限合计 ≥ 计划总人数 且 ≤ 课程人数上限
  • 全部授课教师已确认（含代确认）；无教师不可生效
  • 学时投递合计不足 → 警示（确认后仍可生效）；超过 → 二次确认后可生效

5.1 步骤一：开课前期设置

点击行操作「设置」→ 打开"修改教学任务"抽屉，与开课计划共用同一套抽屉字段。在计划已生效且任务未生效时，主要可修改教室相关信息。

5.2 步骤二：课程班（合班 / Support）

合班

点击「合班」→ 打开合拆班穿梭抽屉，将待合并的专业批次移动到右侧已合并区。合班前提和副作用与开课计划一致。

Support 管理

点击「Support 管理」→ 弹窗维护Support学院（多选，不可选本开课单位），历史只读提示。

5.3 步骤三：师资安排

安排教师 → 进入分组工作台

分组工作台是沉浸式页面，左侧为分组信息：

  • 分组信息区：计划人数、课程人数上限、专业批次、Coordinator
  • 分组树：课程班名称 → 小组名称（可编辑）→ 人数上限 → 备注说明
  • 工具栏：分组（按组数/按人数）、重置、学时类型设置（全部合并/部分合并/分别安排）、复制（从历史学期）、安排教师

右侧有「课程班/小组学时详情」和「学生名单」两个Tab。在学时详情中配置各组的学时类型(L/T/P/O)、周次、周学时、教师、教室属性等。

授课确认

在步骤三点击「授课确认管理」→ 弹窗查看各教师确认进度，可代确认（选择"同意"或"不同意+需求反馈"）。

共同授课

点击「共同授课」→ 弹窗左侧已设置表/右侧可选表，添加共享教师的课号。

8. 开课清单

8.1 教师开课学时统计

菜单位置：开课管理 → 开课清单 → 教师开课学时统计

目的：按教师横向展示各学期授课学时（周学时×周次），支持三种统计维度。

统计维度说明

常见问题

Q：生成开课任务时提示"未设置默认展示学期"怎么办？

A：请先前往 开课管理 → 开课设置 → 开课时间设置，找到目标学期，将"默认展示学期"开关切换为"是"。全局仅允许一个"是"。

Q：为什么在开课安排中看不到某条开课记录？

A：请确认该条记录在开课计划中的生效状态为已生效。草稿或回退状态的计划不会出现在开课安排列表中。

Q：已生效的计划能否删除？

A：不能直接删除。需先从"开课安排"页面对该任务点击「退回」（填写退回说明），计划状态变为回退后，再回到开课计划页删除。注意：退回会清空分组和教师数据，合班会保留（需手动拆班）。

Q：合班后人数怎么算？

A：合并后各批次的人数/预留名额会累加到合班。但分组、教师安排、场地类型偏好会被清空，需重新配置。任务安排状态也会重置为草稿。

Q："撤回"和"退回"有什么区别？

A：撤回：任务回到草稿，但合班/分组/教师全部保留，仅学生小组分配被重置。退回（至计划）：计划状态变为回退，清空分组/教师，合班保留但不自动拆（需手动）。已生效任务不可退回。

Q：授课教师还没确认怎么办？

A：任务生效的门槛之一是"全部授课教师已确认"。可在步骤三点击「授课确认管理」进行代确认（教务端操作），或通知教师登录教师端页面自行确认。

Q：计划总人数可以修改吗？

A：取决于选课类型——开放选课时可以手动编辑计划总人数；不开放选课时，老生显示预置可修人数（只读），新生显示招生计划人数（只读）。可在"修改教学任务"抽屉中查看和修改。

Q：通识选修课（GE）开课怎么操作？

A：通识选修课开课模块目前仍在设计中。当前需使用"校选课程管理"维护GE/ME主数据池后，通过专业开课流程（开课计划→开课安排→开课名单）的扩展路径处理。详细流程待正式发布。
