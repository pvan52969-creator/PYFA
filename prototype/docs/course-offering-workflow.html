XMUM 开课管理 · 操作流程

主路径：准备 → 三类开课（计划 · 任务 · 名单）→ 开课清单 → 共同授课 → 排课/选课

准备 开课计划 任务安排 名单管理 汇总排课
阶段说明（对照当前原型）

阶段一 · 准备：维护开课学期；专业依赖已提交执行计划，通识选修需维护校选课程库。

阶段二 · 三类开课：专业 / 通识选修 / 特殊各自「计划提交 → 任务安排提交 → 名单管理」。专业含合分班；通识选修名单来自选课应用；特殊开课由教务手工维护名单。

阶段三 · 汇总排课：任务提交后纳入开课清单；共同授课维护设置同教师多课合排码；排课/选课应用消费数据。已移除独立「开课计划生成」「合分班管理」「开课明细安排」页。

数据粒度
计划按类型维护；任务提交后清单一门课一条
前置依赖
执行计划已提交 · 当前开课学期有效
