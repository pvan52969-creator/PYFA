## Context

See proposal.md — Why。原型侧栏「课表查询」分组已有「课表查询」（多 Tab 图形/列表课表）与「课表密度查询」（学生/教师密度矩阵）。空闲时间查询为第三入口，列表形态更接近密度页的「上筛选 + 下列表」，但结果粒度是 **按对象一行的空闲汇总**，不是密度矩阵。

可复用：

- 查询布局：`.schedule-query-card` / `.schedule-room-filter-grid` + `.srf-actions`（遵守一行最多 3 条件）
- 多选：密度页 `.density-ms` / `clo-multiselect` 模式
- 课表占用数据：现有排课演示 store / 时间课表行，用于算「已占用 → 取补集得空闲」
- 导出条：`.schedule-tt-export-bar` + `list-export-*`（注意结果卡 `padding: 0`，与 tt-query-page 一致避免上留白）

已确认产品决策：

1. 对象可混选（教师 / 学生 / 专业批次 / 场地）。
2. 筛选含周次区间、星期、节次、场地。
3. 一行一个对象。
4. 周次为区间（起=止即单周）。

## Goals / Non-Goals

**Goals:**

- 独立页面 + 侧栏入口，筛选与混选对象，按对象汇总空闲节次列表。
- 空闲 = 筛选宇宙（周次×星期×节次，及场地相关占用）减去该对象已占用。
- 演示数据可跑通查询 / 重置 / 导出。

**Non-Goals:**

- 不做图形化空闲课表栅格（本期仅列表）。
- 不计算「多人共同空闲」交集专表（用户可自行对比多行；若后续要「共同空闲」另开 change）。
- 不改课表查询 / 密度查询 / 排时间 / 排教室详情。
- 不接真实后端。

## Decisions

### 1. 独立 page-id：`schedule-free-time`

- **选择**：`data-page="schedule-free-time"` → `#page-schedule-free-time`，注册进 `SCHEDULE_PAGES` / `showPage` 分支。
- **理由**：与密度页并列，避免塞进课表查询 Tab 造成「查课表 vs 查空闲」混淆。
- **备选**：作为课表查询第七 Tab → 否决（用户点的是 nav-group 下新菜单）。

### 2. 筛选字段与对象选择器

第一行起按标准排布（示例，实现时可微调顺序但不超过一行 3 条件）：

| 条件 | 控件 |
|------|------|
| 学年学期 | select / 只读当前学期 |
| 周次起～止 | 一格内双 number（算 1 个条件） |
| 星期 | 多选 |
| 节次 | 多选（或按课表节次维护的节次列表） |
| 场地 | 多选教室（兼作筛选；选入「对象」时见下） |
| 教师 / 学生 / 专业批次 | 各类多选（可占多行） |

对象区：四类多选并存，查询时合并为对象列表；**至少选一类中的一个** 才允许出结果。

场地双重角色：

- 作为 **对象**：结果行 `type=room`，空闲 = 该教室在宇宙内无排课占用的节次。
- 作为 **筛选**（若保留独立「场地」条件）：当计算教师/学生/批次空闲时，仅把「占用且落在所选场地」视为忙，或仅用于教室对象子集——**首期简化**：场地多选 **只作为对象来源**（选中的教室进结果行）；若需「只关心某楼教室是否空」即勾选那些教室对象。避免同一控件既滤又选造成歧义。

若产品坚持「场地筛选 + 场地对象」分离：筛选用于收窄占用判定的教室集合，对象仍是人/批次；本期 tasks 采用「场地=可混选对象」，筛选栏星期/节次/周次为人与场地共用时间宇宙。

### 3. 空闲计算

```
universe = weeks[from..to] × selectedWeekdays × selectedPeriods
busy(object) = scheduled slots intersecting universe (by object type join)
free(object) = universe − busy(object)
```

展示：按星期分组，节次合并连续段，如 `周一 1-2,5-6；周二 3-4`。全忙 → `无空闲`。

专业批次：用该批次课表占用（与入学批次课表同源演示数据）。学生：挂批次或个人演示课表。教师：教师课表占用。场地：教室占用。

### 4. 列表列

| 列 | 说明 |
|----|------|
| 序号 | |
| 对象类型 | 教师 / 学生 / 专业批次 / 场地 |
| 对象 | 名称 + 次要标识（工号/学号/批次代码/教室名） |
| 周次范围 | 回显本次查询起止周 |
| 空闲节次 | 汇总文案，过长省略 + 悬停全文 |
| （可选）操作 | 本期可不做「查看课表」跳转，留扩展 |

### 5. 页面壳

- 使用 `page-list` + `schedule-query-card` + `schedule-card`（或 `schedule-timetable-wrap` 仅导出+表），**结果卡 padding:0**，导出条自带内边距（对齐 tt-query-page 留白修复）。
- 不必套 `schedule-tt-query-page` 全高 flex（无多 Tab）；普通 `page-list` 滚动即可。

## Risks / Trade-offs

- [混选对象多、宇宙大] → 原型限制演示对象数量；合并展示避免单元格爆炸。
- [场地角色歧义] → 首期场地仅作对象；若验收要「筛选」再加独立条件。
- [与真实教务「空闲」含考试/锁课] → 原型仅减已排课占用；文档 Non-Goal 写明。

## Open Questions

- 是否需要二期「共同空闲」一键交集行（当前多行人工对比即可）。
- 学生是否必须先选专业批次再级联（首期可扁平多选演示名单）。
