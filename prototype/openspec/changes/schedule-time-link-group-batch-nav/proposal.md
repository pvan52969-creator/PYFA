# Proposal

## Why

排时间详情左侧课程卡已展示「共同授课课号」与「上课批次」，但排课员看不到开课侧绑定的**联动组**（本组学时安排与共同授课课号下某组学时安排绑在一起、须同排不可拆），也无法从批次文案跳到「按批次排」核对合班多批次。缺少这两处入口，联动约束与批次合班信息都藏在开课或其它列表里，排时间现场容易拆散联动或漏看合班批次。

## What Changes

- 排时间详情侧栏课程卡：在「共同授课课号」**下方**增加「联动组」字段，展示该学时单元所属联动组组名；有联动时可点，弹出已有/复用的联动详情弹窗（只读查看）。
- 明确产品口径：开课侧设置的联动组表示跨课号学时安排绑定；排时间时对同联动组的学时**绑在一起排、不可拆开**（落格 / 改格 / 清除等同进同出）。
- 「上课批次」改为可点击（交互对齐授课教师 `sdc-teacher-link`）：跳转该批次「按批次排课」详情；合班多批次时每个批次各自可点。
- **范围仅排时间侧**（`#page-schedule-time-detail` / `scheduleDetailPhase === 'time'`）。不改排教室侧栏字段、菜单与交互。

## Capabilities

### New Capabilities

- `schedule-time-link-group-batch-nav`: 排时间侧栏联动组展示/详情入口、联动学时同排不可拆、上课批次跳转按批次排

### Modified Capabilities

- （无）现有 specs（demo 前缀码、联合 GE 对象、学期安排导出）不覆盖本行为

## Impact

- `app.js`：`renderScheduleDetailCourseList` 时间分支字段 HTML；批次链接辅助函数；解析当前学时单元 → 联动组；落格/改格/清除路径对联动组成员做同排约束；复用开课侧 `openSharedTeachingSlotLinkViewModal`（或等价只读详情）。
- 可能微调 `styles.css`（链接样式复用 `sdc-teacher-link`，尽量不加新视觉体系）。
- 依赖开课侧联动组数据与查看弹窗；若工作区暂缺该能力，实现前须先对齐/补齐只读查询与弹窗，本 change 不扩展「建立/解除联动」产品范围。
- 不改排教室 clone 页专属交互；改时间侧模板时注意 clone 副作用，教室侧不加联动组/批次跳转除非另开需求。
