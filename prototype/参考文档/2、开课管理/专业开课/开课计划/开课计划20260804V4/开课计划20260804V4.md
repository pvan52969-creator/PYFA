## 1. 文档目的

规范专业开课**计划层**能力：从已锁定执行计划生成学期开课任务、维护教学任务基础信息与合班（未生效时）、批量**生效**后进入开课安排。

## 2. 功能概述

- 粒度：**1 门课 × 1 个专业 × 1 个入学批次 = 1 条计划行**（默认各生成独立教学班）。
- 生成**默认不合班**；可选用「生成并自动合班」或工具栏「一键合班」（仅未生效草稿互合）。
- **计划已生效**后：本页合班锁定；编辑抽屉以教室类字段为主（直至开课安排生效后整抽屉只读）；已生效计划的合班改在「开课安排」完成。
- 唯一约束：同学期下同一门课 + 同一专业 + 同一批次仅一条计划行。

## 3. 角色与权限（原型约定）

| 角色 | 能力 |
|------|------|
| 教务 | 生成、编辑、合班（未生效）、生效、删除、查看预置人数与操作记录 |
| 学院 | 视权限可参与合班等（与正式权限模型对齐时再细化） |

## 7. 业务规则

### 7.1 生成前置

开课时间设置中须有「默认展示学期 = 是」；候选来自**已提交/锁定执行计划**中本学期未开课且未延期的专业课。

### 7.2 生成策略

每条候选独立建班；默认生成不合班；可选用「生成并自动合班」或工具栏「一键合班」（仅未生效草稿互合，不与已生效班合并）。

### 7.3 选课类型

开放选课课程的名单后续由选课应用生成；不开放选课在开课名单维护。生成默认「不开放选课」。

### 7.4 Support历史

只读，始终取自特殊课程设置。

### 7.5 删除（硬规则）

仅**非已生效**计划可删（草稿/回退）。已生效须先经开课安排「退回」变为回退后才可删。删除后可重新生成。

### 7.6 学时分类与「是否排场地 / 是否考勤」

适用于抽屉「修改教学任务」中只读**学时分类**与**是否排场地**、**是否考勤（预留）**。开课安排侧共用同一套抽屉与规则。

| 规则项 | 说明 |
|--------|------|
| 学时来源 | 理论/辅导/实践/其他只读，取自课程库 / 培养方案（同课号对齐） |
| 「学时全为 0」 | 四类学时之和 = 0 |
| 默认写入时机 | 仅当排场地/考勤**尚无值**时写入；已有值不因学时展示刷新而覆盖 |
| 学时全为 0 | 排场地=否；考勤=否 |
| 学时不全为 0 | 排场地=是；考勤=是 |
| 手工可改 | 用户可改为是/否；手工值优先 |
| 不联动 | 是否排课 / 录入成绩 / 排考 不按学时默认 |

### 7.7 计划总人数三口径

| 条件 | 编辑性 | 取值 |
|------|--------|------|
| 不开放选课 + 老生 | 只读 | 预置可修人数 |
| 不开放选课 + 新生 | 只读 | 招生计划人数 |
| 开放选课 | 可编辑；保存必填且 ≥0 | 用户手工值；切至开放选课时可清预置名单依赖 |

### 7.8 教学任务开关默认值（字段无值时）

| 字段 | 默认 |
|------|------|
| 选课类型 | 不开放选课 |
| 是否排课 | 是 |
| 是否录入成绩 | 是 |
| 是否排考 | 是 |
| 是否排场地 / 是否考勤 | 见 §7.6 |

### 7.9 抽屉保存校验与起止周生命周期

保存「修改教学任务」须满足：

1. 起止周非空，且周次落在学期教学周内  
2. 预留名额已填且 ≥ 0  
3. 开放选课时计划总人数已填且 ≥ 0  
4. 计划已生效且任务未生效：仅允许保存教室类可改项；任务已生效：整抽屉只读不可保存业务变更  

起止周：生成时默认学期教学周 1–N；用户明确调整并保存后，后续打开/保存**不得**静默重置为学期默认。

### 7.10 合班前提与副作用

**前提（须同时满足）：**

1. 同开课学期、同课程号  
2. 学分、总学时、起止周、教学周数一致  
3. 教学任务开关一致：选课类型、是否排课/排场地/考勤/录入成绩/排考  
4. 计划页仅未生效可合；安排页须计划已生效且任务未生效  

**成功合班后副作用（行合班 / 一键合班 / 生成并自动合班）：**

- 计划人数与预留按合入批次分摊后累加到合班  
- 清空分组、教师安排、场地类型与教室安排偏好  
- 若已进入任务安排：任务安排状态重置为未生效草稿  
- 零学时班与有学时班若因默认排场地/考勤不一致，须先统一再合班  

### 7.11 退回计划时合班保留

从开课安排「退回」至计划：计划状态→回退；清空分组/教师/任务安排侧数据；**保留合班结构**（不自动拆回单批次），须在合拆班中手动拆分。

## 8. 状态流转（计划层）

```
草稿 ──生效──► 已生效 ──开课安排「退回」──► 回退 ──再生效──► 已生效
  │                    （保留合班；清分组/教师；须手动拆班）
  └──删除──►（仅非已生效；移除后可再生成）
```

| UI 文案 | 内部语义（原型） | 下游 |
|---------|------------------|------|
| 草稿 | `submitStatus=draft` | 不可进开课安排列表 |
| 已生效 | `submitStatus=submitted` | 出现在开课安排；`schedulingVisible=true` |
| 回退 | `submitStatus=reverted` | 可改后再生效；合班仍保留 |
