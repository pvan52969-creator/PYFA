# Proposal

## Why

排时间侧落点冲突弹窗目前只展示纯文案（如「与 CDX101 … 教师冲突」），管理员无法从弹窗直接定位对端课去微调。需要在弹窗内提供「去调整」入口：新页签打开对端课课表；并按管理员层级（学校 / 学院 / 专业负责人）校验是否有权调整该冲突课。

## What Changes

- 排时间侧「排课冲突提醒」弹窗中，教师 / 学生对端课展示可操作入口（课名可点或「去调整」按钮）。
- 点击后：有权限则新页签打开对端课排课详情并选中该课（可定位冲突节次）；无权限则弹窗提示「当前冲突课程调整权限不足」类文案，不跳转。
- 权限规则（课程带所属专业 `programmeKey`，学院由专业映射）：
  - **学校负责人**：覆盖全部课程
  - **学院负责人**：覆盖本学院下全部专业课程
  - **专业负责人**：仅覆盖所辖专业（`programmeKey` 一一匹配）
- 原型增加排课管理员演示身份切换（学校 / 学院 / 专业 + 对应学院或专业范围），便于验收三种权限。
- **不改**：排教室侧独立菜单与交互；冲突检测算法本身；强制继续排课逻辑。

## Capabilities

### New Capabilities

- `schedule-conflict-peer-adjust-jump`: 落点冲突弹窗跳转对端课微调，及学校/学院/专业负责人覆盖范围校验。

### Modified Capabilities

- （无）

## Impact

- 主要改动：`app.js` 冲突弹窗渲染与结构化对端引用、深链跳转、演示管理员身份；`index.html` 弹窗/演示身份 UI（若需）。
- 复用既有 `launchScheduleDetailTab` / `buildScheduleDetailLaunchUrl` 新页签能力；可能扩展深链参数以聚焦 `taskId` / 冲突节次。
- 受影响：排时间侧 `#modal-schedule-place-conflict`；排教室侧不纳入本期。
