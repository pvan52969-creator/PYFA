阶段说明（对照当前原型侧栏）

开课设置：开课时间设置、校选课程管理、特殊课程设置；专业开课依赖已提交执行计划；通识选修依赖校选课程库。

专业开课：开课计划 → 开课安排 → 授课确认 → 开课名单。未完成授课确认，不可提交到开课名单。

通识选修（设计中）：通识选修计划 → 通识选修开课 → 授课确认 → 通识选修名单；同样以授课确认为名单前提。
