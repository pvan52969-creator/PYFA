## 1. 文档目的

规范专业开课**任务安排层**：对计划已生效的教学班，分三步完成开课前期设置、课程班（合班 · Support）、师资安排（教师 · 授课确认 · 共同授课），再批量**生效**，进入开课名单与下游排课/开课清单。

## 2. 功能概述

### 2.1 三步引导（样式二）

| 步骤 | 名称 | 聚焦能力 |
|------|------|----------|
| 1 | 开课前期设置 | 课程基础信息（含教室等） |
| 2 | 课程班 | 合班 · Support |
| 3 | 师资安排 | 安排教师 · 授课确认 · 共同授课 |

各步骤均可执行：生效 / 撤回 / 退回；步骤间提供上一步 / 下一步。

### 2.2 与计划层关系

- 列表仅展示**计划已生效**的专业教学班。
- **任务安排生效**与计划生效为双层状态，相互独立。
- 合班 ≠ 分组：合班合并专业批次；分组在安排教师工作台由学院完成。

## 3. 角色与权限（原型约定）

| 角色 | 能力 |
|------|------|
| 教务 | 设置、合班、Support、退回计划、生效/撤回、查看操作记录 |
| 学院 | 安排教师、分组、学时投递、Support 管理（按权限） |
| 教师 | 授课确认（教师端，门槛之一；可由教务代确认） |

## 4. 界面说明

### 4.1 筛选区

学年学期｜课程号/名称｜生效状态（已生效/草稿/回退）｜共同授课状态（Y/N）｜授课确认（已确认/未确认/无教师）｜查询｜重置

### 4.2 工具栏（各步）

生效｜撤回｜退回｜导入（占位）｜上一步 / 下一步（按步骤）

### 4.3 列表共性列

勾选｜开课详情(+/-)｜开课状态｜生效状态｜授课确认｜开课学期｜Course Code｜Course Name｜Classification｜开课单位｜选课类型｜Credits｜起止周｜Prog. Batch｜计划总人数｜Lecturer｜Coordinator｜共同授课状态｜共同授课课号｜操作记录

步骤差异：

- 步骤 2：Support（历史 + 管理）
- 步骤 3：授课确认「管理」；行操作含安排教师、共同授课
- 步骤 1：行操作「设置」

### 4.4 展开子表「开课任务安排」

序号｜课程班/小组｜学时类型｜起止周｜周学时｜总学时｜教师｜同时多组授课｜教室属性｜参考教室偏好｜前往安排/修改

### 4.5 关联界面

| 界面 | 用途 |
|------|------|
| 修改教学任务抽屉 | 步骤 1「设置」；计划已生效且任务未生效时以教室为主 |
| 合拆班抽屉 | 步骤 2 合班 |
| 分组工作台 | 安排教师 / 学时投递 / Coordinator |
| Support 管理 | 维护 Support 学院 |
| 授课确认管理 | 教师确认进度与代确认 |
| 共同授课设置 | 共享教师后的共同授课标记 |
| 退回说明 | 退回计划时必填 / 查看 |

## 7. 业务规则

### 7.1 生效门槛与学时矩阵

须同时满足：

1. 分组结构与学时投递无致命错误（见下表）  
2. **分组人数上限**（有分组时）：合计不得低于计划总人数，且不得超过课程人数上限（计划总人数+预留）  
3. **全部授课教师已确认**（含代确认）；无教师不可生效  
4. **零学时班默认不豁免**：学时分类全为 0 时，若仍要求教师安排完整，缺教师则硬拦截  

| 条件 | 行为 |
|------|------|
| 分组结构错误 / 非法学时投递等致命错误 | **硬拦截**，不可生效 |
| 各组上限合计 &lt; 计划总人数，或 &gt; 课程人数上限 | **硬拦截** |
| 学时投递合计不足计划学时 | **警示**，确认后仍可生效 |
| 学时投递合计超过计划学时 | **二次确认**后可生效 |
| 无任课教师，或存在未确认教师 | **硬拦截** |

生效后：锁定合分班 / 分组 / 教师；开放选课名单由选课应用生成；不开放选课进入开课名单维护。

### 7.2 撤回 vs 退回（副作用总表）

| 操作 | 计划状态 | 任务状态 | 合班 | 分组/教师 | 学生名单分组 |
|------|----------|----------|------|-----------|--------------|
| 撤回 | 仍为已生效 | → 草稿 | **保留** | **保留** | **重置** |
| 退回（至计划） | → 回退 | 清空安排 | **保留**（不自动拆） | **清空** | 清空安排侧 |
| 名单页退回安排 | 仍为已生效 | → 草稿 | 保留 | 可再改安排 | **名单可保留**（见开课名单 PRD） |

- 撤回：已有排课结果则**禁止**，须先撤销排课。  
- 退回：须填退回说明；**已生效任务不可退回**。  
- 退回后合班须在合拆班中手动拆分。

### 7.3 特殊课程默认

新建或教室/Support 仍为系统默认时，带出特殊课程设置；Support历史始终按课号同步。生成时与打开抽屉时 `onlyIfEmpty` 时机以实现为准（生成可全量带出，打开抽屉仅空字段补齐）。

### 7.4 共同授课

须先有任课教师；与其他课程共享教师后标记共同授课状态与课号。

### 7.5 学时分类与排场地/考勤（共用计划规则）

与《开课计划》V4 **§7.6** 完全一致：学时只读；无值时学时全 0→排场地/考勤=否，否则=是；可手工改；排课/成绩/排考不按学时默认；合班开关须一致。

### 7.6 合班前提（安排侧）

同开课计划 V4 **§7.10**：同学期/课号、学分·总学时·起止周一致，教学任务开关一致；任务已生效后不可合班。合班副作用同 §7.10（清分组/教师/教室偏好，任务状态重置）。

### 7.7 修改教学任务（交叉引用）

计划总人数三口径、开关默认、保存校验、起止周生命周期见开课计划 V4 **§7.7–7.9**。本页字段表备注须与之一致。

## 8. 状态流转（任务安排层）

```
计划已生效 + 任务草稿
        │ 设置 → 合班/Support → 师资/授课确认
        ▼
任务「生效」──► 任务已生效 ──► 开课名单可见
        │                │
        │                ├──撤回──► 任务草稿（合班/分组/教师保留，名单分组重置）
        │                └──名单页退回安排──► 任务草稿（名单可保留）
        └──退回──► 计划「回退」+ 清分组/教师（合班保留，须手动拆）
```

另：授课确认进度（已确认 / 未确认 / 无教师）为生效门槛维度，不等于任务生效状态本身。
