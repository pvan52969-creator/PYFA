# 厦大马来分校本科教务系统——ME 借用他专业开课方案确认

> 文档性质：客户确认稿（非正式需求定稿）  
> 日期：2026-08-27  
> 涉及菜单：开课管理 → 选修开课（ME开课）／专业开课／课程班  
> 口径：已对照现行原型的标「已明确」；需客户拍板的标「待确认」。未讨论事项不写成已定规则。

## 1. 请客户先拍板的一句话

借用他专业已经开出的课作为本专业选修时，借方学生是：

- **方案 A：进对方已经开好的组**（同一堂课，只增加选修名额，名单等选课后写入）
- **方案 B：在对方课程班上另开一个选修组**（单独一组，名单等选课后写入）

不定这一句，后面的开课任务、名单、教室、教师学时都会各走各的。

## 2. 背景（已明确对照原型）

客户场景：学院从校选 ME 里选「别人专业开的课」，作为本专业选修。弹窗里这类课状态为 **Pending**（对方专业开课计划里已有同课号，且校选状态正常）。

现行原型点确认后：

- 在**选修开课**再新建一条开课任务（来源 ME、选课方式为开放选课）；
- **不会**并入对方专业开课里已有的那条课程班；
- 两边课号相同，但是两个班。教师、周次、学时要再对齐，Teaching Load 也容易重复计算。

客户口头意向：不要另起一套班，而是沿用对方专业开课那个班；选修侧看到的课程班与对方几乎一致，只是「这一部分学生」的名单由后续选修构成。

## 3. 两个「Group」不要混用

| 说法 | 含义 | 说明 |
|------|------|------|
| MAT/PHY 课表里的 Group1 / Group2 | 课表分类 | Group1 = 本专业自己开；Group2 = 借用他专业课。**不是**教学班里的小组 |
| 系统里的 Group1 / Group2 | 同一课程班下的教学组 | 分组、名单、排课、学时都按这个组走 |

本文「方案 A / 方案 B」里的「组」指**系统教学组**。

## 4. 三种做法对照

| 对比项 | 现状：选修再开一条班 | 方案 A：挂靠对方班，加选修名额（进原组） | 方案 B：挂靠对方班，另插一个选修组 |
|--------|----------------------|------------------------------------------|-------------------------------------|
| 课程班数量 | 两个班（专业一条 + 选修一条） | **一个班**（对方那条） | **一个班**（对方那条，多一个组） |
| 选修开课安排里看到什么 | 自己新建的那条任务 | 对方那条班，标明「借用」 | 对方那条班，多显示一个选修组 |
| 学生坐哪里 | 选修班自己的组（默认同对方不是同一堂） | 进对方已有组，同一堂课 | 进新插的选修组；若同堂须标明同时授课 |
| 选课方式 | 整条选修班 = 开放选课 | 须在班上区分：专业学生不开放、选修名额开放（**现模型做不到，要改**） | 须在**组**上区分开放/不开放（**现模型做不到，要改**） |
| 名单 | 选修班名单等选课 | 同一组里：专业名单按专业规则；选修名额后到 | 原组走专业名单；新组名单后到 |
| 教师 / 周次 / 教室 | 两套，要对齐或做共同授课 | 沿用对方，由开课专业维护 | 默认同堂则沿用对方；不同堂就是第二堂课 |
| 教师学时（Teaching Load） | 两套安排，容易计两次 | 同一堂，计一次 | 同堂必须「只计一次」；否则按两组计 |
| 课程班汇总 | 可能两行（两个班） | 一行 | 一行 |
| 谁说了算 | 各管各的班 | 开课专业管班；借方只申请名额 | 开课专业管班；借方申请插组 |
| 对方已提交 / 已生效后 | 选修仍可另开班 | 加名额是否还允许，**待确认** | 插组是否还允许，**待确认** |
| 改动大小 | 已做成 | 中（名额 / 名单来源要拆开） | 较大（组级选课方式 + 权限 + 学时） |

## 5. 可能存在的问题

### 5.1 两种方案都会碰到

1. **选课方式现在是「整班」字段**  
   专业开课班通常是不开放选课；ME 要开放选课。一个班不能同时两种，除非改成「名额级」或「组级」。

2. **所有权**  
   班在开课专业手里。借方能否改人数、教师、教室？加名额 / 插组要不要对方同意？**待确认**。

3. **容量和教室**  
   对方按本专业人数开的班。多出名额或多一组，教室是否够、谁批？**待确认**。

4. **停课 / 回退**  
   对方停课，借用是否一并取消？借方取消借用，是只撤名额/组，还是动整班？**待确认**。

5. **多个学院同时借同一门**（例如 MAT、PHY 都借 CST 的课）  
   是共用一份选修名额/一个选修组，还是各借各的？**待确认**。

6. **对方还没排好教师和组时**  
   Pending 只要求对方计划里已有同课号，不要求已经排好课。此时「几乎一致」没有可复制的安排。

### 5.2 方案 A 特有

- 专业学生和选修学生可能坐进**同一组**。组容量、评教、考勤是否按一组算，**待确认**。
- 专业名单若已预置/已分配，后到的选修学生如何插入该组，**待确认**。

### 5.3 方案 B 特有

- 新组如果不同时间上课，就不是「和对方班几乎一致」，而是第二堂课。
- 新组如果同时上课，Teaching Load 必须只计一次，否则会再出现「主表与明细对不上」。
- 已生效后再插组，等于改已经排好的班，教师确认、排课是否要重做，**待确认**。

### 5.4 现状（另开一条班）特有

- 课号相同、班却是两套，客户已觉得别扭。
- 要靠共同授课 / 联动才能「一起上」；默认并不会自动并班。
- 课程班汇总可能出现两行。

## 7. 从系统现状看的倾向（不是已定结论）

- 若学生与对方**同一堂课、同一教室、同一教师**：方案 A 更贴「课程班几乎一致」，改动也比插组小。这时不要叫「插一个组」。
- 若必须**单独一组、单独名单、甚至可以不同时间**：走方案 B，并必须同时定第 6、10 题。
- **不建议**继续把「选修再开一个几乎一样的独立班」当作借用 ME 的默认做法；共同授课留给「有的周次合堂、有的周次分开」那种，不应当成借用的常规路径。
