# Spec Delta

## Purpose

约定调课申请抽屉内联动组「拆组」确认提示，以及目标节次下拉对学生/教师/场地冲突标记的展示规则，避免误操作与冲突类型混淆。

## ADDED Requirements

### Requirement: 拆组前确认不可再合并

系统 MUST 在用户于调课申请抽屉左侧课节列表点击「拆组」时，先展示确认弹窗，文案 MUST 明确告知：该课堂拆组提交通过后无法通过再次调课合并。用户确认后系统 MUST 才执行拆组；用户取消后系统 MUST NOT 改变联动组拆合状态。系统 MUST NOT 在点击「合并组」时展示本条拆组确认文案。

#### Scenario: 确认后拆组

- **WHEN** 用户点击某联动组行的「拆组」并在弹窗中确认
- **THEN** 该联动组按现有规则拆开展示，可按课勾选
- **AND** 弹窗提示包含「提交通过后无法通过再次调课合并」含义

#### Scenario: 取消则不拆组

- **WHEN** 用户点击「拆组」但在弹窗中取消
- **THEN** 联动组保持拆组前的合并展示状态

#### Scenario: 合并组不走拆组确认

- **WHEN** 用户点击已拆开联动组的「合并组」
- **THEN** 系统不展示本条拆组不可合并确认文案
- **AND** 合并仍遵循既有规则（含已通过拆开不可合并的拦截）

### Requirement: 目标节次冲突标记分型且最多两个

系统 MUST 在调课申请抽屉右侧目标节次下拉选项上，对学生冲突与教师冲突使用现有冲突标记（⚠）；对场地冲突使用与之视觉不同的新标记。同一选项同时存在的标记数量 MUST NOT 超过 2 个：学生与/或教师冲突合并为至多一个师生类标记；若另有场地冲突，再叠加场地标记。无冲突时 MUST NOT 显示冲突标记。标记的 title/aria-label MUST 反映实际命中的冲突类型（可多项并列说明）。

#### Scenario: 仅师生冲突显示 ⚠

- **WHEN** 某目标节次存在学生冲突和/或教师冲突，且无场地冲突
- **THEN** 该选项仅显示一个 ⚠ 标记
- **AND** 标记说明包含对应的「学生冲突」和/或「教师冲突」

#### Scenario: 仅场地冲突显示新标记

- **WHEN** 某目标节次仅存在场地冲突
- **THEN** 该选项显示场地冲突专用新标记
- **AND** MUST NOT 单独用 ⚠ 表示该场地冲突

#### Scenario: 师生与场地并存最多两个标记

- **WHEN** 某目标节次同时存在学生或教师冲突，以及场地冲突
- **THEN** 该选项同时显示 ⚠ 与场地新标记
- **AND** 标记总数为 2
- **AND** 即使学生与教师同时冲突，仍只占一个 ⚠ 名额

#### Scenario: 无冲突无标记

- **WHEN** 某目标节次探测结果无学生、教师、场地冲突
- **THEN** 该选项不显示冲突标记
