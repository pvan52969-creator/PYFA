## 2.2 系统需求（模块摘要）

### 2.2.1 方案版本管理（已确认）

| 项目 | 内容 |
|------|------|
| 列表字段 | 勾选、培养方案版本、审批状态、专业代码、学制、版本、开始/截止批次、授予学位、引用情况、操作 |
| 检索 | 专业、版本 |
| 批量操作 | 提交审批（draft/rejected）、版本导出（模板待确认） |
| 批次链 | 上一版本截止 = 下一版本开始的前一批次；当前有效版本 endBatch 为空 |

**版本编辑三 TAB：** TAB1 课程分类 · TAB2 课程设置（General/CLO/SLT）· TAB3 方案进程表

**信息条：** 专业、版本、开始/截止批次、学制、授予学位（**不含**毕业总学分）

**TAB1 chips：** 必修合计、选修合计、毕业总学分（`sum-total`）

**保存：** `modal-save-version` 二次确认 → 写入 Store → 返回来源列表

---

### 2.2.1.2 版本审批（已确认）

| 项目 | 内容 |
|------|------|
| 列表字段 | 勾选、培养方案、Status、Stage、专业、开始批次、**总学分**、提交人、提交时间、操作 |
| Tab | Pending / In Progress / History |
| 总学分取值 | `VERSION_CONTENT_STORE` 分类树一级最低学分合计（同 TAB1 毕业总学分） |
| 审批节点 | Programme Office → Academic Affairs → Senate |
| 决策 | Approve / Reject / Update Required |

---

### 2.2.1.3 版本查询（已确认）

只读查看 approved 版本；过滤：专业、版本、开始批次。

---

### 2.2.2 方案版本变更（已确认）

**申请：** 选 approved 版本 → 复制到 `CHANGE_CONTENT_STORE` → 三 TAB 编辑 → 提交

**审核列表总学分：** `CHANGE_CONTENT_STORE` 或目标版本快照的毕业总学分

**影响规则：** 审批通过覆盖 `VERSION_CONTENT_STORE`；**已生成专业批次执行计划不受影响**；未生成批次新建时引用最新版本

---

### 2.2.3 专业批次执行计划（已确认）

| 项目 | 内容 |
|------|------|
| 列表字段 | 勾选、专业代码、专业、专业批次、学院、入学批次、**总学分**、开课状态、是否提交、操作 |
| 数据隔离 | 每批次 `EXEC_CONTENT_STORE[planId]` 独立深拷贝；编辑不回写 `VERSION_CONTENT_STORE` |
| 总学分取值 | 当前批次 `EXEC_CONTENT_STORE` 分类树毕业总学分 |
| 生成规则 | 专业 + 入学批次 → 自动匹配 approved 版本 → 独立副本 |
| 操作 | 生成、编辑、保存（确认返回）、提交、撤回、删除 |

**说明条（列表页）：** 各批次独立；不回写方案版本管理；方案版本变更不影响已生成副本

## 附录 A：核心数据实体

| 实体 | 说明 |
|------|------|
| VERSIONS | 版本主表 draft/pending/approved/rejected |
| VERSION_CONTENT_STORE | 版本方案内容 |
| EXEC_CONTENT_STORE | **各批次执行计划独立副本** |
| CHANGE_CONTENT_STORE | 变更工作区内容 |
| EXEC_PLANS | 执行计划元数据 |
| APPROVAL_QUEUE / CHANGE_APPLICATIONS | 审批实例 |

---

## 附录 B：数据隔离规则

| 场景 | 写入 | 不影响 |
|------|------|--------|
| 编辑方案版本保存 | VERSION_CONTENT_STORE | 已有 EXEC_CONTENT_STORE |
| 编辑执行计划保存 | EXEC_CONTENT_STORE[planId] | VERSION_CONTENT_STORE、其他 planId |
| 方案版本变更通过 | VERSION_CONTENT_STORE | 已生成 EXEC_CONTENT_STORE |
| 新建执行计划 | 新建 EXEC_CONTENT_STORE | 引用当时版本快照，之后独立 |

## 附录 C：总学分取值

- **规则：** 一级分类最低学分之和 = TAB1「毕业总学分」chip
- **审批/变更审核/执行计划列表：** 分别从对应 Store 动态计算
- **顶栏 info-strip：** 不展示毕业总学分
