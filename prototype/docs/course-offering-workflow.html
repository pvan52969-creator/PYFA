阶段说明（对照当前原型侧栏）

开课设置：维护开课学期与授课确认截止日期；专业开课依赖已提交执行计划；通识选修依赖校选课程库。

专业开课（主路径）：开课计划（生成/合分班/提交）→ 开课安排（课程班 · Support · 师资）→ 授课确认（管理端下发 / 教师确认或代确认）→ 开课名单（预置、分组、一键分配）。

通识 / 特殊（设计中）：通识为「计划 → 开课 → 名单」；特殊为「计划 → 任务安排 → 名单」，与专业并行汇入开课清单。

开课清单（调整中）：汇总已提交任务；维护共同授课；可查看教师学时统计与名单变更日志；数据供排课/选课消费。已移除独立「开课计划生成」「合分班管理」「开课明细安排」页。
