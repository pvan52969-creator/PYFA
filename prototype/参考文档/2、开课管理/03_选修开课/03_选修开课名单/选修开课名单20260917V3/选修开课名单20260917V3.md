## 1. 文档概述

### 1.1 文档目的

明确选修开课名单统计、查询、列表、退回、导出、人数抽屉与名单分组工作台（含选修隐藏规则），供研发/测试统一依据。

### 1.2 填写口径

已明确 / 未确认；开放选课默认名单由选课应用生成。

### 1.3 建设背景

安排生效后查看/维护通识选修名单；可退回草稿；手动添加学生可保留。

## 2. 菜单与功能范围

### 2.1 纳入

- 统计卡 GE/ME；查询（含更多）；列表；退回；导出；人数抽屉；管理名单（学生 Tab）

### 2.2 非目标

- 选课应用报名算法；专业开课名单整菜单
- **预置名单 / 一键分配**（选修强制隐藏，见 BR010）

### 2.3 与专业开课名单差异

| 点 | 选修 | 专业 |
|----|------|------|
| 默认名单 | 选课应用 | 预置名单（必修） |
| 预置 / 一键分配 | **无** | 有（有组时） |
| 列表列 | 无共同授课列；有课程类型 | 有选课类型、Prog. Batch、共同授课等 |
| 退回 hint | 选课名单不保留；手动保留 | 预置+手动保留 |
| 统计 | GE 按部门×学分门数；ME Quota | 不同构 |

### 2.4 退回 vs 安排页撤回

| 项 | 名单页「退回」 | 安排页「撤回」 |
|----|----------------|----------------|
| 入口 | 本页工具栏 | 安排页工具栏 |
| 结果态 | 回草稿（可再改再生效） | 已生效→草稿 |
| 授课确认 | 保持 | 保持 |
| 名单 | 选课名单不保留；手动添加仍保留 | 课程组分配重置 |
| 成功提示 | 前往「选修开课安排」继续改 | — |

## 4. 界面说明

- 列表随 **GE/ME 统计 Tab** 过滤。
- 退回仅勾选**已生效**可点；无已生效 tip：`仅可退回开课安排已生效的任务；请先在「选修开课安排」提交生效，或勾选已生效项`
- 管理名单未生效 tip：`开课安排尚未生效，暂不可管理名单。请先在「选修开课安排」提交生效。`
- 未生效点人数空态：`开课安排尚未生效，尚未推送到选课应用，暂无学生名单`
