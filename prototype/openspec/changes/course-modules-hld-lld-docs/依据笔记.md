日期：2026-08-07  
来源：当前原型（index.html / app.js）、参考文档下最新需求、操作流程图。

## 跨模块约束

1. 主链路：开课时间设置 → 开课计划 → 开课安排 →（授课确认齐套后）任务生效 → 开课名单。
2. 未完成授课确认不可将开课安排任务生效；名单页可见范围为「计划已生效且任务已生效」。名单页无独立「提交名单」按钮；流程图「提交到开课名单」语义对齐为「不可跳过确认而进入名单维护阶段」。
3. 授课确认管理 / 教师端入口在「开课清单」侧栏；安排页与分组工作台亦有确认相关入口。
4. 安排「撤回」与名单「退回安排」语义不同：撤回会重置学生小组分配；退回安排可保留名单（以需求/原型为准）。
