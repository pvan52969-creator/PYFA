## Why

开课管理侧栏中「开课设置」与「专业开课」相关页面已有原型与需求文档，但缺少可复用的**概要设计 / 详细设计**模板，也缺少按菜单归档的设计文档，不利于评审对齐与后续开发交接。

## What Changes

- 新增两份可复用模板（中文为主，尽量少用英文；**md + docx**）：
  - 概要设计文档模板
  - 详细设计文档模板
- 基于上述模板，**按二级菜单分别建文件夹**，每个菜单各出 **概要设计 + 详细设计**（共 6 菜单 × 2 = 12 份文档；每份同时提供 **md + docx**）：
  - 开课设置：开课时间设置、校选课程管理、特殊课程设置
  - 专业开课：开课计划、开课安排、开课名单
- 文档内容以当前原型与已有需求/流程图为已知来源；未知规则标明「待确认」，不编造学校政策或接口字段
- **不改**业务代码、页面交互与数据行为

## Impact

- 文档目录：`参考文档/0、模板/`（模板）；各二级菜单目录下新增设计文档版本文件夹（见 design）
- 无运行时 / API / 依赖变更
- 与现有「二级菜单需求文档版本规范」并存：本变更产出的是**设计文档**，不覆盖既有 PRD 版本文件夹
