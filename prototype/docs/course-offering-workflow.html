XMUM 开课管理 · 操作流程

参考教务系统：正常开课、合班、分班、合分班。主路径：时间设置 → 生成计划 → 合分班 → 明细安排（学生 / 教师 / 地点 / 周次）

准备 生成计划 合分班 明细安排
三阶段说明（对照参考视频）

阶段一 · 生成开课计划：依据已提交的专业批次执行计划，按「专业批次 + 课程号」生成明细行。必修课、专业选修、MPU、大学课等归入专业开课；General Elective 归入通识选修开课；挂科重修等额外需求在其他开课人工维护。仅当前「开课学期 = 是」的学年学期可生成。

阶段二 · 合分班：在同一课程号下对计划行操作。正常：一行一班；合班：多行合并为一个教学班；分班：拆成多个教学班；合分班：先合后分，灵活调整容量与批次组合。

阶段三 · 开课明细：教学班分组确定后，为每个班维护学生名单、任课教师、上课地点与上课周次，完成本学期排课前置数据。

数据粒度
计划行 = 1 专业批次 × 1 课程号；教学班 = 合分班后的上课班组
前置依赖
培养方案执行计划已提交 · 开课时间窗口内操作
