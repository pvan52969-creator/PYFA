# 调课管理 · 教室开放时间设置改动方案

> 文档性质：代码改动方案（需求文档，供实现前对齐）  
> 适用范围：调课管理 → **教室开放时间设置**（新菜单，侧栏第一项）；列表提示：我的调课申请 / 调课申请审批 / 调课申请管理；审批详情拦审批  
> 关联代码：`prototype/index.html`、`prototype/app.js`、`prototype/styles.css`  
> 状态：**已按确认口径实现**

---

## 0. 已确认口径

| 项 | 结论 |
| --- | --- |
| 菜单位置 | 调课管理下**第一条**二级菜单，排在「调课原因类型」之前 |
| 维护对象 | **具体教室**；先按**场地类型**分区，再按范围勾选教室批量**追加**开放时间段 |
| 开放时间粒度 | **按学期**；范围字段为**日期范围** + 星期 + 节次，周次可选 |
| 同一教室多段 | **追加多段**，每段可单独修改 / 删除（不覆盖整学期） |
| 未维护教室 | **不限制**（全时段可申请） |
| 不指定教室 | **不检**开放时间 |
| 停课 / 补课 / 加课 | 停课不检；补课/加课有调后教室则检 |
| 发起申请 | **不因「不在开放时间」硬拦**；但同一申请单**不能**同时出现「在时间内」与「不在时间内且已指定教室」——不在时间内的须设**不指定教室**才可与「在时间内」共存 |
| 列表提示 | 三页 `legend-bar` **常驻**说明（有档案即提示）；审批列表**不改列** |
| 审批 | 调后时间不在目标教室开放时间内：**详情提示 + 禁用审批按钮 + 通过硬拦**；驳回不检 |
| 批量调课管理 | **不受教室开放时间限制**（选教室不置灰、不禁选、提交不拦）；开放时间列可展示文案但不约束选择 |
| 修改记录 | 维护页挂修改记录抽屉（`adjustment-room-open`） |
| 与「教室排课时间」 | **独立数据**，不复用 `roomSlotProfiles.blockSlots` |

## 1. 改动目标

### 1.1 新菜单

在「调课管理」增加二级菜单 **「教室开放时间设置」**，作为该分组**第一个**入口。管理端按场地类型维护各教室**可申请调课**的开放时间，并支持按范围批量设置。

侧栏目标顺序：

```text
教室开放时间设置      ← 新增，第一项
调课原因类型
我的调课申请
调课申请审批
调课申请管理
调课申请记录
公假日停课
批量调课管理
```

### 1.2 维护后列表提示

下列三页在已维护开放时间档案后，顶部提示条说明规则（教师/代申请/审批都能看见）：

| 页面 | 提示容器（已有） |
| --- | --- |
| 我的调课申请 | `#adjustment-teacher-hint` |
| 调课申请审批 | `#adjustment-approval-hint` |
| 调课申请管理 | `#adjustment-admin-hint` |

### 1.3 审批拦截

打开调课申请审批详情时，按**调后安排**（日期 / 星期 / 节次 / 教室）判断是否落在该教室开放时间内：

- 不在：详情内展示原因；`#adjustment-detail-approve-btn` **禁用**；点击或 `submitAdjustmentReview` 走通过时 **alert 并中止**，不能完成审批。
- 在（或无需检查）：审批按钮保持现有可用逻辑。

非目标（本期不做，除非 §8 确认）：

- 不改排课表时间 / 排课表教室两侧课表、右键、锁定/待定。
- 不改「排课时间设置 → 教室排课时间」（那是教室**不排课**，服务排课冲突）。
- 不改公假日停课、调课申请记录页。
- **批量调课管理不受教室开放时间限制**（与申请审批解耦；选教室可继续展示开放时间文案，但不置灰、不禁选、提交不拦）。
- 发起申请不因「全部不在开放时间」硬拦；仅拦同一单内「在时间内 + 不在时间内且已指定教室」的混合。
- 不改调课原因类型、请假记录。
- 不做教室开放时间「复制其他学期」（除非确认要复用复制弹窗）。

## 2. 现状摘要

### 2.1 导航与页注册

`index.html` 侧栏 `nav-group`「调课管理」现无教室开放时间项。  
`SCHEDULE_PAGE_IDS`（`app.js`）已登记 `adjustment-reason-type` / `adjustment-teacher` 等，**无**本页 page-id。  
`goPage` 无对应 `render*`。

### 2.2 教室与场地类型

- 教室主数据：`SCHEDULE_ROOM_META`（`room / building / floor / roomType / seats`）。
- 一级场地类型：`SCHEDULE_VENUE_TYPES`（普通教室 / 专业教室 / 计算机教室；另有「不选择教室」不用于本页）。
- `roomType`（多媒体教室、阶梯教室等）可通过已有 `SCHEDULE_VENUE_TYPE_LEGACY_MAP` / `mapScheduleVenueTypeValue` 归到一级场地类型。
- 本页按**一级场地类型**分区批量，列表可同时展示二级 `roomType`、楼栋、楼层便于勾选。

### 2.3 易混淆：教室排课时间

`cfg.roomSlotProfiles[]` 已用于「教室**不排课**」→ 教室时间冲突（排教室 / 锁定教室 / 审批选教室）。  
教室开放时间是**调课可申请窗口**，语义相反、消费入口不同，**禁止写入 `blockSlots`**。

### 2.4 三页提示条

| 函数 | 现有内容 |
| --- | --- |
| `renderAdjustmentTeacherPage` | 共 N 条 · 待处理 · 用户新增 |
| `renderAdjustmentApprovalPage` | 待审批 · 过程中 · 全部 |
| `renderAdjustmentAdminPage` | 同类统计（代申请） |

本期在原统计后**追加**开放时间说明，不替换原统计。

### 2.5 审批按钮

`openAdjustmentDetail(id, withApprove)`：

```js
approveBtn.hidden = !(withApprove && (r.status === 'pending' || r.status === 'reviewing'));
```

通过链路：`openAdjustmentReview` → `#modal-adjustment-review` → `submitAdjustmentReview` → `submitAdjustmentReviewCore`。  
通过时已有 `assertAdjustmentApproveRoomsReady`。本期在通过分支**再拦**开放时间。

调后字段在 `getAdjustmentItems(r)` 的 `it.to`：`date` / `weekday` / `period` / `weeks` / `room` / `roomUnspecified`。

## 3. 数据模型

新内存仓（与 `ADJUSTMENT_STORE` 并列，不进课表节次）：

```js
const ADJUSTMENT_ROOM_OPEN_STORE = {
  term: '',           // 当前维护学期
  profiles: [
    {
      id: 'aro-1',
      term: '2025-2026-1',
      venueType: 'lecture_room',     // 一级场地类型
      room: '教学楼A-102',           // 一段对应一间教室（批量写入时逐间追加）
      dateFrom: '2026-03-01',        // 必填（范围含日期）
      dateTo: '2026-06-30',
      weeks: '',                     // 可选
      weekdays: [1],                 // 1=周一 … 7=周日
      periodFrom: 1,
      periodTo: 2,
      remark: ''
    }
  ]
};
```

判定：**指定教室 + 调后日期/星期/节次** 命中该教室至少一条档案的（学期、日期、可选周次、星期、节次）交集 → 开放；有档案但无一命中 → 不开放。  
教室在本学期**没有任何档案** → 不限制。  
`roomUnspecified` 或教室为空 → 不检。

演示数据：至少 1 条（如 `教学楼A-102` 仅周一第 1–2 节开放），便于审批页构造「不在开放时间」样例。

修改记录：`registerEntityChangeLogMeta('adjustment-room-open', …)`，保存 / 删除时 `appendEntityChangeLog`。

## 4. 维护页交互

### 4.1 页面骨架

- `id="page-adjustment-room-open"`，`class="page-list page adjustment-page"`。
- 标题：教室开放时间设置。
- 副标题：按场地类型勾选教室，批量维护可申请调课的开放时间。

查询区（建议一行 3 列 + 查询/重置，对齐调课列表）：

| 条件 | 控件 |
| --- | --- |
| 学年学期 | 下拉，必选（与调课列表学期口径一致） |
| 场地类型 | 下拉：全部 / 普通教室 / 专业教室 / 计算机教室 |
| 教室名称 | 文本 |
| 楼栋 | 下拉，可选 |
| 楼层 | 下拉，可选 |

工具栏：

- **批量设置开放时间**（需已勾选教室；跨场地类型勾选时提示「请按同一场地类型勾选」）
- 可选：删除所选档案 / 清空本学期该教室全部开放时间

### 4.2 列表

建议双层或单表 + 场地类型分组头：

| 列 | 说明 |
| --- | --- |
| 勾选 | 批量用 |
| 场地类型 | 一级 |
| 教室名称 | `SCHEDULE_ROOM_META.room` |
| 楼栋 / 楼层 / 教室类型 | 辅助 |
| 已维护开放时间 | 摘要：如 `1-16 周 · 周一至周五 · 第1-10节`；无则「未维护（不限制）」 |
| 操作 | 设置 / 清除 |

列表**按段一行**（教室 + 一段）；未维护教室一行显示「未维护（不限制）」。操作：设置 / 添加时段 / 修改 / 删除单段 + 修改记录。

### 4.3 批量设置弹窗（居中表单，非抽屉）

`#modal-adjustment-room-open`：

- 只读：已选教室数、场地类型。
- **日期范围（起止，必填）**；周次可选。
- 星期多选。
- 节次起止（对应该学期 `ensureSchedulePeriods`）。
- 备注（可选）。
- 确定：把同一时段**追加**到所选每间教室（不覆盖已有段）；修改时只改当前段。

弹窗内下拉**保持原生/不走页内可搜索增强**（`enhanceAllSelects` 已跳过 `modal-`）。

## 6. 审批判断

### 6.1 检测函数

```text
collectAdjustmentRoomOpenViolations(request) →
  [{ itemIndex, room, date, weekday, period, reason }]
```

对每条 `item.to`：

1. `cancel` 或无 `to` → 跳过。
2. `to.roomUnspecified` 或教室为空 → 跳过。
3. 取 `to.date`、星期、`to.period`（或 periodFrom–To）、学期。
4. 查该教室本学期档案；无档案 → 跳过（全开放）。
5. 有档案但日期/周次/星期/节次都不相交 → 记入违规。

审批人在详情里改调后日期/节次/教室后，**重跑检测**并刷新按钮态。

### 6.2 按钮与提交

`openAdjustmentDetail(..., true)` 及调后字段 `onchange` 后：

```text
violations = collectAdjustmentRoomOpenViolations(r)
approveBtn.hidden = 仍按原 pending/reviewing
approveBtn.disabled = violations.length > 0
approveBtn.title = 违规摘要
```

详情「调课信息」上方或冲突列旁展示：

> 调后时间不在教室开放时间内：教学楼A-102 · 周一第1节。不能审批。

`openAdjustmentReview`：若仍有违规，`alert` 后 return，不打开录入弹窗。  
`submitAdjustmentReviewCore` 在 `result === 'approved'` 时同样硬拦（防禁用被绕过）。  
**驳回不检**开放时间（仍允许驳回）。

选教室抽屉：仅 `scheduleRoomPickerMode === 'adjustmentApprove'` 时按开放时间置灰/禁选/确定拦截。  
批量调时间 / 批量调教室复用同一抽屉时**不限制**（`shouldEnforceAdjustmentRoomOpenLimit()` 为 false）。  
审批提交拦截仍走 `collectAdjustmentRoomOpenViolations` / `syncAdjustmentRoomOpenApproveUi`。

## 8. 确认记录

1. 未维护教室：**不限制**
2. 不指定教室：**不检**
3. 同一教室：**多段开放，可分别修改（追加）**
4. 范围字段：**包括日期**（日期范围 + 星期 + 节次；周次可选）
5. 发起申请：**不拦**「不在开放时间」；但同一申请单不能同时出现一条在时间内、一条不在时间内（除非不在时间内的设为不指定教室）
6. 列表提示：**常显**（有档案即显示）
7. 审批页：**不改列**
8. 学年学期：**按学期**维护
9. 停课不检；补课/加课有调后教室则检：**同意**
10. **要有修改记录**
