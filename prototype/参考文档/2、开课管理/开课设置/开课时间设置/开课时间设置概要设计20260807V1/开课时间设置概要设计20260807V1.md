## 2. 建设目标与范围

### 2.1 目标

按学年学期维护全校及各开课单位的开课操作时间窗口、默认展示学期与授课确认截止日期，为下游专业开课、通识开课及教师端授课确认提供统一时间基准。

### 2.2 范围内

- 全校开课开放时间（开始 / 截止，含时分）
- 默认展示学期（全局最多一个「是」）
- 授课确认截止日期（仅日期，供教师确认函 Notes）
- 开课单位级开放时间覆盖（列表展开区维护）
- 按条件查询、新增、修改、删除学期配置

### 2.3 非目标（不在本菜单）

- 不维护校历本身、考试周安排
- 不替代培养方案执行计划锁定
- 不含校选课程管理、特殊课程设置
- 教学周数不在本页手工维护（按学期类型派生展示）

## 3. 用户角色与使用场景

| 角色 | 场景 | 目标 |
|------|------|------|
| 教务管理员 | 每学期开课前 | 配置全校及各单位可操作时段 |
| 教务管理员 | 设置默认展示学期 | 让下游开课列表默认落在正确学期 |
| 教务管理员 | 维护授课确认截止日期 | 供教师端确认函展示 |
| 各开课单位教务 | 本单位窗口与全校不一致时 | 通过单位覆盖单独设置（待确认：是否仅管理员代设） |

## 4. 在整体业务链路中的位置

```text
校历学年学期 → 【开课时间设置】→ 开课计划（依赖默认展示学期）
                              → 开课安排 / 开课名单（学期筛选默认值）
                              → 授课确认（教师端 Notes 取确认截止日期）
                              → 各开课单位模块（单位开放窗口控制可操作时段）
```

本菜单位于开课管理链路最前端，与校选课程管理、特殊课程设置并列，同属「开课设置」分组，无强顺序依赖，但专业开课生成任务前须已配置默认展示学期。

## 5. 主业务流程

1. 管理员进入页面，按学年学期 / 默认展示学期筛选列表。
2. 新增尚未配置的学期，设置全校开课起止时间与授课确认截止日期。
3. 在列表内切换「默认展示学期」开关（排他：全局最多一条为「是」）。
4. 对需单独控制的单位，展开行内子表，新增或行内编辑单位开课时间。
5. 下游「生成开课任务」等操作读取默认展示学期；各单位操作受对应窗口「开放中 / 已截止」约束。

## 6. 职责边界

| 职责 | 说明 |
|------|------|
| 负责 | 学期维度的全校 / 单位开课窗口、默认展示学期、授课确认截止日期 |
| 不负责 | 计划生成、任务安排、名单维护、授课确认流程本体 |
| 与他模块交接点 | 默认展示学期 → 开课计划生成前置；确认截止日期 → 教师端；单位窗口 → 各单位开课操作权限 |
