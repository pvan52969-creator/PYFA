## 1. 文档目的

在开课设置侧提供**课号级默认配置**（教室属性/偏好、默认 Support 学院、Support 历史），供专业开课安排新建或仍为系统默认的教学班自动带出，减少每学期重复录入。

## 2. 功能概述

- 从**教务课程库**手动将课程纳入本维护清单（非全库强制配置）。
- 对清单内课号维护：
  1. **教室默认**：理论 / 辅导 / 实践 / 其他 四类学时各自的教室属性与参考教室偏好
  2. **默认 Support 学院**（可多选，不可含本开课单位）
  3. **Support 历史**（Y / N）：该课历史上是否有过 Support
- 下游教学班可按班覆盖教室与 Support 学院；**班级覆盖不回写**课号配置。

## 3. 角色与权限（原型约定）

| 角色 | 能力 |
|------|------|
| 教务管理员 | 添加课程、编辑、删除、查询 |

## 4. 界面说明

### 4.1 页说明

默认只影响**此后新建**，或教室仍为「全普通、无偏好」/ Support 仍为空的教学班；已在开课安排中改过的班不会被覆盖。

### 4.2 筛选区

开课单位｜课程号｜查询｜清除过滤

### 4.3 工具栏

| 按钮 | 说明 |
|------|------|
| 添加课程 | 从教务课程库勾选纳入 |
| 删除 | 多选删除清单项（不影响已写入教学班的值） |

### 4.4 列表列

勾选｜序号｜课程代码｜课程名称｜开课单位｜Support 学院｜Support历史｜操作（编辑）

> 列表不展示教室摘要；教室仅在编辑抽屉维护。

### 4.5 弹窗「添加特殊课程」

筛选：开课单位、课程号  
表列：勾选、序号、课程号、课程名称、开课单位、学分、课程分类  
新纳入默认：教室全普通无偏好；Support 空；Support历史 = N。

### 4.6 抽屉「编辑特殊课程设置」

| 区块 | 内容 |
|------|------|
| 只读 | 课程代码、开课单位、课程名称 |
| 教室信息 | 四学时：属性 + 参考教室偏好 |
| Support历史 | Y / N |
| 默认 Support 学院 | 多选，排除本开课单位 |
| 操作 | 取消 / 确定 |

## 7. 业务规则

### 7.1 纳入与删除

1. 仅清单内课号具备课号级默认；未纳入不影响正常开课。
2. 同一课号不可重复纳入。
3. 删除清单项后，已写入教学班的教室 / Support 值保留。

### 7.2 写入教学班（专业开课安排）

| 场景 | 教室 | Support 学院 | Support历史 |
|------|------|--------------|-------------|
| 新建教学班 / 首次进入编辑且可全量拷贝 | 按课号默认填入 | 按课号默认带出 | 始终按课号同步；未配置为 N |
| 打开编辑且 `onlyIfEmpty` | 仅当仍为系统默认（全普通、无偏好）时补全 | 仅当为空时补全 | 始终按课号同步 |
| 班上已手工改过 | 不覆盖 | 不覆盖 | 仍按课号同步展示 |

### 7.3 通识等其它开课

本页为统一数据源；通识等类型可预留读取同一接口，UI 默认带出可分期实现，不阻塞专业开课。

## 8. 状态说明

本页无独立工作流状态；清单增删改即时生效（原型持久化方式以实现为准）。

## 9. 上下游依赖

| 方向 | 模块 | 关系 |
|------|------|------|
| 上游 | 教务课程库 | 添加课程候选 |
| 下游 | 开课安排（修改教学任务 / Support） | 教室与 Support 默认初始化；Support历史只读展示 |
| 下游 | 开课计划编辑抽屉 | Support历史只读展示 |
| 预留 | 通识选修开课等 | 复用 `getSpecialCourseDefaults(code)` 一类读取 |

## 10. 非目标

- 不替换校选课程管理
- 不强制全库课程必须先配置才能开课
- 不改排课冲突算法
- 不在本页做合班 / 名单 / 任务安排
- 通识/特殊开课全链路 UI 默认同批落地（可后续）
