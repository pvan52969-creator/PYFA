## Why

现行 `20260901*` 十二份开课 PRD 已对齐部分字段文案，但仍是「走查壳」：状态枚举/转移、完整列表字段、校验副作用、逻辑实体不足；开课安排步骤等与原型冲突；教师替换等「未确认」与原型已实现行为矛盾。下游要用这些文档做 **AI 后端开发依据**，必须升到可编码规格，并钉死冲突裁决。

## What Changes

- **仅文档**（不改 `app.js` / `index.html` 业务逻辑）。
- 新建版本文件夹（**升版，不覆盖** `20260901*`）：日期锁定 `20260902`，各菜单 `V(n+1)`。
- 每菜单 PRD（模板 V3.1）至少补：状态枚举+转移、查询/列表完整字段矩阵（对照现行动态表头）、关键 BR 副作用、逻辑实体清单、后端禁止猜测清单。
- 跨菜单短文：`参考文档/2、开课管理/00_规范与变更说明/开课管理状态与实体对照20260902.md`。
- **冲突裁决（本 change 已锁定）**：
  - 规格真源 = 可见 UI 文案 + 本文档已明确规则；演示算法标「演示规则」。
  - 开课安排步骤 = **2 步**（Course Setting / 师资安排），不以旧三步 PRD 为准。
