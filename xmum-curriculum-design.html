厦门大学马来西亚分校（XMUM）— 专业培养方案管理模块

系统设计文档：涵盖方案版本制定、审批、查询及专业批次执行计划四大子模块。学校每年三个入学批次（02 / 04 / 09），各批次独立绑定对应培养方案版本与执行计划。

1 模块总览与功能架构
方案版本制定
  • 新增培养方案版本
  • TAB1 课程分类配置
  • TAB2 课程设置
  • TAB3 方案进程表预览
  • 提交审批
方案版本审批
  • 待办审批列表
  • 审批详情查看
  • 通过 / 驳回
  • 审批意见记录
  • 审批通过后锁定版本
方案版本查询
  • 按学院/专业/版本筛选
  • 版本状态查询
  • 只读查看三 TAB 内容
  • 历史版本对比（可选）
  • 导出/打印
批次执行计划
  • 选择学院+专业+入学批次
  • 自动匹配对应版本
  • 一键生成执行计划
  • 编辑/查看执行计划
  • 面向实际招生的可调整副本
入学批次： 02 批次 04 批次 09 批次 → 每个批次独立维护「版本方案」与「执行计划」，批次与版本通过「适用入学批次」字段关联
2 版本方案制定 — 三 TAB 详细设计
TAB1 · 课程分类 Course Classification

分类层级（树形结构）

  • * Heading 1 — 一级分类（下拉，字典维护）
  • * Heading 2 — 二级分类（下拉，联动 Heading 1）
  • Heading 3 — 三级分类（手动输入，可选；如 General Elective → Arts/Business/Science）

分类属性

  • * 修读类型：必修 / 选修
  • * 最低学分 / 最高学分
  • 课程数量（统计 TAB2 挂载课程数，可手动校验）
  • 专业方向 Specialization（可选，用于分流专业）

汇总区

  • 各层级学分小计 + 占比（合计 100%）
  • 毕业总学分 = 一级分类学分之和
选修课附加表：所有「修读类型=选修」的分类，需填写各学期（Sem 1–8+）的修读学分要求 & 课程修读数量要求矩阵。
TAB2 · 课程设置 Course List

新增/编辑课程

  • 挂载课程分类（先选 H1 → H2 → H3）
  • * 开课学年学期（Semester Offering）
  • 课程来源：从课程库选取 / 引用已有课程

课程基础信息（General Information）

  • 课号 Course Code — 创建后不可改
  • 课名 Course Name — 创建后不可改
  • 开课单位、课程负责人、学分、授课语言
  • 学期类型（Long/Short）、先修/同修课程
  • 课程简介 Synopsis、参考书 References

课程目标 & 学时（Step 2/3）

  • CLO — Course Learning Outcome
  • SLT — Student Learning Time 学时分配
TAB3 · 方案进程表 Programme Structure

展示逻辑（只读，由 TAB1+TAB2 自动生成）

  • 横轴：学年学期（Year 1 Sem 1 … Graduation）
  • 纵轴：课程分类分组
  • 必修/指定课程：显示具体课号+课名+学分
  • 选修大类：显示该学期「要求修读学分 + 课程数量」（来自 TAB1 选修矩阵）

校验提示

  • 各学期必修学分是否与分类要求一致
  • 选修学期分布是否满足矩阵要求
  • 总学分是否达到毕业要求
TAB3 为预览/校验视图，不在此直接编辑；修改需回到 TAB1 或 TAB2。

版本 vs 执行计划：「培养方案版本」是标准模板，审批通过后锁定不可改。「执行计划」是从已审批版本复制生成的批次实例，允许教务人员针对具体招生批次微调（如调整某门课的开课学期），不影响原版本。
4 状态流转与业务规则

方案版本状态机

草稿 Draft → 待审批 Pending → 已通过 Approved ✓ | 待审批 → 已驳回 Rejected → 退回修改

执行计划状态

草稿（可编辑） → 已发布 Published 发布后供学籍/选课/毕业审核引用
规则编号业务规则
R01同一「学院+专业+适用批次」在同一时间段仅允许一个「已审批」的有效版本
R02提交审批前：TAB1 学分汇总=100%，各分类最低≤最高，选修矩阵已填
R03TAB2 每门课程必须挂载到 TAB1 已建分类；开课学期必填
R04审批通过后版本内容只读；变更需新建版本走审批
R05执行计划生成时默认绑定当前批次唯一有效版本，不可跨版本选择
R06执行计划可编辑，但不得修改课号/课名（引用课程库）
角色权限
学院教务员制定版本、编辑执行计划、提交审批
教务处审核员审批通过/驳回、发布执行计划
校领导/院长只读查询、报表
学生/教师通过门户只读查看已发布执行计划
系统管理员分类字典维护、入学批次配置
