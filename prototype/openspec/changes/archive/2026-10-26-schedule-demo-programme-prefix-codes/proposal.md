# Proposal

## Why

排课模块演示课号仍大量使用 `CDF201`、`CDX101`、`CTS101`、`RM*` 等非学校规格前缀，侧栏与冲突弹窗一眼不像真课。学校真实课号（如 `ACC312`）一般为「专业代码三字母 + 数字」，前缀对应所属专业。需要把**排课模块可见课号**统一成该规格，同时避免与真实开课目录撞号。

## What Changes

- 约定排课演示课号规则：**前缀 = 所属专业代码**（与 `PROGRAMMES` / 真实表一致，如 mec → `MEC`、fin → `FIN`）；**数字走演示号段（建议 9xx）**，不占用 Excel 中已出现的真实课号（方案 2）。
- 将排课模块内假前缀演示课（至少含 `CDF*`、`CDX*`、`CTS*`、`RM*`、`RCL*` 及同类查询/教室垫片课号）改写为专业前缀 + 演示号段；同步所有硬编码引用（冲突剧本注释、changelog 文案、查询页等）。
- **课程名称、课程组名称**可不强制对齐 Excel，可保留现有或随意英文/短名。
- 以用户提供的《课程班》导出为**规格参考**（前缀与专业对应关系），不要求整表导入为运行时数据源。
- **不改**：排时间 / 排教室交互与菜单独立性；冲突检测算法口径；开课管理 / 培养方案主数据（除非排课种子挂靠必须同步 catalogId）。

## Capabilities

### New Capabilities

- `schedule-demo-programme-prefix-codes`: 排课演示课号按专业前缀 + 演示号段统一，避免与真课撞号。

### Modified Capabilities

- （无）主 specs 暂无对应条目；与已归档的 `schedule-realistic-course-names`（课名真实化、课号可假）在课号策略上以本变更为准。

## Impact

- 主要改动：`app.js` 排课演示种子（冲突闭环 CDF/CDX、教室 RM/RCL、冲突查询 CTS 等）及所有字面量引用。
- 受影响：排时间侧栏课号、课表卡片、冲突弹窗、按教师/批次课表、课表冲突查询、变更日志演示文案。
- 验收：侧栏不再出现 `CDF*`；mec 批次演示课号形如 `MEC9xx`；与 Excel 真实号不重叠。
