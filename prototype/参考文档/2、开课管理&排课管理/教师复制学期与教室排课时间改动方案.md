# 教师排课时间「复制其他学期」· 教室排课时间 Tab 改动方案

> 文档性质：代码改动方案（需求文档，供实现前对齐）  
> 适用范围：排课基础设置 → **排课时间设置**；排时间锁定教室 / 排教室选教室 / 调课审批选教室  
> 关联代码：`prototype/index.html`、`prototype/app.js`、`prototype/styles.css`  
> 关联说明：`排课与排教室冲突类型说明.md`（实现时同步 §3 / §3.1）  
> 状态：**已按确认口径实现**

---

## 0. 已确认口径

| 项 | 结论 |
| --- | --- |
| 复制 | **覆盖**目标学期该 Tab 全部档案；**教师、教室都要「复制其他学期」** |
| 教室时段类型 | **只要不排课**，不要「只排课」 |
| 查询范围 | 列表 + 新增弹窗：教室名称 / 楼栋 / **楼层** / 教室类型 / 周次 / 星期 / 节次 |
| 学年学期 | **教师排课时间、教室排课时间均为必选**（与课表不排课 / 选修课一致，不可「全部学期」） |
| 冲突消费 | 教室不排课写入 **教室时间冲突**（硬），并接入三条选教室入口（见 §5） |
| 不改 | 排时间侧课表格图例/右键菜单；排教室锁定/待定/右键菜单条目；批量调教室选教室（非审批） |

学期排课时间 Tab 仍可清空看全部学期（它是学期窗口清单，不是时段档案）。其余四个时段类 Tab 学年学期必选。

## 1. 改动目标

### 1.1 教师排课时间：复制其他学期

工具栏增加「复制其他学期」，源学期整表 **覆盖** 当前查询学期。学年学期改为必选（去掉清除「全部学期」）。

### 1.2 教室排课时间 Tab

增加 Tab，按学期维护各教室不排课；查询含楼层；学年学期必选；工具栏同样有「复制其他学期」（覆盖）。

### 1.3 教室不排课 → 三条选教室入口

命中 `roomSlotProfiles.blockSlots` 视为 **教室时间冲突**（与排考、场地借用并列，硬拦）。必须覆盖：

| 入口 | 模式 | 现状 | 本期 |
| --- | --- | --- | --- |
| 排时间侧 · 锁定教室 | `scheduleRoomPickerMode === 'lockRoom'` | 列表无冲突标签；确定只写草稿，不跑冲突 | 列表标「时段占用」；确定遇 `roomTime` 弹窗硬拦 |
| 排教室侧 · 选择教室 | `phase === 'room'` | 已跑 `detectScheduleRoomAssignConflicts` | 检测函数追加不排课即可自动带上 |
| 调课审批侧 · 选择教室 | `scheduleRoomPickerMode === 'adjustmentApprove'` | 只展示他课占用；确定不跑冲突 | 占用列/标签含不排课；确定遇 `roomTime` 弹窗硬拦；「不指定教室」不检 |

非目标：

- 不改课表不排课 / 选修课列表、弹窗、覆盖复制口径。
- 不改教师新增/修改弹窗、筛选、批量保存（仅加复制 + 学期必选）。
- 不改排时间侧 soft 冲突（blackout / elective / teacherSlot）与课表格图例集合。
- 不新增排教室图例项；不改两侧右键菜单。
- 不写入 `SCHEDULE_ROOM_NON_SCHEDULE_OCCUPANCY`。
- 不改批量调教室选教室（`mode === 'batch'`），除非后续单独立项。

## 2. 现状摘要

### 2.1 排课时间设置 Tab

```text
学期排课时间 | 课表不排课时间 | 选修课排课时间 | 教师排课时间
```

`isScheduleTimeSettingRequiredTermTab` 现仅 `blackout || elective`。教师 Tab 有清除按钮。

### 2.2 复制弹窗

`openScheduleSlotCopyModal(kind)` 仅 `'blackout' | 'elective'`，整表覆盖。  
`cloneScheduleSlotRowsForCopy` 不能直接用于教师/教室档案。

### 2.3 教室主数据

`SCHEDULE_ROOM_META`：`room / building / floor / roomType / seats`。`floor` 为数字，展示「1层」。

### 2.4 选教室抽屉（同一 `#modal-schedule-room-picker`）

| mode | 打开函数 | 确定 `confirmScheduleRoomPicker` |
| --- | --- | --- |
| `lockRoom` | `openScheduleLockRoomPicker` | 只写 `scheduleLockedRoomPickerDraft`，**无冲突** |
| `schedule` + 排教室 | 排教室选教室 | `detectScheduleRoomAssignConflicts`，有冲突弹窗 |
| `adjustmentApprove` | `openAdjustmentApproveRoomPicker` | `applyAdjustmentApproveRoomValue`，**无冲突** |
| `batch` | 批量调教室 | 本期不改 |

`getScheduleRoomRowConflictTags` 仅在 `phase === 'room'` 且非 batch/approve 时调用检测。锁定模式走空标签。

审批占用：`getAdjustmentApproveRoomOccupancyLabels` / `getAdjustmentApproveRoomPeriodOccupancy` 只看已排课，不含设置页不排课。

## 3. 教师排课时间：复制 + 学期必选

### 3.1 学期必选

- `isScheduleTimeSettingRequiredTermTab` 增加 `'teacher-slot'`。
- 去掉 `#schedule-time-setting-term-teacher-clear`。
- `rebuildScheduleTermSelects` 教师下拉不再出现「全部学期」。
- 列表仍可保留「学年学期」列（恒为当前查询学期）。
- 复制：目标学期取当前必选值（空则仍拦截，防御用）。

### 3.2 复制（覆盖）

工具栏「删除」后加按钮，复用 `#modal-schedule-slot-copy`，`kind === 'teacher-slot'`。

整份克隆 `teacherSlotProfiles`（新 id）覆盖目标学期。复制不写变更日志。  
`cloneScheduleSlotRowsForCopy` 只服务 blackout/elective。

## 4. 教室排课时间 Tab

### 4.1 菜单位置与学期

```text
学期排课时间 | 课表不排课时间 | 选修课排课时间 | 教师排课时间 | 教室排课时间
```

Tab key：`room-slot`。学年学期 **必选**（`isScheduleTimeSettingRequiredTermTab` 含 `'room-slot'`），无清除按钮。

### 4.2 列表

```text
学年学期（必选）  教室名称  楼栋  楼层  教室类型  周次  星期  节次   [查询] [重置]
```

楼栋变更后刷新楼层选项；空楼栋 = 全部楼层。重置回到默认开课学期，并清空其它条件。

工具栏：`[新增] [删除] [复制其他学期]`。

列：勾选、序号、学年学期、教室、楼栋、楼层、教室类型、座位数、不排课时段、备注、操作。

### 4.3 数据

```text
cfg.roomSlotProfiles[] {
  id, room, building, floor, roomType, seats,
  blockSlots[],   // { weekFrom, weekTo, weekdays[], periods[] } 无 onlySlots
  remark
}
```

演示种子选一间排教室会用到的教室，时段避开已有排考占用（例如 `教学楼A-102` 周一第 1–2 节），便于单独验收不排课着色。

### 4.4 弹窗

独立 `#modal-schedule-room-slot`，禁止 clone 教师弹窗。

筛选：教室名称 / 楼栋 / 楼层 / 教室类型。新增多选批量写；同学期已存在该教室则跳过。修改单教室。校验：每条时段须同时有星期与节次；至少一条不排课。

教室专用 `scheduleRoomSlotDraft`，复用 `normalizeScheduleTeacherSlotRule` 等纯函数，不改教师 DOM。

### 4.5 教室复制

`openScheduleSlotCopyModal('room-slot')`，覆盖 `roomSlotProfiles`。复制不写日志。

### 4.6 修改记录

`registerEntityChangeLogMeta('schedule-room-slot', …)`，增删改写日志。

## 5. 冲突接入（三条入口）

核心函数（新）：

```text
detectScheduleRoomSlotBlockConflicts(probe, room, term) → string[]
```

学期：`getActiveOfferingTermSetting()?.termCode`（与教师时段探测一致）。  
命中：同学期档案 `room === R`，且某条 `blockSlot` 星期、节次、周次与 probe 有交集（周次空则视为命中，对齐 `scheduleTeacherSlotWeeksOverlap`）。

文案：`周一第1-2节 · 教学楼A-102 命中教室不排课时段（第1-14周 周一 第1-2节）`。

### 5.1 公共：写入 `roomTime`

在 `detectScheduleRoomOnlyConflicts` 里，非排课占用之后追加 slot-block 命中 → `result.roomTime`。

这样排教室网格着色、安排硬拦、场地冲突查询（另见 §5.5）自动带上。  
**不要**新增 `roomSlot` 字段，不要改 `recomputeScheduleRoomOnlyConflictFlags` 的三类集合。

### 5.2 排教室侧 · 选择教室

已有路径，检测扩完即可：

- `getScheduleRoomRowConflictTags` → 标签「时段占用」
- `confirmScheduleRoomPicker`（`phase === 'room'`）→ 弹窗；含 `roomTime` 不可继续
- `getScheduleRoomTimetableConflictCellKeys` → 红格

`roomOnly` 弹窗文案：

| 位置 | 现状 | 目标 |
| --- | --- | --- |
| 行标题 | 非排课占用冲突 | **教室时间冲突** |
| 硬拦提示 | …排考、场地借用… | 存在教室时间冲突（排考、场地借用或教室不排课时段），无法安排教室。 |

只改 `roomOnly` 分支，时间侧 `else` 不动。

### 5.3 排时间侧 · 锁定教室（隔离 `lockRoom`）

不改时间侧课表格冲突着色，只改锁定教室抽屉。

**列表标签：** 扩展 `getScheduleRoomRowConflictTags`：

```text
if (scheduleRoomPickerMode === 'lockRoom') {
  entries = getScheduleSelectedSlotEntries();
  用 detectScheduleRoomAssignConflicts（或至少 occupancy + slot-block）
  只展示 roomTime →「时段占用」，hard=true
  不展示座位/类型（锁定教室抽屉现状无这两类）
}
```

原 `phase === 'room'` 分支保持原样。

**确定：** 在 `confirmScheduleRoomPicker` 的 `lockRoom` 分支、写草稿之前：

```text
if (room && entries.length) {
  conf = detectScheduleRoomAssignConflicts(entries, room);
  if (conf.roomTime?.length) {
    openSchedulePlaceConflictModal(conf, null); // 硬拦，不写草稿
    return;
  }
}
```

座位数/类型冲突锁定教室不拦截（与抽屉现状一致）。

### 5.4 调课审批侧 · 选择教室（隔离 `adjustmentApprove`）

**占用展示：**  
`getAdjustmentApproveRoomPeriodOccupancy` / `getAdjustmentApproveRoomOccupancyLabels` 除他课外，若该教室在查询星期/节次/周次命中不排课：

- 节次单元格视为占用（`busy`），文案「不排课」或「教室不排课」
- 行标签并入「时段占用」

**确定：** 「不指定教室」不检测。已选教室则用审批上下文拼 probe：

```text
probe = { weekday, periodFrom: period, periodTo: period, weeks: ctx.weeks }
conf.roomTime = occupancyMsgs + detectScheduleRoomSlotBlockConflicts(probe, room, term)
if (conf.roomTime.length) openSchedulePlaceConflictModal(conf, null); return;
```

再 `applyAdjustmentApproveRoomValue`。审批抽屉不引入座位/类型软冲突。

### 5.5 场地冲突查询

`detectScheduleRoomTimeQueryConflicts` 在排考/借用循环旁：已排记录 vs 该学期 `roomSlotProfiles`，重叠则 `conflictType: 'roomTime'`，明细「命中教室不排课时段」。筛选项不用新 option。

### 5.6 独立性

```text
lockRoom          → 只动锁定教室抽屉标签/确定
phase === 'room'  → 只动教室侧已有检测链
adjustmentApprove → 只动审批选教室占用/确定
```

禁止改 `#schedule-grid-context-menu`、`applyScheduleContextMenuVisibility`、`#schedule-room-grid-context-menu`、锁定/待定格态。  
排时间课表格不读 `roomSlotProfiles`（锁定教室除外）。

## 9. 自检（对照仓库规则）

- 排时间侧只增加锁定教室抽屉的冲突，不改时间侧菜单/图例/落点 soft。
- 排教室侧只扩 `roomTime` 来源与 `roomOnly` 文案，不改右键/锁定待定。
- 审批选教室用 `adjustmentApprove` 早分支，不统一重写排教室确定路径。
- 教室设置弹窗独立 DOM。
- 教师/教室复制只扩 `kind`，不改 blackout/elective 覆盖逻辑。
