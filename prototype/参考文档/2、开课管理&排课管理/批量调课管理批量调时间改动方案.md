# 批量调课管理 · 批量调时间改动方案

> 文档性质：代码改动方案（需求文档，供实现前对齐）  
> 适用范围：调课管理 → **批量调课管理** → 抽屉 **批量调时间**（`#adjustment-batch-tab-time` / `#modal-adjustment-batch`）  
> 关联代码：`prototype/index.html`、`prototype/app.js`、`prototype/styles.css`  
> 状态：**已按方案实现**

---

## 0. 已确认口径

| 项 | 结论 |
| --- | --- |
| 改哪一侧 | **只改批量调时间**。批量调教室 Tab、列表查询区、排时间 / 排教室详情页不改 |
| 日期模式 | 源日期、目标日期各自可切换 **按日期** / **按星期**；默认 **按日期**（保持现状） |
| 按星期字段 | 起止周（起始周 + 截止周）+ 星期（可搜索下拉多选）。节次仍用现有「源节次 / 目标节次」勾选格，不在日期区内再做一份 |
| 课程选择 | 放在 **目标节次下方**；可搜索下拉、可多选；未选 = 命中源日期+源节次的全部课程 |
| 顺位对应 | 多选日期、多选节次时，按顺位一一对应：第 N 个源日期 → 第 N 个目标日期，第 N 个源节次 → 第 N 个目标节次 |
| 顺位排序 | 日期按时间先后，节次按节次号从小到大（与现网 `mapAdjustmentBatchTargetDate` / `mapAdjustmentBatchTargetPeriod` 一致） |
| 天数校验 | 展开后的源日期天数必须等于目标日期天数，否则不能生成明细（现状保留） |
| 调后教室 | 明细表「调整后节次」后新增列；选择器展示；点击打开现有教室选择弹窗；默认带出原教室 |
| 教室弹窗 | 复用 `#modal-schedule-room-picker`，新增独立 mode 分支，禁止改排时间 / 排教室详情交互 |

---

## 1. 改动目标

在批量调时间抽屉中补齐四块能力：

1. **目标节次下增加课程筛选**（可搜索、可多选），缩小生成明细的课程范围。  
2. **源 / 目标日期支持按星期选择**：切换后用起止周 + 星期多选展开为具体日期。  
3. **调课明细顶部常驻提示**：说明多选日期、节次按顺位对应。  
4. **明细行可改调后教室**：选择器展示，点击弹出教室选择弹窗，写回该行并重算冲突。

非目标（本期不做）：

- 不改 `#adjustment-batch-tab-room` 批量调教室表单、明细、提交。  
- 不改批量调课管理列表页查询条件布局（仍遵守查询条件一行最多 3 个）。  
- 不改排课表时间 / 排课表教室详情页、右键菜单、锁定 / 待定。  
- 不改我的调课申请、调课申请管理、调课申请记录、调课申请审批。  
- 不把现有页面级 `enhanceScheduleSearchableSelect` 改成默认支持 `multiple`（它明确排除 `select.multiple`，且抽屉属 modal 作用域不会自动增强）。

## 2. 现状摘要

### 2.1 入口与结构

| 项 | 现状 |
| --- | --- |
| 列表入口 | `#page-adjustment-batch` → `openAdjustmentBatchDrawer('time')` |
| 抽屉 | `#modal-adjustment-batch`，时间 Tab `#adjustment-batch-tab-time` |
| 状态 | `ADJUSTMENT_BATCH_STATE.time` / `timeTarget` / `room` |

时间侧表单当前只有：

```text
源日期（日历起止）
源节次（checkbox 多选）
目标日期（日历起止，天数须与源一致）
目标节次（checkbox 多选，个数须与源一致）
[确定生成调课明细] [清空调课明细]
明细表（无课程筛选、无调后教室列）
原因类型 / 调整原因 / 附件
```

### 2.2 日期与映射

- 日期：`openAdjustmentBatchDatePicker` → `#adj-batch-cal-dd` 选起止，`expandAdjustmentHolidayRange` 展开为 `state.dates`。  
- 命中：`collectAdjustmentBatchHits('time')` 按 `dates × weekday × 源节次` 扫 `getScheduleTaskRows()`。  
- 对应：`mapAdjustmentBatchTargetDate` / `mapAdjustmentBatchTargetPeriod` **先排序再按下标配对**。  
- 天数 / 节次数不一致：`validateAdjustmentBatchTimeForm` 拦截。

### 2.3 明细与提交

- 渲染：`renderAdjustmentBatchPreview('time')`，空表 `colspan=11`。  
- 列：序号、课程编号、课程名称、上课小组、教师、源日期、原节次、教室、调整后日期、调整后节次、冲突情况。  
- 冲突：`checkAdjustmentBatchTimeRowConflict` 用**原教室**做场地冲突。  
- 提交：`confirmAdjustmentBatch('time')` 只写回 `slot.weekday` / `periodFrom` / `periodTo`，**不改教室**。  
- 归档：`serializeAdjustmentBatchDetailRows` 无 `targetRoom`；详情表亦无调后教室列。

### 2.4 可复用能力

| 能力 | 位置 | 注意 |
| --- | --- | --- |
| 教室弹窗 | `#modal-schedule-room-picker`，`scheduleRoomPickerMode === 'batch'` | 现只服务批量调教室源/目标教室 |
| 节次多选格 | `initAdjustmentBatchMultiChecks` + `.schedule-multi-check-grid` | 时间 / 教室两侧共用初始化，改 time 时勿打乱 room |
| 可搜索单选 | `enhanceScheduleSearchableSelect` | **不处理 `multiple`，且跳过 modal/drawer** |
| 教学周 / 星期 | `getOfferingTermTeachingWeeks`、`SCHEDULE_WEEKDAYS`、`getScheduleTermStartDate`、`adjustmentTeachingWeekOf` | 按星期展开日期用这套 |

## 3. 目标交互

### 3.1 表单（批量调时间）

```text
源日期
  [按日期 | 按星期]          ← 新增切换，默认按日期
  按日期：现有「选择起止日期」日历
  按星期：起始周、截止周、星期（可搜索多选）

源节次（可多选）             ← 不变

目标日期
  [按日期 | 按星期]          ← 同上
  按日期 / 按星期 字段同源日期

目标节次（可多选）           ← 不变

课程                       ← 新增，紧跟目标节次
  可搜索下拉，可多选
  未选 = 不限制课程

[确定生成调课明细] [清空]
提示：多选日期和节次时，按顺位对应调课（第 N 个源日期→第 N 个目标日期，第 N 个源节次→第 N 个目标节次）
明细表 …
```

切换模式时：

- 清空该侧已选日期 / 周次 / 星期，并清空调课明细（与改日历后清空 `preview` 一致）。  
- 另一侧模式与已选值不动。  
- 按星期展开后的日期写入该侧 `dates`，后续命中、映射、天数校验仍走 `dates`。

### 3.2 按星期展开规则

设起始周 `W1`、截止周 `W2`（`W1 ≤ W2`），星期集合 `D`（1–7）。

1. 用当前学年学期教学周数校验周次（`getOfferingTermTeachingWeeks`）。  
2. 对 `W1…W2` 的每个教学周、`D` 中每个星期，用学期开始日算出具体 `YYYY-MM-DD`。  
3. 按日期升序去重，得到 `dates`。  
4. 按钮摘要示例：`第1–8周 · 周一、周三（16 天）`。

源、目标可一边按日期、一边按星期；只要展开后天数相等即可生成。

### 3.3 课程筛选

- 选项：当前学期已排课任务（`getScheduleTaskRows()`），展示 `课程号 课程名称`，value 用课程号。  
- 搜索：课程号 / 课程名称模糊。  
- 生成明细时：已选课程号集合非空，则 `collectAdjustmentBatchHits` 只保留 `task.code` 命中集合的行。  
- 未选：保持现状（命中源日期+节次的全部课；无命中时仍可走现有演示行）。

### 3.4 明细表

| 列 | 说明 |
| --- | --- |
| … 调整后节次 | 不变 |
| **调后教室** | **新增**，紧跟调整后节次 |
| 冲突情况 | 不变，改教室后按新教室重算 |

调后教室单元格：

- 展示选择器按钮（复用 `.adj-pick-btn` 观感），文案为教室名；空则「选择教室」。  
- 点击打开 `#modal-schedule-room-picker`。  
- 确定后写回该行 `targetRoom`，刷新该行文案并 `annotateAdjustmentBatchTimeConflicts`。  
- 默认：`targetRoom = 原教室`（生成明细时带出）。

### 3.5 提交与归档

- 提交时：除改星期/节次外，若 `targetRoom` 有值则写回 `slot.room`，并 `persistTaskSchedule` / `syncScheduleTaskRoom`。  
- `serializeAdjustmentBatchDetailRows('time')` 增加 `targetRoom`。  
- 批量调课记录详情表在「调整后节次」后增加「调后教室」。  
- 列表页「目标」摘要仍可只显示日期范围 + 节次，不必把每行教室拼进列表（详情里看）。

## 4. 代码改动

### 4.1 `index.html`（仅时间 Tab）

`#adjustment-batch-tab-time .adjustment-batch-form`：

1. 源日期、目标日期各包一层模式切换：  
   `#adjustment-batch-time-date-mode` / `#adjustment-batch-timeTarget-date-mode`  
   值 `date` | `weekday`。  
2. 按日期区：沿用现有 `#adjustment-batch-time-date-btn`、`#adjustment-batch-timeTarget-date-btn`。  
3. 按星期区（默认隐藏）：  
   - `#adjustment-batch-time-week-from` / `#adjustment-batch-time-week-to`  
   - `#adjustment-batch-time-weekdays`（多选）  
   - 目标侧对应 `timeTarget-*`。  
4. 目标节次后新增：  
   `#adjustment-batch-time-courses`（`select multiple`，由专用增强包一层可搜索 UI）。  
5. `#adjustment-batch-table-head` 增加常驻提示（不要只用 `#adjustment-batch-time-tip` 的 hidden 错误条）：  
   文案见 §3.1。  
6. 明细表头在「调整后节次」后加 `<th>调后教室</th>`。

批量调教室 Tab 的 HTML **不动**。

### 4.2 `app.js` 状态

```javascript
ADJUSTMENT_BATCH_STATE.time = {
  dates: [], range: { start: '', end: '' },
  dateMode: 'date',           // date | weekday
  weekFrom: 0, weekTo: 0, weekdays: [],
  courseCodes: [],            // 多选课程号
  preview: [], files: [], generatedKey: ''

ADJUSTMENT_BATCH_STATE.timeTarget = {
  dates: [], range: { start: '', end: '' },
  dateMode: 'date',
  weekFrom: 0, weekTo: 0, weekdays: []

```

`room` 状态不扩字段。

建议新函数（名称可微调，职责如下）：

| 函数 | 职责 |
| --- | --- |
| `syncAdjustmentBatchDateMode(kind)` | 切换按日期/按星期显隐，清空该侧已选并清明细 |
| `fillAdjustmentBatchWeekSelects(kind)` | 填起始/截止周 option |
| `expandAdjustmentBatchWeekdayDates(weekFrom, weekTo, weekdays, termCode)` | 周×星期 → 日期数组 |
| `syncAdjustmentBatchWeekdayDates(kind)` | 按星期侧把展开结果写入 `dates` |
| `initAdjustmentBatchCourseSelect()` | 灌课程 option + 挂可搜索多选 |
| `getAdjustmentBatchSelectedCourseCodes()` | 读已选课程号 |
| `openAdjustmentBatchTimeRowRoomPicker(rowIndex)` | 打开教室弹窗，mode=`batchTimeRow` |
| `applyAdjustmentBatchTimeRowRoom(room)` | 写回 `preview[rowIndex].targetRoom` 并重算冲突 |

改现有函数（时间侧分支，教室侧早返回 / 保持原样）：

| 函数 | 改动 |
| --- | --- |
| `validateAdjustmentBatchTimeForm` | 按星期时校验起止周、星期非空；`weekFrom ≤ weekTo`；先展开再比天数 |
| `getAdjustmentBatchTimeSelectionKey` | 纳入 `dateMode`、周次、星期、课程号 |
| `collectAdjustmentBatchHits` | `kind==='time'` 且已选课程时按课程号过滤；教室侧不走课程过滤 |
| `previewAdjustmentBatch('time')` | 行上带 `targetRoom: h.room` |
| `renderAdjustmentBatchPreview('time')` | 新列选择器；`colspan` 11→12 |
| `checkAdjustmentBatchTimeRowConflict` | 场地冲突改用 `row.targetRoom \|\| row.room` |
| `confirmAdjustmentBatch('time')` | 写回调后教室 |
| `serializeAdjustmentBatchDetailRows` / `renderAdjustmentBatchDetailTable` | 时间明细增加 `targetRoom` |
| `resetAdjustmentBatchForm('time')` | 重置新字段与课程下拉 |
| 教室弹窗确认 | `scheduleRoomPickerMode === 'batchTimeRow'` **独立分支早返回**，不要改 `batch` / `lockRoom` / 排教室分支 |

`initAdjustmentBatchMultiChecks`：只继续灌节次格；课程下拉另函数初始化，避免教室 Tab 被带上课程 UI。

### 4.3 可搜索多选（抽屉内）

现有 `shouldEnhanceScheduleSearchableSelect`：

- `select.multiple` → 不增强；  
- 祖先是 `.modal-overlay` → 不增强。

因此课程、星期多选 **不要指望页面级 ss-wrap 自动生效**。

实现建议：

- 在抽屉内做专用组件（如 `.adj-batch-ss-multi`）：输入框过滤 + 下拉勾选 + 已选标签。  
- 原生 `<select multiple hidden>` 或 hidden input 存值。  
- 不要修改全局 `enhanceScheduleSearchableSelect` 的「跳过 multiple / 跳过 modal」规则，以免排课页下拉行为变化。

星期多选、课程多选共用这一套即可。

### 4.4 教室弹窗分支（独立性）

`applyScheduleRoomPicker`（或当前确认选教室处）增加：

```javascript
if (scheduleRoomPickerMode === 'batchTimeRow') {
  applyAdjustmentBatchTimeRowRoom(scheduleRoomPickerSelected);
  scheduleRoomPickerMode = 'schedule';
  closeModal('modal-schedule-room-picker');
  return;
}
```

禁止为该需求改：

- `#schedule-grid-context-menu` / 时间侧 `applyScheduleContextMenuVisibility`  
- `#schedule-room-grid-context-menu`  
- 排教室锁定 / 待定 / 撤回  

`openAdjustmentBatchTimeRowRoomPicker` 只设置 mode、当前行下标、已选教室，再 `renderScheduleRoomModalRows()`。

### 4.5 `styles.css`

仅加抽屉内样式，例如：

- `.adj-batch-date-mode` 切换条  
- `.adj-batch-weekday-fields` 起止周 + 星期一行排布  
- `.adj-batch-ss-multi` 可搜索多选  
- `.adj-batch-order-hint` 明细顶提示  
- `.adj-batch-time-preview .adj-pick-btn` 调后教室选择器

不改排时间 / 排教室课表格样式。

## 5. 校验与提示

| 场景 | 行为 |
| --- | --- |
| 按星期未选起止周或星期 | 不能生成；提示补全 |
| 起始周 > 截止周 | 不能生成 |
| 展开后天数为 0 | 不能生成（周次/星期与学期对不上） |
| 源、目标展开后天数不一致 | 沿用现文案：天数不一致 |
| 源、目标节次数不一致 | 沿用现文案：节次数不一致 |
| 已生成后又改日期模式/周/星期/课程/节次 | 清空明细，须重新点「确定生成」 |
| 明细有冲突 | 仍禁止提交；改调后教室后重算，冲突消失才可提交 |

`#adjustment-batch-time-tip` 继续只承担生成结果 / 错误；顺位说明用常驻 hint，不 `hidden`。

## 6. 自检

改完前确认：

- 只打开批量调教室：表单、明细、选教室是否与改前一致？  
- 只打开批量调时间：是否仅出现本节四项变化？  
- 排时间侧、排教室侧课表与右键是否完全未动？  

任一为「否」→ 拆开改动，撤回对另一侧的影响。

## 7. 建议改动顺序

1. HTML：模式切换、按星期字段、课程下拉、明细顶提示、调后教室列。  
2. 状态 + 按星期展开 + 校验 / `generatedKey`。  
3. 课程可搜索多选 + `collectAdjustmentBatchHits` 过滤。  
4. 明细顶提示文案；确认映射仍按排序顺位。  
5. 调后教室列 + `batchTimeRow` 弹窗分支 + 冲突改用目标教室 + 提交 / 详情归档。  
6. 重置、样式、自检教室 Tab 与排课两侧。
