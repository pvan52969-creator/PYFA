# 二级菜单需求文档 · 版本与变更说明规范

> 与 Cursor 规则 `.cursor/rules/prd-versioning-change-notes.mdc` 同步。  
> 变更说明模板：[`../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx`](../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx)

## 1. 原则

| 原则 | 说明 |
|------|------|
| 母文件夹 = 一级菜单 | 二级菜单文档放在对应一级菜单目录下 |
| **每版本一文件夹** | `二级菜单/<菜单><日期><Vn>/` 内放该版 md/docx；变更说明放在**新版**文件夹 |
| 禁止覆盖 | 不得用新内容覆盖已有版本文件夹内的 md/docx |
| 升版递增 | 同菜单下次产出为新版本文件夹；允许跳号（如废弃 V3 后直接 V2→V4） |
| 变更必随 | 凡升版须同时产出「变更说明」（对齐简版模板），对照**上一有效版本** |

```

```

## 3. 变更说明必填项（简版模板）

1. 版本信息（文档名、V_ → V_、日期、确认状态）  
2. 本次改了什么：类型 ∈ {新增, 修改, 删除, 澄清}，一行一事  
3. 前后对照（复杂时）  
4. 连带影响（影响原型/开发/测试时）

## 4. 操作提示

```bash
# 升版生成 PRD（写入新版本文件夹；不会覆盖已有 Vn）
.venv-doc/bin/python scripts/generate-submenu-prd-docx.py --bump --date 20260810

# 生成/补全变更说明（对照上一有效版 → 本版；输出到本版文件夹）
.venv-doc/bin/python scripts/generate-submenu-prd-change-note.py \
  --menu 开课计划 --from V2 --to V4
```

无需求差异时不要空升版。废弃中间版时删除对应版本文件夹，下一版变更说明直接写旧有效版→新版。
