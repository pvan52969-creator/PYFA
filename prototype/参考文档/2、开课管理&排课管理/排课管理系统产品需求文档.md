## 模块范围

排课基础设置、排课表时间、排课表教室、课表查询、调课管理。对应原型 `#sidebar-nav-schedule`。

## 主流程

排课基础设置 → 排课表时间（提交）→ 排课表教室 → 课表查询 → 调课管理

## 双阶段

| 维度 | 排课表时间 | 排课表教室 |
|------|------------|------------|
| 主职责 | 星期/节次/周次 + 场地类型/备注/锁定教室 | 具体教室 |
| 课表布局 | 行=星期，列=节次 | 行=教室，列=节次 |
| 冲突 | 教师/学生/软冲突/预重修/先修 | 教室时间/座位/类型 |
| 列表入口 | 按入学批次/教师/课程 | 按时间排/按场地类型排 |
| 流转 | 提交 → 教室侧 | 派教室 → 课表查询 |

## 关键交互（时间侧）

- **提交（保留）**：列表勾选范围后批量「提交至排课表教室」；详情页右上角「提交」将当前范围排时间结果提交至教室侧（可含未排完确认）；提交后该范围只读
- 初始化不显示排课场地设置；选中已排单元格或右键「设置场地类型」后显示
- 左键选中整格（格内全部已排节次）；右键指向具体课程卡片（角标箭头）
- 课表卡片默认可显示排课场地（场地类型）
- 课程号后学时进度图标：绿勾已排完 / 蓝叹号未排完 / 红叹号超排

## 关键交互（教室侧详情）

- 左侧课程列表按同时段合并（同周次+星期+节次+教师）；多课号以反斜杠拼接
- 课程号后排教室进度图标：绿勾已排教室 / 蓝叹号未排教室
- 课表为教室×节次矩阵；选中左侧课程卡片时按排课场地过滤教室行
- 选教室抽屉顶部展示场地类型、场地备注、小组人数与节次摘要
- 侧栏「按课程排（教室）」已隐藏，保留页兼容旧深链；**仅教室侧**主列表已取消「发布课表」（不影响时间侧「提交」）

## 调课管理（2.2.6，已按六子菜单扩写）

| 子菜单 | 要点 |
|--------|------|
| 我的调课申请 | 教师发起四类申请、撤销、详情；冲突三维 |
| 调课申请审批 | Tab 待审/已提交/全部；驳回必填意见；通过回写课表 |
| 调课申请管理 | 代申请教师 + 整点半点；代申请是否进审批待确认 |
| 调课申请记录 | 汇总真实新增（排除演示/公假） |
| 公假日停课 | 新增自动停课 + 人事确认；免审批 |
| 批量调课管理 | 批量调时间/调教室；免审批直接写回 |
