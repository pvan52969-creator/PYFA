## 2. 建设目标与范围

### 2.1 目标

规范专业开课**计划层**：从已锁定执行计划生成学期开课任务，维护教学任务基础信息与合班（未生效时），批量**生效**后进入开课安排。

### 2.2 范围内

- 从执行计划候选生成开课任务（1 门课 × 1 专业 × 1 入学批次 = 1 条计划行）
- 修改教学任务：起止周、预留、选课类型、排课/排场地等开关、教室属性与偏好
- 合班 / 一键合班（仅未生效草稿互合）
- 计划批量生效、删除（非已生效）
- 预置人数查看、操作记录

### 2.3 非目标（不在本菜单）

- 不含任务安排三步（师资、授课确认）——见《开课安排》
- 不含名单维护
- 不含通识选修 / 特殊开课计划
- 计划已生效后合班改在「开课安排」完成

## 3. 用户角色与使用场景

| 角色 | 场景 | 目标 |
|------|------|------|
| 教务 | 学期开课前 | 从执行计划生成并完善计划行 |
| 教务 | 多专业批次需合班 | 在未生效阶段合并为同一课程班 |
| 教务 | 计划信息确认完毕 | 批量「生效」，使任务进入开课安排 |
| 学院 | 合班协作（权限待确认） | 与教务共同完成合班 |

## 4. 在整体业务链路中的位置

```text
开课时间设置（默认展示学期）+ 培养方案执行计划（已锁定）
        ↓
   【开课计划】→ 生效 → 【开课安排】→ 授课确认齐套 → 任务生效 → 【开课名单】
        ↑                    │
   退回（保留合班）←──────────┘
```

特殊课程设置提供 Support 历史与教室默认（安排侧带出）；本页为专业开课主链路第一站。

## 5. 主业务流程

1. 确认开课时间设置中已有「默认展示学期 = 是」。
2. 打开「生成开课任务」，从已锁定执行计划勾选候选，生成草稿计划行（默认不合班）。
3. 逐条或批量编辑教学任务（起止周、人数口径、开关、教室等）；可选一键合班。
4. 勾选草稿/回退计划，工具栏「生效」→ 状态变为已生效，出现在开课安排列表。
5. 若需退回修改，须经开课安排「退回」至回退状态后再编辑；已生效计划不可在本页删除。

**跨模块约束（计划层视角）：** 本页仅负责计划生效；任务安排生效及授课确认齐套发生在开课安排，名单维护以任务已生效为前提（见开课安排 / 开课名单概要设计）。

## 6. 职责边界

| 职责 | 说明 |
|------|------|
| 负责 | 计划行生成、教学任务基础信息、未生效合班、计划层生效/删除 |
| 不负责 | 分组、教师安排、授课确认、名单、排课 |
| 与他模块交接点 | 已生效计划 → 开课安排可见；Support 历史 ← 特殊课程设置；默认学期 ← 开课时间设置 |
