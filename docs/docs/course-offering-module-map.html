专业开课泳道
  1. 前置：培养方案执行计划已提交 + 开课时间设置有效
  2. 开课计划：按学期/专业批次生成任务；可点「特殊开课」从课程库加行
  3. 计划生效 → 开课安排：Course Setting → 师资安排；生效须授课确认齐套
  4. 开课名单：按小组维护学生；教务退回 = 安排撤回效果
选修开课泳道
  1. 前置：校选课程管理有库 + 开课时间设置有效
  2. 选修开课计划：类型配额 / 组数标准（不是专业那种「生成任务再生效」）
  3. 选修开课安排：加课、分组师资后生效
  4. 选修开课名单：开放选课相关；退回保持确认状态
并行支路：Teaching Load（学时统计）· 授课确认管理 / 教师端 · 授课教师替换 · 课程班统一停课。排课计划入池看安排已生效，不以确认齐套为门槛。
讲解时别跳过：共同授课/联动、同时授课、生效完整度与 Coordinator、合班与教师替换、教室偏好、Support、可选范围、一键分配 — 左侧目录「关键规则」，测细则以专节为准。

开课设置 · 开课时间设置

开课设置配置「哪个学期可以开课」以及教师确认截止日期。

  • 作用：维护各学期开课时间范围、教学周数、授课确认截止日期；可按单位展开细调。
  • 新增：仅列出尚未配置开课时间的学期；教学周数按学期类型固定。
  • 确认截止日期：只要日期即可；可设已过期日期；不随开课窗口是否截止而锁定；教师端确认信函 Notes 取自此设置。
  • 规则：无当前有效开课学期时，后续生成/安排应受阻（测试拦截提示）。

开课设置 · 校选课程管理

开课设置选修开课的课程库与分类；修读范围真源之一。

  • 按校选类型 Tab 管理课程（GE/ME、类别、修读范围等）。
  • 选修开课计划 / 安排加课应引用本库，不混用专业课生成逻辑。
  • 修读范围细则见 可选范围（年级·专业）；校选侧栈为「类型 → 年级 → 专业」（无可选批次行）。
  • 测试：库内课程能否进入配额与安排；库外课号不可冒充选修。

开课设置 · 特殊课程设置

开课设置课号级默认教室偏好 / Support 专业，供新开课带出。

  • 从教务课程库手动纳入课号，维护四类学时教室偏好与默认 Support 专业（现行口径，非学院）。
  • Support 历史：有勾选默认 Support 专业 → Y，未勾选 → N；不可手改；未纳入清单课号下游视为 N。
  • 专业开课安排新建或仍为系统默认的班会自动带出；班级覆盖不回写本页。
  • 已生成数据不随本页再改（改配置只影响后续新建；删除清单也不回滚已落班）。
  • 细则见 教室偏好、Support 专业。

专业开课 · 计划 → 安排 → 名单

开课计划

生成学期开课任务

  • 一课 × 一专业批次 → 一条计划。
  • 依赖已提交执行计划 + 开课时间。
  • 「特殊开课」从课程库加行并标记，与专业开课并列进安排/名单。
  • 合班副作用见 合班 · 教师替换；计划生效后进入安排。

开课安排

样式2 · 两步条

  • Step1 Course Setting（含 Support / 教室默认带出）；Step2 师资 / 授课确认 / 共同授课。
  • 安排生效见 生效完整度 · Coordinator（确认齐套为硬门槛之一）。
  • 学院「撤回」：已生效→草稿，分组教师保留，确认不变；已排课须先清排课。
  • 安排页「退回」：未生效安排退回计划并清空分组教师（另一条规则）。
  • 共同授课 / 同时授课 / 联动 / 教室偏好见「关键规则」专节。

开课名单

按小组维护学生

  • 任务安排提交（已生效）后维护名单。
  • 教务「退回」效果同安排撤回：已生效→草稿，确认不变；名单只清分组归属。
  • 有小组时可用预置名单 + 一键分配（细则见专节）；可入名单学籍：Active + Normal。
易混三点：① 计划「生效」≠ 安排「生效」；② 安排「退回计划」≠ 学院「撤回」≠ 名单「退回」；③ 撤回/名单退回不取消授课确认。

选修开课 · 计划 → 安排 → 名单

选修开课计划

配额 / 组数标准

  • 按类型维护配额与组数，不是专业「生成任务再生效」。
  • 依赖校选课程库。

选修开课安排

加课 · 修读范围 · 分组师资

  • 在安排页加课；Step1 可改修读范围 / Support；分组、排教师后生效。
  • 修读范围相对校选多「可选批次」行；已生效后修读范围只读。
  • Support：不可选本课所属部门下专业；保存后共享给所选专业。
  • 分组工作台：显示 GE 配额条；隐藏预置/一键分配。

选修开课名单

开放选课侧

  • 退回：生效→草稿，授课确认保持；选课应用名单不再保留，手动添加仍保留。
  • 无预置名单 / 无一键分配（与专业名单对照测）。

关键规则 · 共同授课 & 联动组

安排 Step2 两层概念：先「共同授课组」，再「联动安排」。不要混成一件事。

A. 共同授课（一组模型）

  • 一组共用一个内部标记，不是两两独立配对；组内 ≥2 个不同教学班（可同课号）。
  • 入口：安排列表「共同授课」；须未生效且已有任课教师；已生效不可再设。
  • 添加条件：与入口课至少有一名相同任课教师；对方未在其他组（在他组须先移出）。
  • 入口课已有组员时再添加 → 先确认「加入共同授课组」；两门都未成组可直接加。
  • 移出：只离开本组；剩 ≥2 仍同组；仅剩 1 门则一并清标记。
  • 替换/移除教师不自动解绑；要拆只能在共同授课设置里手动移出。
  • 本版不要求新课与组内每一门都有共同教师；组内已无共同教师仍不解绑。
  • 排课时该共同教师可为组内这些班忽略时间冲突（排课侧语义）。

B. 联动组（同堂排课绑定）

  • 在共同授课组内，把多班的学时安排行绑成联动组；入口：「配置共同授课 / 管理联动安排」。
  • 建立条件：仅要求周次、周学时一致；组内至少 2 个教学班。
  • 绑定后：排课将同时间同教室；开课侧不强制教室偏好相同。
  • 加入共同授课组不会自动建联动；同堂须手动绑定联动。
  • 可点「查看」看联动组明细；排课计划里「联动组」与「同时授课」分两列展示。
一键同步共同授课（专业安排工具栏）：只按权限+当前筛选，给特殊课程已关联、课号不同、仍有共同任课教师、且尚未打标的班补绑定；不并已有组、不解绑；会把两个已有组连上的批次跳过。要拆仍只能手动移出。
与「同时授课」区分：同时授课细则见下一节；联动组 = 跨班共同授课后的排课同堂绑定。排课计划入池时，共同授课另须关联班均已生效且学时安排/联动组齐套。

关键规则 · 同时授课（对照联动组）

安排详情学时行 同课多小组是否「合班上课计一次学时」——不要和跨班联动搞混。

  • 控件须手动选择「是 / 否」；新增安排行默认为空（未选不可糊弄过去）。
  • 选多个小组 + 是：合班同时授课，Teaching Load / 学时只计一次。
  • 选多个小组 + 否：保存后自动拆成每个小组一条（学时类型 / 周次 / 周学时 / 总学时 / 教师不变）。
  • 与联动组：排课计划里「同时授课」「联动组」分两列；一个管同课多组计学时，一个管跨班同堂排课。
同时授课联动组
范围同一教学班内的多个小组共同授课组内多个教学班的学时行
建立条件手动选是/否周次 + 周学时一致；组≥2 班
对排课多组可同堂（计学时语义）绑定后同时间同教室
对 Load「是」时学时只计一次不改变「是否同时授课」计法本身

关键规则 · 安排生效完整度 + Course Coordinator

开课安排 · 确认生效 测「为什么点不了生效 / 弹什么」时用本节。

A. 硬阻断（确认生效按钮禁用）

  • 已停课 → 无法生效。
  • 选修且计划总人数未填（空；0 算已填）→ 须先填。
  • 有小组时：组名非空且不重复；每组上限 >0；各组上限合计 ≤ 课程人数上限，且合计 ≥ 计划人数。
  • 师资/学时不完整：计划学时 >0 的类型须已安排教师；安排行须有教师、起止周、周学时；有安排行未选课程组不可生效；四学时全 0 仍须至少安排教师。
  • 真实教师（排除 TBC）须全部「已确认」或「管理端代确认」；未下发 / 待确认 / 不同意 → 硬阻断。
  • 有真实教师时 Course Coordinator 必填（见下）。

B. 二次确认仍可生效

  • 欠学时（尚未录满）、超学时 → 弹窗警示后仍可提交，不硬阻断。

C. 生效成功副作用

  • 锁定合分班、分组与教师安排。
  • 必修可去开课名单维护；选修默认名单由选课应用生成，仍可维护。

D. Course Coordinator

  • 有真实教师时：保存与生效均必填；仅一名真实教师 → 强制默认该人，无 ✎；多名 → 侧栏 ✎ 从本课真实教师中选（TBC 不可设）。
  • 已生效后仍可改 Coordinator（不解锁分组/教师安排）。
  • 更改不改变授课确认结果；确认管理/教师端信上的 Coordinator / Email 刷新为新值。
  • 已发送或已确认（含代确认/不同意）时改 Coordinator：二次确认；已发邮件正文不重写、不补发。
  • 仅改 Coordinator 不作废确认（与「改安排内容保存失效」区分）。
例外并存：开课安排「确认生效」入口永远要求确认齐套。生效后经「授课教师替换」或改安排保存导致确认回退时，安排可保持已生效——那是替换菜单的特例，再生效仍须齐套。

关键规则 · 合班副作用 + 授课教师替换

合班（专业开课计划）

  • 一致性：同课号 / 学分 / 总学时 / 起止周 / 选课类型；教学任务开关一致；任务已生效后不可合班。
  • 人数：计划人数、预留名额、课程名额上限均累加。
  • 副作用：清空相关班分组与教师；清教室偏好；任务安排重置草稿。
  • 选修开课安排页无合班入口（勿按专业抄测）。
  • 入口：专业开课计划操作列合/拆班（合分班独立页已下线）。

授课教师替换

  • 面向已生效班；单行或一键（同课该原教师全部安排行）。
  • 替换后：安排保持已生效，不得打回草稿，也不得要求再走安排「确认生效」。
  • 受影响且仍有本课任务的教师须重新下发/确认；班级确认可变为部分确认/未确认。
  • 「已生效 + 确认未齐套」并存仅本菜单允许；安排页再生效仍须齐套。
  • 共同授课：只改当前课号被操作行；关联课不换人；绑定保留（即使已无共同教师）；要拆只能手动移出。
  • 二次确认 tip 须分列：范围 / 不变 / 生效 / 确认；确认后邮件通知被替换教师。
口播对照：合班 = 计划阶段合并班，清空安排重来；教师替换 = 已生效后换人，保生效、确认可回退。两者都不会自动拆共同授课。

关键规则 · 教室偏好

特殊课程设置 → 安排学时行 → 排课计划

  • 定位：仅作排课参考；最终教室以排课安排为准（开课侧不保证排到偏好教室）。
  • 控件：多选下拉（可搜教室号/软件名），禁止自由文本；空 = 无偏好。
  • 过滤：选项按该学时行「场地类型」过滤。
  • 课号默认：特殊课程设置可按理论/辅导/实践/其他维护默认偏好；新建/仍为系统默认的班带出；班上改过不回写课号配置。
  • 合班副作用：合班成功会清分组/教师/教室偏好，任务安排重置草稿（测合班后偏好是否被清）。
  • 下游：排课计划只读展示偏好；对外对接字段含场地偏好。

关键规则 · Support 专业

特殊课程设置默认 · 安排侧可覆盖 现行对象是专业（Programmes），不是学院。

课号默认（特殊课程设置）

  • 维护「默认 Support 专业」多选。
  • Support 历史：勾选了默认专业 → Y，未勾选 → N；只读推导，不可手改。
  • 未纳入特殊课程清单的课号：下游 Support 历史视为 N。
  • 仅生成前已维护的设置会带出到新开课；已生成班不随本页再改。

开课安排 / 选修安排覆盖

  • 班上可改 Support；覆盖不回写课号默认。
  • 可选约束：不可选「本课所属部门 / 开课单位」下的专业（对齐「不可含本开课单位」）。
  • 选修安排：保存后共享给所选专业；计划/抽屉里 Support 历史只读展示。
  • 删除特殊课程清单项：已写入班上的 Support 值保留，以后新建不再带出。
讲解口播：Support = 这门课需要哪些外专业/外单位来「撑」师资或协作；历史 Y/N 告诉你这课号过去有没有走过 Support，不是手填开关。

关键规则 · 可选范围（年级 · 专业）

校选课程管理 · 选修开课安排 专业开课一般不走此栈（按专业批次生成）。

1. 修读范围栈布局

  • 栈外上方：可选学生类型。
  • 栈内固定顺序：类型 → 年级 → 专业；选修安排相对校选多一行「可选批次」。
  • 类型三态：可选 / 不可选 / 不限（都不选专业 = 全开放）。

2. 年级语义跟随「类型」

类型勾选年级的含义不勾任何年级
可选勾选 = 可修年级学期（存 eligibleYears）不额外限制年级
不可选勾选 = 不可修年级学期（存 excludedYears）不限制年级
不限年级行禁用并清空不限制年级

类型在可选 ↔ 不可选间切换时：保留勾选集合，只改变「可修/不可修」含义。

3. 专业范围与「初始化」默认

  • 可选：白名单专业可修；不可选：黑名单不可修；专业与年级都不限 → 全开放。
  • GE 初始化：Arts/Business/Science → 同大类专业设为不可选；Science 时 MAT 除外仍可选；「不限」类别 → 清空为全开放。
  • ME 初始化：有开课专业 → 开课专业 + MAT 设为可选；无开课专业 → 所属部门下专业 + MAT 设为可选。
  • 冲突课程 / 先修课程：修读范围抽屉可维护（校选侧）。

4. 选修安排「可选批次」

  • 白名单；空存 = 范围内全选。
  • 批次选择器：不在范围或受年级限制/无法折算的批次灰显；空草稿打开默认全选可选项。
  • 安排已生效后修读范围只读；选课端对批次的最终校验属下游（UC）。

关键规则 · 一键分配名单

专业开课 · 开课名单工作台 选修侧强制隐藏，勿按专业抄测。

何时出现 / 谁不能用

  • 专业名单：有小组（含唯一组）才显示；无小组学生在课程班上，不走一键分配。
  • 选修 / 开放选课：预置名单与一键分配强制隐藏。
  • 可入名单：Active + Normal；分配前课程名单人数不得超过各组人数上限合计。

规则弹窗（必测 tip）

  • 维度（可多选）：国籍类型 · 专业 · 入学批次 · 性别。
  • 每维模式：等比例 / 按顺序 / 唯一值。
  • 优先级：1～已勾选数的连续正整数，越小越优先；改任一后其余自动重排。
  • 未勾选维度不参与；至少选一个维度才能开始。
  • 另有「按学号顺序」开关（默认 Y）。
  • 成功后再打开回填上次规则。

执行副作用与边界

  • 跳过「手动添加」学生，不纳入自动分配。
  • 遵守各组人数上限；满员无法入组须显式提示，不静默丢弃。
  • 「重置分组」：撤销全部入组（不删平行分组），并清空本次规则勾选/模式/优先级。
  • 与预置名单并存：预置也可按勾选学号分配，同样跳过手动添加。
  • 名单列表「分配状态」：missing=无人或有人未进组；warn=已分配超名额上限；ok=全部分配且未超限（不是草稿/排课枚举）。
  • 改分组人数上限：允许各组上限合计超过课程人数上限，保存后按差额抬高预留，计划人数不变。
对照口播：专业 = 预置 + 一键分配帮老生班拆组；选修 = 选课应用推名单，工作台只做维护/手动添加，没有一键分配。

课程班管理 · 课程班 / Teaching Load / 授课确认

课程班

  • 汇总专业开课（含特殊）+ 选修已开出 section（草稿/已生效/停课）。
  • 停课统一在本页：不可撤销；该组学时出 Load；同课其他组不受影响；全组停完才清整课排课。

Teaching Load

  • 周学时×周次；多组且同时授课=是时学时只计一次。
  • 超限阈值可空（空=不标红）；停课组学时不再计入。

授课确认管理

  • 管理端发送、代确认、跟踪状态；draft/disagreed 可发；pending 可代确认。
  • 已确认安排被回头修改并保存且相对快照有变化→ 变未确认；仅改 Coordinator 不变确认。
  • 未改动保存、撤回、名单退回 → 不取消确认。
  • 截止日解析：个人 > 学院 > 全校（学院/个人不得早于全校）。

授课确认（教师端）

  • Pending 列表：确认 / 不同意（不同意必填意见）。
  • Notes 截止日取解析后的生效日（个人 > 学院 > 全校）。

课程班管理 · 授课教师替换 / 排课计划

授课教师替换

  • 面向已生效班替换教师；细则见 合班 · 教师替换。
  • 保生效、确认可回退；共同授课不解绑。

排课计划

  • 下游排课入池视图。
  • 门槛：安排已生效；不以授课确认齐套为入池条件（替换后未齐套仍入池）。
  • 停课排除；共同授课另须关联班均已生效且学时/联动齐套。

关键门槛与易错点（必讲）

主题正确口径常见误解
授课确认何时变未确认 已确认安排被修改并保存，且相对已确认快照有实质变化 以为撤回/名单退回/未改保存都会清确认
安排生效 结构+师资学时完整+真实教师确认齐套+有教师时 Coordinator 必填；欠/超学时可警告仍生效 以为只填完教师就能生效；或欠学时被硬拦
Course Coordinator 有真实教师必填；TBC 不可设；改 Coordinator 不废确认、已发邮件不重写 以为改 Coordinator 会作废确认或解锁安排
合班 一致性校验后累加人数；清分组/教师/偏好；回草稿；已生效不可合；选修无合班 以为合班后安排原样保留
教师替换 保生效、确认可回退；只换本课；共同授课不解绑 以为会打回草稿或自动拆共同授课
排课计划入池 看安排已生效 以为必须确认齐套才能进排课
撤回 / 名单退回 已生效→草稿；分组教师保留；确认不变；已排课先清排课 与「退回计划」（清空分组教师）搞混
特殊开课 计划页按钮加行，走专业安排/名单；停课在课程班 找已下线的「特殊开课」侧栏
特殊课程设置 默认带出给新建班；不回写已生成班；Support 历史由是否勾选默认专业推导 改设置期望历史班一起变；或手改 Support 历史 Y/N
共同授课 vs 联动组 先打共同授课标记；联动须手动绑（周次+周学时）；加入组不自动联动；换教师不解绑 以为加共同授课就会同堂；或换教师自动拆组
同时授课 vs 联动组 同时授课=同课多小组是否合班计学时；联动=跨班同堂排课绑定；排课计划分两列 揉成同一列/同一概念
教室偏好 多选参考、按场地类型过滤、空=无偏好；排课以实排为准 当成强制排到该教室；或当自由文本填
Support 对象 现行为 Support专业；不可选本课所属部门下专业 仍按旧「Support 学院」测；或可选本开课单位专业
修读范围年级 语义跟随类型（可选=可修 / 不可选=不可修 / 不限=禁用）；切换类型保留勾选只改含义 年级永远当排除集；或不限时仍可勾年级
一键分配 专业有组才有；跳过手动添加；优先级连续；选修强制无此按钮 选修也能一键分配；或把手动添加学生一并自动分
建议讲解顺序：主流程 5 步 → 专业泳道跑通 → 选修对比 → 关键规则（共同授课/联动 → 同时授课 → 生效完整度·Coordinator → 合班·替换 → 教室偏好 → Support → 可选范围 → 一键分配）→ 课程班停课与排课入池 → 易错表收尾。

讲解检查清单（可勾）

  • □ 侧栏四大分组与当前原型一致（无特殊开课独立分组）
  • □ 画出专业 vs 选修两条泳道差异（计划形态不同）
  • □ 演示或口述：计划生效 → 安排两步 → 确认齐套 → 安排生效 → 名单
  • □ 说清三种「退/撤」：安排退回计划 / 学院撤回 / 名单退回
  • □ 生效硬阻断清单 + 欠/超学时仍可生效；Coordinator 必填且改之不废确认
  • □ 同时授课：是=学时计一次 / 否=拆行；与联动组对照表说清
  • □ 合班副作用（清安排回草稿）+ 教师替换保生效、确认可回退、不解绑共同授课
  • □ 说清确认失效主因 + 排课入池不看确认齐套
  • □ 共同授课一组模型 + 换教师不解绑 + 一键同步只补不拆
  • □ 联动组：周次/周学时一致、排课同堂、加入组不自动联动
  • □ 教室偏好=参考多选；空=无偏好；合班会清偏好
  • □ Support=专业；历史由勾选推导；不可选本部门专业；不回写课号默认
  • □ 修读范围：类型→年级→专业；年级语义随类型；GE/ME 初始化差异；选修多可选批次
  • □ 一键分配 tip 全条；跳过手动添加；选修无预置/无一键
  • □ 停课只在课程班且不可撤销；确认截止个人>学院>全校
  • □ 提醒已下线入口不要写进测试用例
