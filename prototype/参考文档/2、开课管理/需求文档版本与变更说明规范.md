# 二级菜单需求文档 · 版本与变更说明规范

> 与 Cursor 规则 `.cursor/rules/prd-versioning-change-notes.mdc` 同步。  
> 变更说明模板：[`../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx`](../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx)

## 1. 原则

| 原则 | 说明 |
|------|------|
| 母文件夹 = 一级菜单 | 二级菜单文档放在对应一级菜单目录下 |
| V1 为基线 | 当前各菜单 `…20260803V1` 为正式 V1，保留不删 |
| 禁止覆盖 | 不得用新内容覆盖已有版本的 md/docx |
| 升版递增 | 同菜单下次产出为 V2、V3…，文件名带新日期 |
| 变更必随 | 凡升版须同时产出「变更说明」（对齐简版模板） |

## 2. 目录与命名

```
参考文档/2、开课管理/
  开课设置/
    开课时间设置/<菜单><YYYYMMDD>Vn.md|.docx
    特殊课程设置/…
  专业开课/
    开课计划/…
    开课安排/…
    开课名单/…
  需求文档版本与变更说明规范.md
```

变更说明与对应 PRD 同目录：

```
<菜单><旧日期>V1→<新日期>V2变更说明.md|.docx
```

## 3. 变更说明必填项（简版模板）

1. 版本信息（文档名、V_ → V_、日期、确认状态）  
2. 本次改了什么：类型 ∈ {新增, 修改, 删除, 澄清}，一行一事  
3. 前后对照（复杂时）  
4. 连带影响（影响原型/开发/测试时）

## 4. 操作提示

```bash
# 升版生成 PRD（不会覆盖已有 Vn；需显式指定下一版本）
.venv-doc/bin/python scripts/generate-submenu-prd-docx.py --bump --date 20260810

# 生成/补全变更说明（对照上一版 → 本版）
.venv-doc/bin/python scripts/generate-submenu-prd-change-note.py \
  --menu 开课计划 --from V1 --to V2
```

无需求差异时不要空升版。
