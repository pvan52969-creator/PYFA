## 1. 文档目的

规范校选课程（校内选修）**主数据池**的维护：纳入课程、状态、修读范围、开课默认教学设置，作为通识选修开课计划的候选课库与默认值来源。

## 2. 功能概述

- 维护校选课程清单（**GE** 通识选修 + **ME** 专业选修类校选）。
- **修读范围**：可选/不可选专业（互斥）、可选学生类型、不可选年级学期、冲突课程、先修课程。
- **开课默认信息**：Support 历史、状态、是否排课/排场地/考勤/录入成绩/排考、备注；学时与学分只读。
- **不**在本页维护计划人数、预留名额、起止周、分组与教师（在通识选修开课侧维护）。
- **不**按入学批次细化修读范围（范围到专业；该专业全部入学批次适用）。

### 2.1 入口拆分

| 列表操作 | 能力 |
|----------|------|
| 修读范围 · 查看 | 只读弹窗 |
| 修读范围 · 设置 | 抽屉维护修读范围 |
| 课程信息 · 修改 | 抽屉维护开课默认教学设置与状态/备注 |

### 2.2 数据来源（原型）

| 类型 | 来源 | 本页「新增」 |
|------|------|--------------|
| GE | GE Restrictions List 种子同步 | **不可**从课库新增 |
| ME | 教务课程库 `Major Elective` | **可**从课库纳入 |

## 3. 角色与权限（原型约定）

| 角色 | 能力 |
|------|------|
| 教务 | 查询、新增 ME、批量改状态、删除、设置修读范围、修改开课默认 |

## 7. 业务规则

### 7.1 类型与校选课类别

| 规则 | 说明 |
|------|------|
| 类型 | `GE` / `ME`；可由 `electiveType` 或课程分类推断（major→ME，默认 GE） |
| GE 类别 | `arts` / `business` / `science` / `unrestricted` |
| ME | `geCategory` 强制为空；列表显示「—」 |
| GE 课号缺省类别 | `G01…`/`G1×`→arts；`G02…`/`G2×`→business；`G03…`/`G3×`→science；其余→unrestricted |

### 7.2 课程纳入

1. **GE**：由 Restrictions List（或等价同步）进入池；本页「新增」**不**提供 GE。  
2. **ME**：仅课库 `Major Elective`；按 catalogId / 课号去重。  
3. 新纳入默认：状态=正常；学生类型三种全选；先修取自课库；修读范围按 §7.3 初始化。

### 7.3 修读范围 · 专业

| 规则 | 说明 |
|------|------|
| 互斥 | `eligibleProgrammeKeys` 与 `excludedProgrammeKeys` **不可同时非空** |
| 全开放 | 两者皆空 → 全部专业可选（展示「全开放」） |
| 限制类型展示 | 有可选名单→可选；仅有不可选→不可选；皆空→不限 |
| **初始化 · ME** | 可选 = 本课开课单位（学院）下全部专业；不可选为空 |
| **初始化 · GE unrestricted** | 皆空（全开放） |
| **初始化 · GE arts/business/science** | 不可选 = 同大类专业；**science 时 MAT 专业从不可选中剔除**（仍可选） |
| 存储 | 专业 key 小写 |

### 7.4 不可选年级学期

- 维度：Year1～Year4及以上 × Semester 1/2/3；存值如 `Y2S1`。  
- 空 = 各年级各学期均可选。  
- 年级勾选可级联该年三学期；支持半选。  
- 兼容旧整年值：展开为该年三学期。

### 7.5 可选学生类型

- 合法值：Local / Chinese / International。  
- 保存时 **至少勾选 1 种**。  
- 三种全选（或等效）展示为「全部学生类型」。

### 7.6 冲突课程 / 先修课程

| 类型 | 语义 | 候选 | 空值 |
|------|------|------|------|
| 冲突 | 已修冲突课的学生不可再选本课 | 校选课库（除本课） | 无冲突限制 |
| 先修 | 未修完先修课不可选本课 | 课库+校选（除本课） | 无先修限制 |

课号大写存储；过滤本课。

### 7.7 开课默认教学设置

字段无值时默认：

| 字段 | 默认 |
|------|------|
| Support 历史 | N |
| 是否排课 / 排场地 / 考勤 / 录入成绩 / 排考 | 是 |
| 选课类型（只读） | 开放选课 |

加入通识开课计划时，将上述开关与 Support 历史带入教学班默认值；`enrollmentType` 固定为开放选课。备注写入计划行备注（`offeringRemark`/`remark`）。

> 本模块默认「排场地/考勤=是」，**不**采用专业开课「学时全 0→否」规则（校选库侧无按班学时重算默认）。

### 7.8 状态

```
（新增/种子）──► 正常(active) ◄──► 停课(suspended)
                      │
                      └──删除──► 移出校选池
```

- 修改途径：批量弹窗、开课默认抽屉。  
- **停课课不可被选入通识开课计划**（候选仅 `electiveType=GE` 且 `status=active`）。  
- 无审批流。

### 7.9 删除

- 仅删除校选池记录，**不**删除教务课库。  
- 原型**未**拦截「已加入通识开课计划」的课（正式版建议拦截或强提示，见 §11）。

### 7.10 通识开课消费规则（下游）

| 环节 | 规则 |
|------|------|
| 候选 | 仅 GE + 正常 |
| 同学期 | 同一课程每学期仅可开课一次（已在计划中的不可再勾） |
| 修读范围默认 | 从校选带入专业模式与名单、学生类型、不可选年级学期、冲突/先修、备注；**不带入批次细化** |
| 教学默认 | Support 历史 + 五类是否开关 + 开放选课 |
| 学期覆盖 | 通识开课「修读范围」可按学期调整；任务安排生效后锁定 |

### 7.11 学时只读口径

- 总学时：课库 meta；缺省可按学分×14。  
- 四类学时：系统推算（理论约占 2/3 等，以实现为准）；本抽屉不可改。
