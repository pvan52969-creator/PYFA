XMUM 开课管理 · 操作流程

对齐当前侧栏：开课设置 → 专业开课 / 选修开课（计划 → 安排 → 名单）→ 课程班管理。特殊开课已并入专业开课计划页按钮，与专业开课并列走安排与名单。安排生效须齐套授课确认；停课统一在「课程班」。撤回 / 名单退回不取消确认；改已确认安排并保存才会变未确认。

开课设置 专业开课（含特殊开课） 选修开课 课程班管理
阶段说明（对照当前原型侧栏）

开课设置：开课时间设置、校选课程管理、特殊课程设置。专业开课依赖已提交执行计划；选修开课依赖校选课程库。特殊课程设置维护课号默认教室/Support，生成新开课时带出（已生成数据不随本页再改）。

专业开课：侧栏仅计划 / 安排 / 名单。计划页「特殊开课」从课程库加行，标记为特殊开课，与专业开课并列进入安排、名单。计划生效 → 安排（Course Setting / 师资，齐套授课确认后再生效）→ 名单。学院在安排页「撤回」、教务在名单页「退回」同一效果：已生效→草稿，分组与教师保留，授课确认不变；已排课须先清排课。安排页「退回」是另一件事：未生效安排退回计划并清空分组教师。

选修开课：计划是类型配额 / 组数标准，不是专业那种先计划再生效再安排。安排页加课、分组师资后生效。退回为生效→草稿，授课确认不变（按钮名未拍板）。

授课确认何时变未确认：仅已确认安排被回头修改并保存、且内容相对已确认快照确有变化。未改动保存、撤回、名单退回都不取消确认。生效后「授课教师替换」也可保持已生效、确认回退。

课程班管理：「课程班」汇总专业开课（含特殊开课）与选修开课已开出课程班（含草稿/已生效/停课）；停课统一在本页。Teaching Load、授课确认管理/教师端、授课教师替换为并列入口。排课计划入池看安排已生效，不以授课确认齐套为门槛。

数据粒度
计划按类型维护；特殊开课与专业开课同页；课程班侧汇总已开出 section
