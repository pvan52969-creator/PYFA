# 二级菜单需求文档 · 版本与变更说明规范

> 与 Cursor 规则 `.cursor/rules/prd-versioning-change-notes.mdc` 同步。  
> 变更说明模板：[`../../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx`](../../0、模板/厦大马来分校本科教务系统——需求调整变更说明模板（简版）.docx)  
> 路径映射脚本：[`../../../scripts/prd_folder_paths.py`](../../../scripts/prd_folder_paths.py)

## 1. 原则

| 原则 | 说明 |
|------|------|
| 母文件夹 = 一级菜单 | 二级菜单文档放在对应一级菜单目录下 |
| **序号前缀** | 一级 `NN_菜单名`；二级 `NN_菜单名`（与侧栏顺序一致，见下表） |
| **每版本一文件夹** | `<二级>/<菜单><日期><Vn>/` 内放该版 md/docx；变更说明放在**新版**文件夹 |
| 禁止覆盖 | 不得用新内容覆盖已有版本文件夹内的 md/docx |
| 升版递增 | 同菜单下次产出为新版本文件夹；允许跳号 |
| 变更必随 | 凡升版须同时产出「变更说明」（对齐简版模板），对照**上一有效版本** |

版本文件夹（在二级菜单下）：

```
<菜单名称><YYYYMMDD><Vn>/
  <菜单名称><YYYYMMDD><Vn>.md|.docx
  <菜单><旧日期><旧Vn>→<新日期><新Vn>变更说明.md|.docx
```

## 3. 变更说明必填项（简版模板）

1. 版本信息（文档名、V_ → V_、变更日期）  
2. 本次改了什么：类型 ∈ {新增, 修改, 删除, 澄清}，一行一事  
3. 前后对照（复杂时）  
4. 连带影响（影响原型/开发/测试时）

## 4. 操作提示

```bash
# 升版生成 PRD（V2 模板推荐）
python3 scripts/generate-prd-20260825-batch.py   # 或对应批次脚本

# 升版生成 PRD（0610 结构）
python3 scripts/generate-submenu-prd-docx.py --bump --date 20260810

# 生成变更说明
python3 scripts/generate-submenu-prd-change-note.py --menu 开课计划 --from V5 --to V6
```

无需求差异时不要空升版。
