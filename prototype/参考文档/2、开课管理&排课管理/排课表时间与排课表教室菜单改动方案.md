# 排课表时间 / 排课表教室 · 菜单与流转改动方案（修订版）

> 文档性质：改动方案（需求整理 · 修订）  
> 适用范围：排课管理侧栏、排课列表/详情页、时间→教室数据流转  
> 状态：待评审 / 待实现  
> 修订要点：教室侧**复制三套独立页面**；时间侧增加**提交**；提交后数据流转至教室侧

---

## 1. 背景与目标

将原「排课安排」拆为两个同级业务阶段：

| 目录 | 业务定位 |
|------|----------|
| **排课表时间** | 安排上课时间；完成后**提交**，任务进入教室侧 |
| **排课表教室** | 安排上课教室；承接时间侧已提交数据；布局与操作步骤与时间侧一致，但为**独立页面与独立业务** |

目标：

1. 重命名「排课安排」及下属三个菜单。
2. 在「课表查询」前新增同级目录「排课表教室」，下挂同名三个二级菜单。
3. 教室侧**复制**三套与时间侧布局、样式、操作步骤一致的页面（独立 page、独立业务）。
4. 页头、面包屑同步改名。
5. 排课表时间各列表页及对应排课界面增加**提交**按钮；提交后数据流转到排课表教室侧。


| 菜单文案 | data-page | 说明 |
|----------|-----------|------|

| 教师排课 | `schedule-teacher` | 列表，可进排课详情 |

| 教室排课（隐藏） | `schedule-room` | 存量页，不作为本方案教室侧主入口 |

## 3. 目标结构（改后）

```
排课管理
├── …基础配置…
├── 【分组】排课表时间
│   ├── 按入学批次排     → schedule-time（+ 提交）
│   ├── 按教师排         → schedule-teacher（+ 提交）
│   └── 按课程排         → schedule-course（+ 提交）
│       └── 排课界面     → schedule-time-detail（时间模式，+ 提交）
├── 【分组】排课表教室          ← 新增，位于课表查询前
│   ├── 按入学批次排     → schedule-room-intake（新建，独立页）
│   ├── 按教师排         → schedule-room-teacher（新建，独立页）
│   └── 按课程排         → schedule-room-course（新建，独立页）
│       └── 排课界面     → schedule-room-detail（新建，教室模式）
├── 【分组】课表查询
└── 【分组】调课管理
```

### 3.1 文案对照

| 位置 | 改前 | 改后 |
|------|------|------|
| 一级分组 | 排课安排 | **排课表时间** |
| 二级 | 入学批次排课 | **按入学批次排** |
| 二级 | 教师排课 | **按教师排** |
| 二级 | 课程排课 | **按课程排** |
| 一级分组 | （无） | **排课表教室** |
| 二级 | （无） | **按入学批次排 / 按教师排 / 按课程排**（独立页） |

### 3.2 页面对照（时间侧 vs 教室侧）

| 维度 | 排课表时间（改名 + 提交） | 排课表教室（复制新建） | 一致性要求 |
|------|---------------------------|------------------------|------------|
| 按入学批次排 | `schedule-time` | `schedule-room-intake`（建议 id） | 布局、筛选区、表格、操作步骤一致 |
| 按教师排 | `schedule-teacher` | `schedule-room-teacher` | 同上 |
| 按课程排 | `schedule-course` | `schedule-room-course` | 同上 |
| 排课界面 | `schedule-time-detail`（时间业务） | `schedule-room-detail`（教室业务） | 布局样式、操作步骤一致；业务焦点不同 |

> page id 为实现建议命名，评审通过后可微调，但须**时间 / 教室两侧分离**，不得共用同一 `data-page`。

### 3.3 「一致」与「独立」边界

| 维度 | 要求 |
|------|------|
| 布局样式 | 与时间侧同名页保持一致（查询区、表格列结构、工具栏位置、详情栅格等） |
| 操作步骤 | 列表查询 → 进入排课 → 落点/调整 → 保存/提交，步骤对齐 |
| 业务数据 | **独立**：教室侧仅展示/处理「时间侧已提交」的任务；排教室结果写教室侧状态 |
| 交互焦点 | 时间侧以排时间为中心；教室侧以排教室为中心（时间可只读或弱编辑，以实现时约定为准） |

## 4. 业务流转：时间侧提交 → 教室侧

### 4.1 流程示意

```mermaid
flowchart LR
  A[排课表时间<br/>排时间] --> B[提交]
  B --> C[任务进入可排教室池]
  C --> D[排课表教室<br/>排教室]
  D --> E[教室侧完成/发布]
```

### 4.2 提交入口（排课表时间）

以下位置均需增加**提交**按钮（文案建议统一为「提交」）：

| 位置 | 说明 |
|------|------|
| 时间侧三个列表页 | 支持勾选后批量提交，和/或行内提交（实现时二选一或并存，建议：列表勾选批量提交 + 详情页提交） |
| 时间侧对应排课界面 | 详情页工具栏增加「提交」，将当前批次/教师/课程范围内已排时间任务提交至教室侧 |

### 4.3 提交规则（建议）

| 规则 | 说明 |
|------|------|
| 前置条件 | 至少存在已排上课时间的课节；未排时间不可提交（或提交时提示并拦截） |
| 提交范围 | 按当前入口维度：批次 / 教师 / 课程（与列表勾选或详情上下文一致） |
| 提交结果 | 任务标记为「已提交排教室」（状态名可定为 `submittedForRoom` / `待排教室`） |
| 教室侧可见 | 仅时间侧已提交的数据出现在排课表教室三列表及详情中 |
| 时间侧提交后 | 建议限制再改时间（只读或需撤回后可改）；撤回是否做本期可选 |
| 教室侧 | 对已接收任务进行排教室；未提交任务在教室侧不可见 |

### 4.4 状态建议（原型可用枚举）

| 状态 | 含义 | 出现侧 |
|------|------|--------|
| 排时间中 / 未提交 | 时间侧作业中 | 仅时间侧 |
| 待排教室 | 已提交，等待排教室 | 教室侧列表可见 |
| 排教室中 | 教室侧已开始安排 | 教室侧 |
| 已完成 | 教室已排完（可选再接发布） | 两侧可展示进度 |

> 具体字段可挂在任务 / 批次进度对象上；原型阶段可用内存 store 模拟流转。

## 7. 实现要点建议

### 7.1 侧栏示例

```html
<div class="nav-group">排课表时间</div>
<a class="nav-item" data-page="schedule-time">按入学批次排</a>
<a class="nav-item" data-page="schedule-teacher">按教师排</a>
<a class="nav-item" data-page="schedule-course">按课程排</a>

<div class="nav-group">排课表教室</div>
<a class="nav-item" data-page="schedule-room-intake">按入学批次排</a>
<a class="nav-item" data-page="schedule-room-teacher">按教师排</a>
<a class="nav-item" data-page="schedule-room-course">按课程排</a>

<div class="nav-group">课表查询</div>
```

### 7.2 页面复制策略

1. **HTML**：复制 `page-schedule-time` / `teacher` / `course` 及详情页，改 id、筛选项 id、表格 tbody id。  
2. **样式**：优先复用现有 schedule 样式类；两侧视觉一致。  
3. **脚本**：  
   - 时间侧：保留现有渲染，增加 `submit*ToRoomSchedule()`。  
   - 教室侧：平行 `renderScheduleRoomIntakePage` 等；数据源 = 已提交集合。  
4. **详情上下文**：`scheduleBatchDetailContext` 增加 `phase: 'time' | 'room'`，返回页、面包屑、可编辑能力按 phase 分支。

### 7.3 提交交互（原型）

1. 用户在时间侧排完时间 → 点「提交」。  
2. 确认框：说明提交后进入排课表教室、是否限制再改时间。  
3. 成功后：提示「已提交至排课表教室」；可选跳转对应教室侧列表。  
4. 教室侧刷新后可见对应批次/教师/课程行，进入详情排教室。

### 7.4 导航高亮

两侧 page-id 已分离，**各点各亮**，无需双入口记忆方案。

## 8. 验收标准

1. 侧栏为「排课表时间」「排课表教室」两个分组，教室分组在课表查询之前；旧「排课安排」文案不再作为导航名。  
2. 时间侧三菜单改名为「按××排」，页头、详情面包屑一致。  
3. 教室侧三菜单可进入**独立页面**（URL/page-id 与时间侧不同），布局样式与操作步骤与时间侧同名页一致。  
4. 教室侧页头、面包屑使用「排课表教室 / 按××排」。  
5. 时间侧列表与排课界面均有「提交」；未满足条件时有明确提示。  
6. 提交后，对应数据出现在教室侧；未提交数据不出现在教室侧。  
7. 操作流程图文案反映「时间 → 提交 → 教室」两段式。  
8. 课表查询、调课管理结构不受影响。
