排课基础设置 排课表时间 排课表教室 课表查询 调课管理
阶段说明（对照当前侧栏）

① 排课基础设置 课表节次维护 → 排课时间设置（学期排课/排教室窗口等）→ 排课规则设置（午休、节次上限）。

② 排课表时间 按入学批次 / 教师 / 课程排时间；课表冲突查询同层。联合排课、自动排课规则 → 自动排课为支路（不插入主路径）。

③ 排课表教室 按时间排、按场地类型排；场地冲突查询为支路。自动排教室侧栏已隐藏，流程图不再展示。

④ 课表查询 课表查询为主入口；课表密度查询、学期安排导出为支路。

⑤ 调课管理 教师端 Class Adjustment（Pending / New）；管理端审批、管理、记录；配置支路为教室开放时间、原因类型；另有公假日停课与批量调课。
