# 授课确认会怎么变？——给业务同事看的对照表

一句话先记住：

- **授课确认** = 任务安排已经提交完成  
- **没确认** = 还不能当正式课用（名单 / 开课清单 / 排课一般进不去）  
- **教师替换** = 课已经确认后，只换老师，不用重新确认  

---

## 表一：你做了什么 → 授课确认会怎样

| 你做的事 | 授课确认变成？ | 老师安排还在吗？ | 学生名单还在吗？ | 还能直接排课/进正式流程吗？ | 还要再确认吗？ |
|---|---|---|---|---|---|
| 提交任务安排 | 已确认 | 在 | 可以去维护 | 可以 | 不用 |
| 教师替换（课已确认） | **还是已确认** | 只换申请里的老师 | 在 | **可以，继续用** | **不用** |
| 任务安排「撤回」 | 变成未确认 | 在（可继续改） | 小组分配会清掉 | 不可以 | **要再提交一次** |
| 名单里「退回」任务安排 | 变成未确认 | 在 | **在** | 不可以 | **要再提交一次** |
| 任务安排「退回」开课计划 | 变成未确认 | **清空** | 按规则拆回各班 | 不可以 | 要从头再走任务安排并提交 |
| 撤回/退回后改完，再提交 | 重新已确认 | 按新的来 | 看上面哪条路径 | 可以 | 这次提交就是再确认 |

---

## 表二：两种「改老师」别搞混

| | 教师替换 | 先撤回，再在任务安排里改老师 |
|---|---|---|
| 什么时候用 | 课已经确认，只想换人 | 还想大改（分组/合班/学时等）或必须撤回时 |
| 授课确认 | **不变，仍是已确认** | 先变成未确认，改完要再提交 |
| 合班、分组 | 一般不动 | 可以一起改 |
| 要不要重新确认 | **不要** | **要** |

---

## 表三：常见问法（直接看答案）

| 问题 | 答案 |
|---|---|
| 课已经确认了，只换一个老师？ | 走 **教师替换**，不用重新确认 |
| 确认后又撤回了？ | 确认没了，改完必须 **再提交** 才算确认 |
| 撤回后能不能只走教师替换，当作又确认了？ | **不能**，必须再提交任务安排 |
| 已经排过课了，能直接撤回任务安排吗？ | **不能**，要先处理排课结果 |
| 名单里点退回，学生会丢吗？ | **一般不丢**；但确认会没，要再提交 |
| 退回开课计划，合班怎么办？ | 合班会拆开；老师安排会清空 |

---

## 一眼流程图

```
提交任务安排 → 已确认 → 可以正式用
                 ↑
                 │ 教师替换（只换老师，确认不变）
                 │
已确认 ──撤回/名单退回──→ 未确认 ──再提交──→ 又变成已确认
```
