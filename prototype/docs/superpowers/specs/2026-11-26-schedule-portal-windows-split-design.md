# 排课门户开放时间拆分 · 模块时间设置分轨

日期：2026-11-26  
状态：已实现（原型 UI / 迁移 / 模块互锁）

## 背景

`#page-schedule-time-setting` 学期表目前只有「教师使用开放时间」「学生查看开放时间」两列，把教师看课表、教师调课开放、调/补/加可选目标时间混在一起（或未建模）。

`#page-schedule-module-setting` 的「时间设置」/`timeSetting`（代码文案已局部改为「排课时间」）只表达排课侧约束是否生效，无法单独开关调课侧时间校验。既有 OpenSpec `schedule-time-vs-adjustment-windows` 曾约定「不新增调课时间设置列」；本次产品明确要求拆列，**以本文为准覆盖该约定**。

## 目标

1. 学期主表用四列门户/调课相关时间替换原「教师使用开放时间 + 学生查看开放时间」。
2. 「调/补/加课可选时间范围」仅校级（学期）配置，专业不可改、不展示。
3. 模块设置「时间设置」更名为「排课时间设置」；**不**单独增加「调课时间设置」列——开放「调课管理」后按学期开放时间窗口校验，关闭则不可用。
4. 旧 `teacherView*` / `studentView*` 可迁移兼容，不删字段。

## 非目标

- 不改排时间 / 排教室详情页交互（遵守 schedule-time-room-independence）。
- 不停课选课大改（仅约定停课不走「调/补/加可选时间范围」）。
- 不在本轮做完整教师/学生门户运行时闸门联调（契约写清；原型以配置 UI + 最小校验/说明为主）。
- 不自动 git 提交。

## 方案（已选）

**方案 1：主表拆列 + 模块拆开关 + 数据字段分轨。**

已否决：仅改文案仍共用旧字段；只拆模块不拆学期列。

## 页面结构

### 排课时间设置 · 学期主表

列顺序（相关段）：

1. 排课起止时间  
2. 排教室起止时间  
3. **教师查看课表时间**  
4. **教师调课开放时间**  
5. **调/补/加课可选时间范围**  
6. **学生查看课表时间**  
7. 操作  

增删改弹窗：原「教师使用开放时间」拆为上述 3～5；学生标签改为「学生查看课表时间」。控件沿用现有起止区间选择器。

### 专业时间设置子表

- 含：排课起止、排教室起止、教师查看课表、教师调课开放、学生查看课表。  
- **不含**「调/补/加课可选时间范围」。

### 排课模块设置

| 原 | 新 |
|----|-----|
| 时间设置 / 排课时间（`timeSetting`） | **排课时间设置**（key 仍 `timeSetting`） |
| （曾试加调课时间设置） | **去掉**；语义并入「调课管理 + 学期开放时间」 |
| 调课管理 | 保留 |

## 字段与闸门

### 学期配置

| 字段 | UI | 闸门 |
|------|-----|------|
| `teacherTimetableViewStart/End` | 教师查看课表时间 | 教师能否查看课表 |
| `teacherAdjustmentOpenStart/End` | 教师调课开放时间 | 教师能否发起调/停/补/加（另需调课管理开放） |
| `adjustmentSelectableRangeStart/End` | 调/补/加课可选时间范围 | 调/补/加申请可选的目标时间；**停课只能选已排课堂，不走此范围** |
| `studentTimetableViewStart/End` | 学生查看课表时间 | 学生能否查看课表 |

专业可覆盖：教师查看课表、教师调课开放、学生查看课表；未配沿用学期。  
专业不可覆盖：`adjustmentSelectableRange*`。

### 模块开关

| key | UI | 闸门 |
|-----|-----|------|
| `timeSetting` | 排课时间设置 | 排课/排教室起止、不排课等**排课侧**约束是否生效 |
| `adjustment` | 调课管理 | 模块总开/关；开放后按学期教师调课开放时间等窗口校验；关闭则强行不可用 |

### 生效条件（契约）

- 教师看课表：当前时间 ∈ 教师查看课表时间（专业有覆盖用专业）。  
- 教师发起调/停/补/加：调课管理开放，且当前 ∈ 教师调课开放时间（已配置时）。  
- 调/补/加选目标节次：目标时间 ∈ 学期「调/补/加课可选时间范围」（已配置时）。  
- 学生看课表：当前 ∈ 学生查看课表时间。

## 互锁 / 默认

1. **排课与调课可并存**（取消「有排课就不能开调课」）。  
2. 开放**排课时间设置** → 排课表时间/教室默认开放；**不**再强制关掉调课管理。  
3. 禁用任一排课权限列 → 排课时间设置一并禁用（排课侧内部联动保留）。  
4. **调课管理**：关=强行不可用；开=按学期开放时间窗口。无独立「调课时间设置」列。  
5. 最新学期默认：排课时间设置、排课权限、调课管理均开放。

## 旧数据迁移

| 旧 | 新 |
|----|-----|
| `teacherViewStart/End` | 同时灌入 `teacherTimetableView*` **与** `teacherAdjustmentOpen*` |
| `studentViewStart/End` | `studentTimetableView*` |
| （无） | `adjustmentSelectableRange*` **默认同该学期排课起止**（便于演示；空=未配时实现按「不限制」或回退排课起止，以默认同排课起止为准） |
| 仅有 `timeSetting` | 补 `adjustmentTimeSetting`：若该学期 `adjustment` 已开放则默认开放（false），否则默认禁用（true） |

旧字段保留兼容，标记弃用，不删除。

## 验收要点

1. 学期主表可见四列新文案；无「教师使用开放时间」「学生查看开放时间」。  
2. 弹窗可分别编辑四类区间；保存后回显正确。  
3. 专业子表无「调/补/加课可选时间范围」；另三列可配。  
4. 模块表可见「排课时间设置」「调课时间设置」；互锁符合上文。  
5. 旧学期数据打开后教师查看/调课开放均有值（来自旧 teacherView 迁移）。
