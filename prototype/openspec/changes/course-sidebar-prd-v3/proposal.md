## Why

开课管理侧栏已挂出 12 个二级菜单原型，但需求文档仍多为旧 PRD V2 章节结构，且「授课教师替换」「排课计划」尚未纳入 PRD 目录映射。现已定稿《厦大马来分校本科教务系统PRD模板_V3》与变更说明简版 V3，需要把这批菜单的需求正文统一升到 V3（界面 ID / 字段状态矩阵 / 功能与规则编号），便于评审对账与开发交接。

## What Changes

- 按 PRD 模板 V3，为下列 **12 个侧栏菜单** 各产出一版完整需求文档（**md + docx**），写入各自新版本文件夹（禁止覆盖旧版）：
  - 开课设置：开课时间设置、校选课程管理、特殊课程设置
  - 专业开课：开课计划、开课安排、开课名单
  - 课程班管理：课程班、Teaching Load、授课确认管理、授课确认（教师端）、**授课教师替换**、**排课计划**
- 有上一有效版的菜单：升 `Vn+1`，并产出 **变更说明简版 V3**（含对象类型 / 对象ID）
- 尚无版本文件夹的菜单（授课教师替换、排课计划）：补 `prd_folder_paths` 映射与目录后出 **首版 V1** +「无→V1」变更说明
- 内容来源：现行原型（`index.html` / `app.js`）与上一有效版 PRD；未知规则标「未确认 / UC」，**不编造**学校政策或接口字段
- **不改**业务代码、页面交互与运行时数据行为（纯文档交付）
