## Why

排课管理（含调课）面向英文语境用户时，时间轴与场地相关表头仍大量使用中文（周次 / 日期 / 星期 / 教室），与已英文化的 Course Code、Lecturer 等不一致。补课 Pending 等列表已开始局部英文化，需要整块统一，避免同屏混用。节次暂保持中文，待后续再定英文措辞。

## What Changes

- 在**排课管理侧栏**（`#sidebar-nav-schedule`）覆盖的全部页面、抽屉、弹窗与导出中，将以下**字段标签**统一改为英文：
  - 周次 → **Week**
  - 日期 → **Date**
  - 星期 → **Day**
  - 教室 → **Venue**
- **本次不改「节次」**（表头 / 筛选 / 表单 / 导出均仍用「节次」）。
- 同语义复合标签在排课/调课范围内一并替换（如 教室类型 → Venue Type，上课教室 / 原教室 / 目标教室 / 调后教室 → 对应 Venue 措辞）。
- **不改**单元格展示值本身的语言习惯（如 `周一`、`第1节（8:00 AM-…）`、周次数字 `1` 等），除非该处本就是标签文案。
- **不改**开课模块、培养方案模块，以及「起止周」等不同语义字段。
- 排时间 / 排教室详情网格：表头轴标签按上表英文化；联合排课已去掉的「星期」空表头保持空（不加 Day），避免回退此前交互。

## Capabilities

### New Capabilities

- `schedule-en-axis-labels`：排课管理域内 Week / Date / Day / Venue 字段标签英文化约定与覆盖范围（节次暂除外）

### Modified Capabilities

- （无）现有主 specs 不因此次纯标签替换产生需求级变更

## Impact

- `index.html`：排课/调课页面与相关 modal 中的 `<th>` / `<label>` / 文案
- `app.js`：动态表头、筛选 label、导出 CSV headers、详情/冲突抽屉字段名、变更日志 `fieldLabel`（仅排课/调课实体）
- `styles.css`：通常无需改；若有依赖中文选择器的文案钩子需核对（预期无）
- 范围边界：仅 `sidebar-nav-schedule` 域；开课 / 培养方案侧栏与其页面保持中文原样
