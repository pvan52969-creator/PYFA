# 排教室界面 · 教室列表与占用交互改动方案

> 文档性质：代码改动方案（需求已确认）  
> 适用范围：排课管理 · 排教室详情（`scheduleDetailPhase === 'room'`）  
> 关联代码：`prototype/app.js`、`index.html`、`styles.css`  
> 前置文档：[排教室界面冲突与教室安排改动方案.md](./排教室界面冲突与教室安排改动方案.md)

---

## 1. 已确认产品规则

| 议题 | 决策 |
|------|------|
| 多锁定教室 | **并集显示**：筛选与教室池仅保留全部 `lockedRoom` 的并集 |
| 部分覆盖教室 | **不隐藏**，按匹配度排序**靠后**（tier=2） |
| 节次已有 `room` | 点击格时 **提示不能排**，不允许再待定 |
| 锁定操作 | **立即持久化**：`slot.room` 写入 + `persistTaskSchedule` + `markScheduleDirty` |
| 筛选区名称 | **教室筛选**（非教师筛选） |

---

## 2. 目标概览

1. 左侧课程列表：按**当前教学周次** + 菜单作用域，展示课表内已排时间节次。  
2. 选课后**教室筛选**自动回显：有锁定教室 → 按锁定教室并集查；无锁定 → 按场地类型查。  
3. 右侧教室列表：默认未锁定教室；底部 **fixed**「展开更多教室」；按有效座位升序 + 时间匹配精度排序。  
4. 节次格：空白 / 待定 / 锁定 三色；点击空白 → 待定；已占用 → 3 秒 toast。  
5. 课表区顶部居左：**锁定**（待定→锁定并持久化）、**撤回**（释放待定）。

---

## 3. 数据与状态

```javascript
scheduleRoomFilterMode = 'venueType' | 'lockedRoom'
scheduleRoomFilterLockedRooms = []          // 锁定教室并集
scheduleRoomPendingBySlot = Map<slotId, { room, weekday, periodFrom, periodTo }>
scheduleRoomTimetableExpanded = boolean     // 展开全部教室（含他批锁定）
```

- **待定**：仅内存 `scheduleRoomPendingBySlot`，不写 `slot.room`。  
- **锁定**：清除待定 → `applyScheduleRoomToSlotForWeeks` → `persistTaskSchedule`。

## 4. 模块改动

### 4.1 左侧课程列表

- `buildScheduleRoomMergedSlotCards`：增加 `slotMatchesWeekFilter(slot, task, getScheduleDetailTimetableWeekFilter())`。  
- 切换 `#schedule-detail-week-grid` 后 `renderScheduleDetailPage` 重算列表（已有 `commitScheduleWeekDrag`）。

### 4.2 教室筛选回显

- `syncScheduleRoomFilterFromActiveCard()`：在 `selectScheduleRoomMergedCard` 成功后调用。  
- **仅同步到教室筛选条件**，不硬锁教室池：  
  - 有 `lockedRoom`：初始 `applied = { lockedRoomUnion: true }`，场地类型写入表单可改；单个锁定教室同时回显到「教室」。  
  - 无锁定：自动选中卡片 `venueTypes[0]` 并写入 `scheduleRoomTimetableFilterApplied`。  
- 用户可修改任意筛选条件后点「查询」重新过滤；「重置」恢复当前课程的默认同步条件。

### 4.3 教室池与排序

- `getScheduleRoomTimetableBasePool`：仅列表入口作用域；场地类型 / 锁定教室由 `applyScheduleRoomTimetableUserFilters` 按已应用条件过滤。  
- `scoreScheduleRoomTimeMatch(room, need, tasks, weekFilter)`：  
  - tier 0：需求节次全空闲（精准）  
  - tier 1：全空闲且连续空闲区间 > 需求节次（富余）  
  - tier 2：部分覆盖（`overlapRatio` 作三级键）  
  - tier 9：需求节次全占用（排最后，展开时仍显示）  
- `getScheduleRoomTimetableRows`：座位升序 → tier → 富余/覆盖比 → 教室名。

### 4.4 节次列

- 教室列表**始终展示全部节次列**（课表节次维护配置）。  
- 选中课程的 `periodFrom~periodTo`（`getScheduleActiveRoomPeriodNeed`）仅用于匹配度排序与待定占用范围，不收窄表头。

### 4.5 展开更多（fixed）

- `#schedule-room-grid-footer` 置于 `.schedule-timetable-scroll` 外，CSS `position: sticky; bottom: 0`。  
- 不再使用 tbody 内 expand row。

### 4.6 格态与点击

- `getScheduleRoomCellState(room, weekday, periodNo)`：`empty` | `pending` | `locked`。  
- `onScheduleRoomGridCellClick(room, weekday, periodNo, ev)`：  
  1. 未选左侧课程 → 忽略  
  2. 选中节次已有 `room` → toast「该课程已安排教室，不能重复排教室」  
  3. 格态 locked/pending → toast「该时段已被锁定/待定，请重新选择」  
  4. empty → 写入 `scheduleRoomPendingBySlot`  
- `showScheduleRoomCellToast(msg)`：3 秒自动关闭。

### 4.7 锁定 / 撤回

- `#schedule-room-hold-actions`：排教室阶段显示；有 pending 时启用。  
- `lockScheduleRoomHold()`：待定 → `slot.room` + 持久化。  
- `revokeScheduleRoomHold()`：清除当前选中节次的待定。

---

## 5. 实施顺序

1. 状态变量 + 左侧周次过滤 + 筛选回显 + 锁定并集池  
2. 匹配度排序 + 节次列收窄 + fixed 展开底栏  
3. 格态着色 + 点击待定/toast + 锁定/撤回持久化  

---

## 6. 与旧方案差异

- 废止「排教室侧点击空格无操作」约定，改为**待定占用**工作流。  
- 锁定即持久化，不依赖额外「保存排课」按钮（仍保留脏标记与现有保存条）。
