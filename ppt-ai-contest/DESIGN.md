# DESIGN.md — AI大赛参赛PPT设计稿

## 项目信息
- **主题**：AI赋能开课管理系统全流程提效
- **受众**：AI大赛评委（技术专家 + 业务负责人）
- **场景**：现场汇报评审
- **页数**：16页
- **风格**：科技未来感、蓝紫暗色系、数据驱动、专业可信

---

## 1. 画布与全局母版

| 参数 | 值 |
| :--- | :--- |
| 画布尺寸 | 1280 × 720 |
| 母版结构 | 三区（A标题块 / B内容区 / C页脚条） |
| A区 | 0–120px，标题32–36px bold，左对齐，padding-left 70px |

## 2. 颜色系统

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |
| 背景主色 | `#0A0E27` | 全篇底色、封面/章节过渡/结束页满铺背景 |
| 卡片底色 | `#131C3D` | 内容卡片、信息块、表格底色 |
| 主色（蓝） | `#3B82F6` | 标题栏渐变起点、按钮、关键图标 |
| 辅色（紫） | `#8B5CF6` | 渐变终点、副标题点缀、次要区块 |
| 强调色（青） | `#06B6D4` | 巨型数字、核心数据标注、CTA元素 |
| 文本主色 | `#F1F5F9` | 标题、正文、卡片标题 |
| 文本副色 | `#94A3B8` | 引导句、辅助说明、页码 |
| 成功绿 | `#10B981` | 正向指标、完成状态 |
| 警告橙 | `#F59E0B` | 对比强调、待办标注 |

### 色彩面积分配

| 色彩角色 | 面积占比 | 适用区域 |
| :--- | :--- | :--- |
| 背景主色 | 60–70% | 全页底色 |
| 主/辅色 | 20–30% | 标题栏、卡片边框、装饰色块 |
| 强调色 | ≤10%（Hero页15–20%） | 巨型数字、关键图标 |
| 文本/中性色 | 剩余 | 正文、页脚 |

### 渐变方案
- **标题栏渐变**：`linear-gradient(135deg, #3B82F6 0%, #8B5CF6 100%)`
- **卡片头部渐变**：`linear-gradient(135deg, rgba(59,130,246,0.15) 0%, rgba(139,92,246,0.08) 100%)`
- **大数字渐变**：`linear-gradient(180deg, #06B6D4 0%, #3B82F6 100%)` 作为文字裁剪色
- **半透明覆盖**：`rgba(59,130,246,0.08)` 大面积浅色蒙版

## 3. 字体系统

| 层级 | 大小 | 字重 | 行高 | 字体 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 64px | bold | 1.2 | 思源黑体 | 仅封面 |
| 章节大字 | 56px | bold | 1.1 | 思源黑体 | 章节过渡、结束页 |

## 4. 装饰元素白名单

| 元素 | 用法 |
| :--- | :--- |
| 渐变竖线 | 标题块左侧4px宽，蓝紫渐变，A区标题前缀 |
| 发光圆点 | 卡片列表项前缀，6px直径，`#3B82F6` + glow效果 |
| 半透明网格线 | 部分页面背景，`rgba(59,130,246,0.03)` 细网格 |
| 底部渐变条 | C区上方4px宽渐变线，蓝→紫→透明 |
| 装饰几何块 | 封面/结束页角落，`opacity:0.12` 的三角形/圆形色块 |

**禁止**：阴影过重（boxShadow blur ≤ 30px）、装饰小贴片（200×70塞标题栏）、全页图片轮播式排版

## 6. 生图清单

本PPT无需外部生图，全部采用SVG几何装饰、渐变、图表组件。原因：暗色科技风适合几何抽象，避免具象图片与暗色背景的冲突。
