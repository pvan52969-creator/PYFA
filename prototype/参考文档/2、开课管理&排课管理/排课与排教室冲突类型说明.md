# 排课与排教室 · 冲突类型说明

| 项 | 内容 |
|----|------|
| 文档性质 | 产品/实现口径说明（与当前原型一致） |
| 适用范围 | 排课管理 · 排课表时间 · 排课表教室 |

## 1. 两侧职责对照

| 维度 | 排课（排时间） | 排教室 |
|------|----------------|--------|
| 主职责 | 安排星期 / 节次 / 周次，设置场地类型与备注 | 为已排时间节次安排具体教室 |
| 冲突关注 | 教师、学生、占位时段、先修、预重修；午休/规则/学时仅弹窗 | 仅教室三类：教室时间、座位数、场地类型 |
| 不检测 | 教室时间 / 座位数 / 场地类型 | 教师 / 学生 / 占位 / 先修 / 预重修等时间侧冲突 |
| 数据关系 | 排课后提交至排教室 | 承接时间侧已提交节次并派教室 |

## 2. 排课界面（排时间）冲突类型总表

| 冲突类型 | 图例归属 | 判定规则 | 格子着色 | 落点操作 | 说明 |
|----------|----------|----------|----------|----------|------|
| 教师冲突 | 教师冲突 | 同教师在同星期、重叠节次、重叠周次已有课 | 是 | 不可继续，仅提示 | 硬冲突 |
| 学生冲突 | 学生冲突 | 同专业批次学生时段重叠；含本课其他学时已排节次 | 是 | 不可继续，仅提示 | 硬冲突 |
| 不排课时间 | 占位/时段提示 | 命中排课时间设置 · 课表不排课时段 | 是 | 可强制落点；落点后保留着色 | 落点弹窗提醒 |
| 选修课占位 | 占位/时段提示 | 命中排课时间设置 · 选修课预占位 | 是 | 按钮可见，点击通常拦截；与午休/排课规则并存时才可真正继续 | 落点弹窗提醒 |
| 教师排课时间 | 占位/时段提示 | 教师「不排课」命中，或「只排课」落点不在允许时段内 | 是 | 可强制落点；落点后保留着色 | 只排课/不排课互斥 |
| 先修冲突 | 先修冲突 | 先修/后修课程同时段冲突 | 是 | 可强制落点 | — |
| 预重修冲突 | 预重修冲突 | 仅「重修检测」进行中出现 | 是 | 可强制落点 | 非检测中不展示 |
| 综合冲突 | 综合冲突 | 多种可着色冲突并存且走综合主类型时 | 是 | 以明细中最严规则为准（含硬冲突则不可继续） | 品红色 |
| 午休规则 | — | 命中午休相关排课规则 | 否 | 可强制继续 | 仅弹窗 |
| 排课规则 | — | 每日节次上限、教师晚间天数等规则 | 否 | 可强制继续 | 仅弹窗 |
| 学时超排 | — | 该学时已排满或落点将超排 | 否 | 可强制继续（将产生超排） | 仅弹窗 |

### 2.1 占位冲突补充口径

| 项 | 说明 |
|----|------|
| 落点时 | 在规则时段内排课须弹窗提醒 |
| 忽略后 | 已排课格仍检测占位冲突，黄色着色保留 |
| 只排课判定 | 落点不在任一只排课时段内即冲突 |
| 不排课判定 | 落点命中不排课时段即冲突 |
| 互斥规则 | 教师档案只排课 / 不排课二者择一 |
| 图例显示 | 占位三类图例合称「占位/时段提示」；弹窗细类按实际命中展示，多种并存时回退为「占位/时段提示」 |
| 不检测范围 | 排时间侧不检测教室时间、座位数、场地类型 |

## 3. 排教室界面冲突类型总表

| 冲突类型 | 强度 | 判定规则 | 格子着色 | 安排教室操作 | 说明 |
|----------|------|----------|----------|--------------|------|
| 教室时间冲突 | 硬 | 拟派教室时段被排考、场地借用等非排课占用，或命中排课时间设置 · 教室排课时间（不排课） | 是 | 禁止安排 | 图例显示；锁定教室 / 审批选教室确定时同样硬拦 |
| 座位数冲突 | 软 | 小组/课程上限人数 > 教室有效座位 | 否（仅弹窗） | 可继续 | 样式预留紫色格子色 |
| 场地类型不一致 | 软 | 节次要求的场地/教室类型与所选教室无交集 | 否（仅弹窗） | 可继续（可忽略） | 样式预留绿色格子色 |
| 综合冲突 | — | 多类教室冲突并存 | 按主类型/综合色 | 含教室时间则一律硬拦 | 弹窗分行展示明细 |

### 3.1 排教室补充口径

| 项 | 说明 |
|----|------|
| 他课占用 | 他课已派教室由格态「锁定」拦截，不计入教室时间冲突 |
| 教室不排课 | 来自排课时间设置 · 教室排课时间；写入教室时间冲突（硬）。排教室选教室、排时间锁定教室、调课审批选教室均检测；审批「不指定教室」不检 |
| 不检测范围 | 排教室侧不判教师/学生/占位/先修/预重修等时间侧冲突 |

### 3.2 格态色（非冲突）

| 状态 | 说明 | 背景色 |
|------|------|--------|
| 锁定 | 该时段教室已锁定占用 | `#e5e7eb` |
| 待定 | 当前操作待定占用，尚未锁定 | `#fde68a` |

## 5. 综合冲突说明

| 项 | 说明 |
|----|------|
| 定义 | 同一格子或同一次落点/派教室动作中，同时命中多种冲突类型时的展示口径 |
| 展示名 | 综合冲突 |
| 色系 | 品红（格子 `#f0abfc`，描边/色块 `#c026d3`，摘要底 `#fae8ff`） |
| 排时间侧着色优先级 | 教师 > 学生 > 教室 > 先修 > 预重修 > 占位（soft）；走综合主类型时用品红色 |
| 排教室侧处理 | 教室时间 / 座位数 / 场地类型多种并存时弹窗分行展示；含教室时间则不可强制继续 |
| 操作原则 | 以明细中最严规则为准：存在硬冲突（教师/学生/教室时间）则不可继续；仅软冲突可按各类型规则强制或忽略 |
