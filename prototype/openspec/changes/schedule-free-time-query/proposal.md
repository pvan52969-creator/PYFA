## Why

教务常需同时对比多名教师、学生、专业批次（及场地）在指定周次范围内的空闲节次，以便找共同空档或安排补课/调课。现有「课表查询」按单一对象看已排课表，「课表密度查询」看占用密度，都无法一次混选多类对象并以列表汇总空闲时间。

## What Changes

- 在侧栏「课表查询」分组下新增菜单 **空闲时间查询**（独立页面，非课表查询 Tab）。
- 查询条件支持：学年学期、周次区间（可单周可多周）、星期、节次（时间）、场地；对象可 **混选** 教师 / 学生 / 专业批次 / 场地。
- 结果以 **列表** 展示：**一行一个对象**，汇总该对象在筛选范围内的空闲节次。
- 提供查询 / 重置；支持导出（与同类列表页一致的按查询条件导出即可，原型演示）。
- 复用现有查询条件布局标准（一行最多 3 条件，按钮在第一行右侧）；演示数据即可，不接真实后端。

## Capabilities

### New Capabilities

- `schedule-free-time-query`: 空闲时间查询页（混选对象、周次区间与时间/场地筛选、按对象一行汇总空闲节次列表）

### Modified Capabilities

- （无）`openspec/specs/` 下暂无对应主规格需改写

## Impact

- `index.html`：侧栏导航项；新页面 `#page-schedule-free-time`（查询区 + 列表 + 导出条）
- `styles.css`：列表空闲节次单元格等页面局部样式（优先复用 `schedule-query-*` / 密度页多选）
- `app.js`：页面注册与路由；筛选渲染；空闲计算（相对已排课演示数据取补集）；列表渲染与导出
- 侧栏「课表查询」分组：在「课表密度查询」旁增加入口
- **不改**排时间 / 排教室详情页交互；不改课表查询各 Tab
