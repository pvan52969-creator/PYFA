阶段说明（对照当前原型侧栏）

开课设置：开课时间设置、校选课程管理、特殊课程设置；专业开课依赖已锁定执行计划；选修开课依赖校选课程库。

专业 / 选修 / 特殊开课：各走「计划 → 安排 → 名单」。安排步骤含师资与授课确认门槛；停课不在各安排页工具栏，统一在「课程班」页批量操作。

课程班管理：「课程班」汇总三类已开出课程班（含草稿/已生效/停课）；Teaching Load、授课确认管理/教师端、授课教师替换为并列入口。下游排课/选课消费已生效且授课确认完成的数据。
