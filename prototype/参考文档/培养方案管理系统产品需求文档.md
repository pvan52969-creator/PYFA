## 2.2 系统需求（模块摘要）

### 2.2.1 方案版本管理（已确认）

| 项目 | 内容 |
|------|------|
| 列表字段 | 勾选、培养方案版本、审批状态、专业代码、学制、版本、开始/截止批次、授予学位、引用情况、操作 |
| 检索 | **专业、审批状态** |
| 批量操作 | 提交审批（draft/rejected）、版本导出（模板待确认） |
| 批次链 | 上一版本截止 = 下一版本开始的前一批次；当前有效版本 endIntake 为空；当前有效版本行高亮（绿底 + 左边框） |
| 状态标签 | Draft / In Progress / Approved / Rejected（英文） |

**列表列对齐（居中）：** 审批状态、专业代码、学制、版本、开始批次、截止批次、授予学位、版本引用情况。

**版本编辑三 TAB：** TAB1 课程分类 · TAB2 课程设置 · TAB3 方案进程表

**TAB1：**
- 分类树表头列「**课程性质**」（原修读类型，展示必修/选修）
- 课程性质列居中
- 一级不可编辑/删除；「+ 新增分类」仅新增二级；三级在二级行「+子级」

**TAB1 学分校验：**

| 分类 | 规则 |
|------|------|
| 必修（有三级） | 三级最低合计 = 二级最低 = 二级最高 |
| 选修（有三级） | 三级最低合计 ≤ 二级最低 ≤ 二级最高 |

**TAB2 学分校验：**

| 分类 | 添加时 | 提交时 |
|------|--------|--------|
| 必修 | 二级累计 ≤ 最高 | 最低 ≤ 已配 ≤ 最高 |
| 选修 | 已配 ≥ 最低 | 已配 ≥ 最低（最高仅限制学生选课） |

**TAB2 其他：**
- 分类课程学分配置情况表（可展开）
- 分类筛选、搜索
- 移除课程二次确认
- **居中列：** 学分、开课学期、课程性质（执行计划模式另加「实际开课学期」）
- 课程弹窗：必修强制「指定学期」；选修可开关；**查看模式下指定学期开关与下拉不可操作**（`not-allowed`）

**开课学期（版本）：** Y1S1~YnS3 模板，**不含具体年月**；Y 为培养方案学年（非自然年），相对版本起始批次（02/04/09）。

#### 开课学期映射规则（核心）

**表 1  一年三学期与入学类型**

| 入学类型 | S1 | S2 | S3 |
|:--------:|:--:|:--:|:--:|
| 02 入学 | 02 | 04 | 09 |
| 04 入学 | 04 | 09 | 02 |
| 09 入学 | 09 | 02 | 04 |

> Y1S1~Y1S3 均属第一学年 Y1；Y 为培养方案学年，非自然年。

**表 2  三类学期对照**

| 概念 | 位置 | 含义 |
|------|------|------|
| 版本开课学期 | 方案版本/变更 | 相对版本起始的 Y1S1~YnS3 |
| 执行计划开课学期 | 执行计划 TAB2 | 相对本入学批次的 Y1S1~YnS3 |
| 实际开课学期 | 仅执行计划 | 明确年月，供开课模块 |

**表 3  生成时换算步骤**

1. 保留版本原始学期 `versionSemester`
2. 按版本/执行起始批次类型旋转槽位 → 执行计划 `semester`
3. 计算 `actualSemester`
4. 选修课学期矩阵同步旋转

**表 4  示例：版本 2023/02 + 批次 2029/09**

| 执行开课学期 | 实际开课学期 | 取自版本 |
|:------------:|:------------:|:--------:|
| Y1S1 | 2029/09 | Y1S3 |
| Y1S2 | 2030/02 | Y1S1 |
| Y1S3 | 2030/04 | Y1S2 |
| Y2S1 | 2030/09 | Y2S3 |

## 附录 A：核心数据实体

| 实体 | 说明 |
|------|------|
| PROGRAMMES | 专业（Programme）主数据；原 MAJORS |
| VERSIONS | 版本主表；`programmeKey`、`startIntake`、`endIntake` |
| EXEC_PLANS | 执行计划；`intake`（入学批次编码） |
| VERSION_CONTENT_STORE | 版本方案内容 |
| EXEC_CONTENT_STORE | 各批次执行计划独立副本 |
| PROGRAM_COURSES | 含 semester、actualSemester（仅执行计划）、versionSemester |

> 课程分类中的「Major Core / Major Elective」等为课程层级术语，与 Programme（专业）不同，保持不变。
