## 1. 文档概述

### 1.1 文档目的

明确本二级菜单界面树、字段矩阵、功能与 tip 业务规则，供产品、研发、测试与 AI 后端统一依据。

### 1.2 填写口径

- 「（已明确）」：原型可见文案或 tip/alert 已写明。
- 「（未确认）」：未讨论或占位。
- 教室偏好凡多选控件处禁止写成自由文本。
- 原型已注释/隐藏的入口在规则中标明「原型已隐藏」，禁止当生效能力实现。

### 1.3 建设背景

从课程库纳入特殊课程并维护学时模式/教室偏好/Support/共同授课默认，供开课带出。

## 2. 菜单与功能范围

### 2.3 非目标

学分、总学时、计划人数、预留名额、选课方式、是否排课/排场地等教学任务字段在**开课计划**抽屉维护；本菜单编辑抽屉现行可见 UI 不含上述字段，禁止按开课计划抽屉抄入本菜单。

## 3. 界面结构

```
P01 page-special-course-settings
├── P01-F01 查询（所属部门/课号/课名）
├── P01-L01 列表
├── P01-M01 添加课程
└── P01-D01 编辑特殊课程 drawer-special-course-edit
      课程信息 / 学时类型设置 / 教室偏好设置 / Support / 共同授课
```

## 4. 抽屉分区（已明确）

学时类型设置同开课计划：全部合并 / 部分学时合并 / 按学时类型分别安排。教室偏好设置：按学时类型分行，场地类型+多选参考教室，下拉可搜教室号或软件名。Support 历史由默认 Support 专业自动带出（勾选→Y，未勾选→N，不可手改）。共同授课：添加课程维护共同授课课号。

对照走查：薄版缺的是抽屉可见项（学时模式/教室/Support/共同授课），不是学分名额；学分名额不在本抽屉。
